# F46 退药

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

已发药处方的退药：按明细行退回到原批次，生成回库流水与退药金额依据，供 M09 F63 退药退款。

---

## 2. 依赖

- 依赖：M06（`prescription_item` / `herb_prescription_item` 已发数量）、F51/F114（发药记录）、F41（批次）
- 被依赖：M09 F63（退药退款）、M15 F121（进销存"退药"列）

---

## 3. 涉及的表

`drug_return`、`drug_return_item`、`stock_transaction`、`stock`、`herb_stock`（均 M07 自有）

---

## 4. 规则

**R1 退药必须有来源处方。** 退药明细关联 `prescription_item_id` / `herb_prescription_item_id`，无处方不得退药（杜绝无源入库）。

**R2 退量 ≤ 已发量 − 已退量。** 超额退药拒绝（E3053）。

**R3 退药单号 `DR{yyyyMMdd}{4位}`**（契约 §1.2），状态 `DRAFT → CONFIRMED | VOID`，确认后回库生效。

**R4 回原批次，但不得复活终态批次。** 退药优先回到发药时扣减的批次（`stock_transaction` 可追溯）；
原批次已是 `DEPLETED` / `EXPIRED`（契约 §2.8 终态）时**不得复活**，改为退回同品目可用批次；
若该品目已无任何 `NORMAL` 批次，则新建批次回库（继承成本与效期），全过程写流水与状态日志。

**R5 过期/冻结批次不可退入。** 目标批次 `EXPIRED` → 拒绝；`LOCKED`（盘点中）→ 拒绝并提示盘点结束后处理（E3051）。

**R6 饮片按克回库。** 退药量 = 退回付数 × 每味剂量（g）。

**R7 金额按开方时价。** 退药金额取**处方明细的开方时价**（`unit_price_fen` / `price_milli_per_g`），不取当前资料库价（F112 R7 同族规则）。

**R8 高风险审计。** 退药确认写 `audit_high_risk`（RISK_REFUND 同类），含原因；退药原因必填。

**R9 处方状态联动。** 部分退药 → `PARTIAL_RETURNED`，全部退完 → `FULLY_RETURNED`；**由 M06 `transition()` 完成，M07 不直接 UPDATE**（R-M07-7）。

## 5. 验收标准

**AC1（部分退药）**
- Given 处方已发药 2 盒
- When 退 1 盒
- Then 生成 DR 单，库存 +1，处方状态 `PARTIAL_RETURNED`
- 验证方式：自动

**AC2（全额退药）**
- Given 剩余已发 1 盒全部退回
- When 确认退药
- Then 处方状态 `FULLY_RETURNED`
- 验证方式：自动

**AC3（超额被拒）**
- Given 已发 2 盒，申请退 3 盒
- When 确认
- Then 拒绝 E3053
- 验证方式：自动

**AC4（无源退药被拒）**
- Given 未关联处方明细
- When 创建退药单
- Then 拒绝 E2001
- 验证方式：自动

**AC5（回原批次）**
- Given 发药扣的是批次 B1
- When 退药
- Then 回库流水 `batch_id=B1`
- 验证方式：自动

**AC6（饮片按克）**
- Given 退 2 付、每味 15g
- When 确认
- Then 回库 `+30 g/味`
- 验证方式：自动

**AC7（金额按开方时价）**
- Given 开方时价 1000 分，现资料库价 1200 分
- When 退药
- Then 退药金额按 1000 分计
- 验证方式：自动

**AC8（高风险审计）**
- Given 退药确认
- When 查 `audit_high_risk`
- Then 有记录且含原因
- 验证方式：自动

**AC9（崩溃一致）**
- Given 退药事务中途强杀
- When 重启
- Then 库存与退药单要么全在要么全不在
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3053 | 退药数量超过可退数量 | 否 |
| E3051 | 目标批次状态不允许回库 | 否 |
| E2001 | 未关联来源处方明细 | 否 |
| E3001 | 退药单状态非法转换 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 确认中途崩溃 | 事务回滚，可重新确认 |
| 批次已被盘点冻结 | 提示盘点结束后重试，不静默换批次 |
