# F48 盘点

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: L（拆 F48.1 建单 / F48.2 录入 / F48.3 差异处理 / F48.4 审批）]

---

## 1. 职责

周期性实物盘点：冻结批次 → 录入实盘数 → 生成差异 → 审批后生成调整流水，校正账面库存。

---

## 2. 依赖

- 依赖：F41（批次冻结/解锁）、F42（账面量）、F43（调整流水）
- 被依赖：M15 F121（盘点差异单独列示）

---

## 3. 涉及的表

`stock_check`、`stock_check_item`、`stock_check_status_log`、`stock_transaction`、`stock_batch`

---

## 4. 规则

**R1 单号 `CK{yyyyMMdd}{4位}`**（契约 §1.2）。

**R2 状态机（契约 §2.12）。**
```
DRAFT → COUNTING（批次 LOCKED）→ ADJUSTING（差异待处理）→ APPROVED（生成调整流水）
DRAFT → CANCELLED
```
每次转换写 `stock_check_status_log`，禁止裸 UPDATE。

**R3 冻结范围。** 进入 `COUNTING` 时，范围内的批次置 `LOCKED`，禁止出库（R-M07-9）；退出（审批/取消）时解锁回 `NORMAL`。

**R4 账面粉本。** 建单时冻结账面量快照 `book_qty`，**不随后续出入库变化**（盘点期间账面以快照为准）。

**R5 差异 = 实盘 − 账面。** 差异可正可负；`ADJUSTING` 阶段可逐行标记「调整 / 不调整」并填原因。

**R6 审批生成调整流水。** 只对标记为「调整」的行生成流水（`ref_type='STOCK_CHECK'`），数量为差异值（带符号），`amount_fen` 按批次成本计。

**R7 盘点期间不允许其他库存变动。** 被冻结批次的发药/报损/退药全部拒绝（E3051），需先结束盘点。

**R8 高风险审计。** 审批（涉及库存账实调整）写 `audit_high_risk`。

**R9 未审批不生效。** `ADJUSTING` 状态下库存不变，可取消（`CANCELLED`）并解锁。

## 5. 验收标准

**AC1（建单冻结）**
- Given 建盘点单含药品 A 两个批次
- When 进入 COUNTING
- Then 两个批次 `LOCKED`，账面量快照已记录
- 验证方式：自动

**AC2（冻结期间禁止出库）**
- Given 批次被盘点冻结
- When 发药
- Then 拒绝 E3051
- 验证方式：自动

**AC3（录入实盘生成差异）**
- Given 账面 30，实盘 28
- When 录入
- Then `diff_qty = -2`
- 验证方式：自动

**AC4（审批生成调整流水）**
- Given 差异 -2 并标记调整
- When 审批
- Then 库存变 28，一条 `qty_change=-2` 的调整流水，批次解锁
- 验证方式：自动

**AC5（不调整的行不产生流水）**
- Given 两行差异，其中一行标记不调整
- When 审批
- Then 只产生一条调整流水
- 验证方式：自动

**AC6（取消解锁）**
- Given COUNTING 状态盘点单
- When 取消
- Then 批次回 NORMAL，无流水产生
- 验证方式：自动

**AC7（非法状态转换）**
- Given 盘点单 APPROVED
- When 再次审批
- Then 拒绝 E3054
- 验证方式：自动

**AC8（高风险审计）**
- Given 审批完成
- When 查 `audit_high_risk`
- Then 有记录含差异汇总
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3054 | 盘点单状态非法转换 | 否 |
| E3051 | 盘点冻结期间禁止库存变动 | 否 |
| E3050 | 调整后出现负库存（需先处理原因） | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 审批中途崩溃 | 事务回滚，批次保持 LOCKED，可重新审批（幂等） |
| 实盘录错 | ADJUSTING 阶段可改；已审批则新增一次盘点单 |
