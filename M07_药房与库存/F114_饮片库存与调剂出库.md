# F114 饮片库存与调剂出库

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

中药饮片的库存与调剂：**库存单位恒为克（g）**，出库量 = `每味剂量(g) × 付数`，并按配置的损耗率扣减；支持按味逐行选批。

---

## 2. 依赖

- 依赖：M06（`herb` / `herb_prescription_item` / 处方 `doses`）、F41（批次）、F43（流水）
- 被依赖：F115（中药发药）、M15 F121（饮片进销存）

---

## 3. 涉及的表

`herb_stock`、`herb_dispense`、`stock_transaction`、`stock_batch`

---

## 4. 规则

**R1 单位恒为克。** 入库可按 kg 录入并换算（F40 R6）；`herb_stock.qty_g` 与所有饮片流水均以 g 计（契约 §8 / R-M07-5）。

**R2 出库量算法（契约 §8）。**
```
扣减量(g) = round( 每味剂量(g) × 付数 × (1 + 损耗率‰/1000) )
```
损耗率取配置 `herb.loss_rate`（千分比，默认 0）；**损耗只影响库存，不计入患者费用**。

**R3 付数变更必须重算。** 与 F112 同理：付数变了要按新付数重算每味扣减量，**不得按比例缩放**（契约 §3.2）。

**R4 逐味选批。** 每味按 `expiry_date ASC` 选批；`EXPIRED` / `LOCKED` 跳过；同一味可跨批次扣减。

**R5 库存不足整方拒绝。** 任一味不足 → 整张处方拒绝调剂（E3050），避免"配了一半"。

**R6 毒性饮片单独标记。** 毒性饮片出库流水带 `is_toxic` 标记，便于追溯（与 F113 的提醒形成闭环）。

**R7 与成药链路同构。** 同样写流水、同样受盘点冻结限制、同样可退药（F46 R6）。

**R8 同事务。** 库存扣减 + 流水 + `herb_dispense` 在同一事务（R-M07-2）。

---

## 5. 验收标准

**AC1（按付数扣减）**
- Given 处方 7 付，黄芪 15g/付
- When 调剂
- Then 黄芪扣减 105 g
- 验证方式：自动

**AC2（损耗率生效）**
- Given 损耗率 20‰，剂量 10g × 7 付
- When 调剂
- Then 扣减 `round(70 × 1.02) = 71` g
- 验证方式：自动

**AC3（付数变更重算）**
- Given 付数由 7 改为 14
- When 重新调剂计算
- Then 扣减量为原值 ×2（重算而非缩放）
- 验证方式：自动

**AC4（库存不足整方拒绝）**
- Given 其中一味库存不足
- When 调剂
- Then 拒绝 E3050，其余味均未扣减
- 验证方式：自动

**AC5（以克存储）**
- Given 入库 5kg
- When 查 `herb_stock`
- Then `qty_g=5000`
- 验证方式：自动

**AC6（毒性饮片标记）**
- Given 处方含毒性饮片
- When 调剂
- Then 流水带 `is_toxic=1`
- 验证方式：自动

**AC7（崩溃一致）**
- Given 调剂事务中途强杀
- When 重启
- Then 各味扣减与流水一致
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3050 | 饮片库存不足 | 否 |
| E3051 | 批次不可用 | 否 |
| E3059 | 损耗率配置非法（负数或过大） | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 调剂中途崩溃 | 事务回滚，可重新调剂 |
| 损耗率配置错误 | 拒绝并提示修正配置，不静默按 0 处理 |
