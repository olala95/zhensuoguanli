# F40 入库

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

登记药品与饮片的采购入库：选择供应商 → 录入明细（品目 / 数量 / 单价 / 批号 / 效期）→ 确认后生成批次与库存，并写库存流水。

---

## 2. 依赖

- 依赖：M06（`drug` / `herb` 资料，只读）、M14（配置）、M12（审计）
- 被依赖：F41（批次）、F42（库存）、F43（流水）、M15 F121（进销存期初/入库）

---

## 3. 涉及的表

`supplier`、`stock_in`、`stock_batch`、`stock`、`herb_stock`、`stock_transaction`（均 M07 自有）

---

## 4. 规则

**R1 单号与状态。** 入库单号 `IN{yyyyMMdd}{4位}`（契约 §1.2），事务内取号；状态 `DRAFT → CONFIRMED | VOID`，确认前可改，确认后只能作废（E3058）。

**R2 一个明细行 = 一个批次。** 明细行不单独编号，用 `stock_in_id + line_no` 定位（契约 §1.3）；确认时每行生成一个 `BT{yyyyMMdd}{6位}` 批次内码。

**R3 供应商批号原样保存。** `supplier_batch_no` 保留供应商原始批号，与系统批次内码**区分**（契约 §1.2）。

**R4 效期必填。** 成药与饮片批次必须登记效期；临入库已过期 → 拒绝（E2002）。

**R5 成本以毫元计。** `unit_cost_milli`（毫元/单位），金额 `amount_fen = round(qty × unit_cost_milli / 10)`（契约 §3，R-M07-10）。

**R6 饮片按克存储。** 可按 kg 录入（`input_unit='KG'`），系统 ×1000 换算为 g（R-M07-5）。

**R7 确认即生效。** 确认动作在**同一事务**内完成：写批次 → 增库存 → 写流水 → 写状态日志（R-M07-2）。

**R8 供应商档案。** 供应商不存在时可先建档（`supplier`），记录名称、联系人、电话、许可证号。

## 5. 验收标准

**AC1（建档入库单）**
- Given 供应商"康美药业"，含成药 A 100 盒（成本 8.50 元/盒）与饮片"黄芪"5kg
- When 确认入库
- Then 生成 1 张 `IN` 单 + 2 个批次，`stock.qty=100`、`herb_stock.qty_g=5000`
- 验证方式：自动

**AC2（批次内码与供应商批号分离）**
- Given 明细行供应商批号为 `KM2026A`
- When 确认
- Then `stock_batch.batch_no` 形如 `BT{yyyyMMdd}{6位}`，`supplier_batch_no='KM2026A'`
- 验证方式：自动

**AC3（效期缺失被拒）**
- Given 明细行未填效期
- When 确认
- Then 拒绝 E2002
- 验证方式：自动

**AC4（kg 换算）**
- Given 饮片按 5kg 录入
- When 确认
- Then `qty_g = 5000`
- 验证方式：自动

**AC5（金额精度）**
- Given 成本 8.555 元 × 100
- When 计算流水金额
- Then `amount_fen = 85550`（先按毫元乘后 ROUND_HALF_UP 到分）
- 验证方式：自动

**AC6（确认后不可改）**
- Given 入库单已 CONFIRMED
- When 修改明细
- Then 拒绝 E3058
- 验证方式：自动

**AC7（流水可追溯）**
- Given 入库已确认
- When 查 `stock_transaction WHERE ref_type='STOCK_IN'`
- Then 每个明细行一条正向流水，含 `batch_id / qty_change / balance_after / amount_fen`
- 验证方式：自动

**AC8（崩溃一致性）**
- Given 确认入库事务执行中强杀进程
- When 重启
- Then 批次、库存、流水要么全在要么全不在，不出现"有库存无流水"
- 验证方式：自动（故障演练 #3 同源）

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001/E2002 | 明细必填缺失 / 效期非法或已过期 | 否 |
| E3058 | 入库单已确认/已作废不可修改 | 否 |
| E3001 | 状态非法转换 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 确认中途断电 | 事务回滚，重启后可重新确认（单号保留，允许跳号） |
| 供应商不存在 | 引导先建档，不静默创建 |
| 磁盘写满 | E1002 明确报出，单据保持 DRAFT |
