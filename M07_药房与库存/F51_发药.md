# F51 发药

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

成药（含颗粒）发药：按处方明细逐行选批扣减库存，生成发药记录与出库流水，并把处方推进到 `DISPENSED`。

---

## 2. 依赖

- 依赖：M06（`prescription` / `prescription_item`，状态 CONFIRMED）、F41（批次选批）、F43（流水）
- 被依赖：M09（收费后发药）、M10（药袋标签 F69）、M15 F122

---

## 3. 涉及的表

`dispense`、`stock_transaction`、`stock`、`stock_batch`（均 M07 自有；`prescription` 状态经 M06 接口回写）

---

## 4. 规则

**R1 前置：处方必须已确认且未发药。** `CONFIRMED` 才可发药；已 `DISPENSED` 重复发药拒绝（E3055）。

**R2 扣减量 = 明细数量。** 逐行按 `prescription_item.quantity` 扣减（拆零单位由 `pack_qty` 换算，见 F44/F45）。

**R3 选批规则：近效期优先。** 默认 `expiry_date ASC`；`EXPIRED` / `LOCKED` / `DEPLETED` 批次自动跳过（R-M07-3，F49 R4）。可显式指定批次（药师手工选批）。

**R4 库存不足整单拒绝。** 任一行可用量不足 → 整单拒绝 E3050，**不做部分发药**（避免账实不一致与后续退费复杂度）。

**R5 同事务四件事。** 写 `dispense` → 写负流水 → 减 `stock.qty` → 调 `m06_prescription.mark_dispensed()`，**全部在一个 `db.tx()`**（R-M07-2 / R-M07-7）。

**R6 批次归零转 DEPLETED。** 扣减后 `qty_remain = 0` → 批次转 `DEPLETED` 并写状态日志。

**R7 发药记录可追溯。** `dispense` 记录处方、患者、操作人、`occurred_at`；每行流水带 `ref_line_id` 指向处方明细行。

**R8 幂等。** 同一处方重复提交（`idempotent_key`）不产生第二批发药与二次扣减。

**R9 药师权限。** 仅 PHARMACIST / ADMIN / DOCTOR（兼岗）可执行，写 `audit_operation`。

---

## 5. 验收标准

**AC1（正常发药）**
- Given 处方已确认，含药品 A 2 盒，批次有货
- When 发药
- Then `dispense` 生成、库存 -2、负流水 1 条、处方 `DISPENSED`
- 验证方式：自动

**AC2（未确认不能发药）**
- Given 处方 PENDING
- When 发药
- Then 拒绝 E3001
- 验证方式：自动

**AC3（重复发药被拒）**
- Given 处方已 DISPENSED
- When 再次发药
- Then 拒绝 E3055
- 验证方式：自动

**AC4（库存不足整单拒绝）**
- Given 两行明细，其中一行库存不足
- When 发药
- Then 整单拒绝 E3050，库存无任何变化
- 验证方式：自动

**AC5（近效期优先）**
- Given 批次甲效期 2026-12、批次乙 2027-06
- When 自动选批发药
- Then 扣减批次甲
- 验证方式：自动

**AC6（批次归零转态）**
- Given 批次剩余恰好等于发药量
- When 发药
- Then 批次 `DEPLETED`，状态日志完整
- 验证方式：自动

**AC7（崩溃一致性）**
- Given 发药事务执行中强杀进程
- When 重启
- Then 库存扣减与发药记录一致，不出现少扣或多扣
- 验证方式：自动（故障演练 #3）

**AC8（幂等重提）**
- Given 同一处方带相同幂等键提交两次
- When 第二次
- Then 只扣一次库存
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3050 | 库存不足 | 否 |
| E3055 | 处方已发药，不可重复发药 | 否 |
| E3051 | 指定批次不可用（过期/冻结/耗尽） | 否 |
| E3001 | 处方状态不允许发药 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 发药中途断电 | 事务回滚；重启后重新发药，库存未被扣减 |
| 部分行失败 | 整单回滚，不做部分发药 |
| 处方回写失败 | 同事务回滚，库存不扣 |
