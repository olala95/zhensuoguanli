# M07 药房与库存 · 验收

> 本文只写**跨 F 的端到端场景与故障演练**，单 F 内部的 AC 见各 `Fxx.md`，不重复。

## 1. 端到端场景

### S1 成药全链路（入库 → 发药 → 退药）

```
建档药品 → 入库（F40）生成批次 → 医生开方确认（M06）→ 药师发药（F51）
   → 库存扣减 + 流水 + 处方转 DISPENSED
   → 部分退药（F46）→ 回原批次 + 处方转 PARTIAL_RETURNED
   → 全部退完 → FULLY_RETURNED
```

**判定**：
- [ ] 每个环节都有对应的 `stock_transaction`，`ref_type/ref_id/ref_line_id` 可反查到单据
- [ ] 任一时刻 `Σ 流水 qty_change` = `stock.qty`
- [ ] 退药量始终 ≤ 已发未退量
- [ ] 处方状态由 M06 状态机推进，M07 未直接 UPDATE `prescription`

### S2 中药全链路（入库 → 调剂 → 代煎发药）

```
饮片建档 → 按 kg 入库换算为 g（F40）→ 饮片处方 7 付确认（M06 F111/F112）
   → 中药发药代煎（F115）→ 各味按 剂量×付数×(1+损耗‰) 扣减（F114）
   → 记录代煎费、包装数、预计可取时间
```

**判定**：
- [ ] `herb_stock.qty_g` 单位恒为克
- [ ] 扣减量 = 剂量 × 付数（含损耗率），付数变更后重算而非缩放
- [ ] 颗粒处方走成药链路，但仍带中医证型信息

### S3 盘点闭环（冻结 → 录入 → 差异 → 审批）

```
建盘点单（F48.1）→ COUNTING，批次 LOCKED → 期间发药/报损/退药被拒（E3051）
   → 录入实盘（F48.2）→ ADJUSTING → 逐行标记调整（F48.3）
   → 审批（F48.4）→ 生成调整流水 + 解锁
```

**判定**：
- [ ] 冻结期间所有库存变动被拒并留痕
- [ ] 未标记调整的行不产生流水
- [ ] 审批后库存 = 实盘数，差异金额可按批次成本汇总

### S4 效期与预警

```
入库登记效期 → 扫描（F49）→ 近效期预警 → 到期自动 EXPIRED
   → EXPIRED 批次禁止销售出库，但允许报损（F47）
   → 库存低于安全线 → LOW_STOCK 预警（F50），补货后自动关闭
```

**判定**：
- [ ] 预警幂等，重复扫描不产生重复行
- [ ] 发药自动选批遵循近效期优先
- [ ] 过期批次销售出库被拒、报损放行

### S5 跨模块：发药 → 收费 → 退药退款

```
发药（F51/F115）→ M09 生成账单收费（只读处方与发药记录）
   → 患者退药（F46）→ M09 F63 按退药明细退款
```

**判定**：
- [ ] M09 只读 M07 数据，未直写 M07 表
- [ ] 退药退款金额 = 退药明细按开方时价计算的金额
- [ ] 退药与退款在同一业务流程内可追溯（退药单号 ↔ 退款单号）

## 2. 故障演练

| # | 场景 | 期望 |
|---|---|---|
| M7-1 | 发药事务执行中强制断电 | 重启后库存扣减与发药记录一致，**不出现少扣或多扣**；未提交部分整体回滚 |
| M7-2 | 入库确认中途断电 | 批次、库存、流水要么全在要么全不在，不出现"有库存无流水" |
| M7-3 | 盘点审批中途断电 | 事务回滚，批次保持 LOCKED，可重新审批且幂等 |
| M7-4 | 退药回库时原批次已 DEPLETED | 批次复活为 NORMAL 后回库，状态日志完整 |
| M7-5 | 尝试修改/删除库存流水 | 数据库触发器拒绝 E2006，只能新增反向流水 |
| M7-6 | 同一发药请求重复提交（幂等键） | 只扣一次库存，不产生第二批发药记录 |
| M7-7 | 库存不足时发药 | 整单拒绝 E3050，无任何部分扣减 |
| M7-8 | 盘点冻结期间发药 | 拒绝 E3051，提示盘点结束后重试 |
