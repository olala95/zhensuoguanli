# F115 中药发药（代煎/自煎）

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

中药处方的调配发药：按付数调剂出库（F114）、记录代煎/自煎方式、包装与代煎费、生成取药凭证信息。

---

## 2. 依赖

- 依赖：M06（`prescription` 含 `doses` / `is_decoction` / `decoction_method` / `administration`）、F114（调剂出库）、F112（计价）
- 被依赖：M09（收费）、M10（药袋标签与饮片方打印 F67/F69）、M15 F122

---

## 3. 涉及的表

`herb_dispense`、`stock_transaction`、`herb_stock`、`stock`（颗粒走成药链路）

---

## 4. 规则

**R1 前置同 F51。** 处方必须 `CONFIRMED`；已发药不可重复（E3055）。

**R2 发药方式三选一。** `自煎 / 代煎 / 颗粒`：
- 自煎、代煎 → 走饮片调剂（F114）；
- **颗粒** → 按成药链路计价与出库（契约 §8：颗粒按袋/盒计），但仍记录中医诊断与证型。

**R3 必填项（契约 §8）。** 发药前校验：付数、煎法、服法、每味脚注齐备；缺失 → 拒绝（与 F111 同一组必填校验）。

**R4 代煎费与包装费。** 取 F112 计价结果：`decoction_fee_fen`（按付数或按处方，由配置决定）与 `package_fee_fen`，写入 `herb_dispense`。

**R5 包装数量。** 代煎按付数分袋（`packs = doses`）；自煎按味分包。

**R6 取药凭证。** 记录取药人、取药时间、代煎预计可取时间（代煎场景）。

**R7 同事务。** 出库 + 流水 + `herb_dispense` + 处方状态回写（`mark_dispensed`）同一事务（R-M07-2/R-M07-7）。

**R8 处方状态回写走接口。** 调 `m06_prescription.mark_dispensed()`，禁止裸 UPDATE。

---

## 5. 验收标准

**AC1（自煎发药）**
- Given 饮片处方 7 付、煎法服法脚注齐备
- When 自煎发药
- Then 各味按 7 付扣减，`herb_dispense.decoction_type='ZIJIAN'`，处方 `DISPENSED`
- 验证方式：自动

**AC2（代煎发药）**
- Given 代煎处方
- When 发药
- Then `decoction_type='DAIJIAN'`，记录代煎费与预计可取时间
- 验证方式：自动

**AC3（颗粒走成药链路）**
- Given 颗粒处方
- When 发药
- Then 按袋/盒出库（走 `stock` 而非 `herb_stock`）
- 验证方式：自动

**AC4（必填缺失被拒）**
- Given 缺煎法
- When 发药
- Then 拒绝 E2001
- 验证方式：自动

**AC5（代煎费按付数）**
- Given 代煎费 300 分/付，7 付
- When 发药
- Then `decoction_fee_fen=2100`
- 验证方式：自动

**AC6（重复发药被拒）**
- Given 已 DISPENSED
- When 再次发药
- Then 拒绝 E3055
- 验证方式：自动

**AC7（崩溃一致）**
- Given 发药事务中途强杀
- When 重启
- Then 饮片库存与发药记录一致
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 付数/煎法/服法/脚注缺失 | 否 |
| E3055 | 已发药不可重复 | 否 |
| E3050 | 饮片库存不足 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 发药中途崩溃 | 事务回滚，重新发药 |
| 代煎费配置缺失 | 按 0 计并 warn 日志，不阻断发药（费用可后续冲正） |
