# F71 打印失败恢复

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

打印失败的分类、重试、放弃与告警：区分**可重试**（离线/缺纸/Agent 不可达）与**不可重试**（模板缺失/渲染失败），并在超限时给出明确结论。

---

## 2. 依赖

- 依赖：F66（任务与状态机）、F72（Hardware Agent 状态）、M12
- 被依赖：F70、M14 健康检查

---

## 3. 涉及的表

`print_failure`、`print_job`、`print_status_log`

---

## 4. 规则

**R1 失败即留痕。** 每次失败写 `print_failure`：`error_code`、`message`、`retryable`、`attempt_no`、`occurred_at`。

**R2 分类（03 §6）。** E4xxx（硬件）与 E7xxx（打印）中除模板缺失外一律 `retryable=true`；`E7001 模板缺失` 为 `retryable=false`（重试没用，需先补模板）。

**R3 自动重试 + 上限。** 可重试失败进入 `RETRYING`，自动再次 `PRINTING`；超过 `print.max_retry`（默认 3）→ `ABANDONED`。

**R4 放弃写高风险审计。** 凭证缺失是风险事件（患者可能拿不到处方/凭条），写 `audit_high_risk` 并在健康检查中可见。

**R5 人工放弃。** 操作员可主动放弃（如换打印机），需填原因。

**R6 不阻塞业务（R-M10-6）。** 打印失败**绝不回滚**已确认的处方、已收的款、已扣的库存。

**R7 失败可查询。** 按任务、业务单据、时间区间查失败记录，便于排查硬件问题。

---

## 5. 验收标准

**AC1（可重试失败进入 RETRYING）**
- Given 打印机离线（mock）
- When 执行
- Then 状态 FAILED → RETRYING，`print_failure` 有记录，`retryable=true`
- 验证方式：自动（mock）

**AC2（超限放弃）**
- Given 重试次数已达 `max_retry`
- When 再次失败
- Then 状态 ABANDONED，写高风险审计
- 验证方式：自动

**AC3（模板缺失不可重试）**
- Given 模板不存在
- When 创建任务
- Then 拒绝 E7001，`retryable=false`
- 验证方式：自动

**AC4（失败不回滚业务）**
- Given 发药后打印失败
- When 查处方与库存
- Then 处方仍 DISPENSED、库存已扣（不回滚）
- 验证方式：自动

**AC5（人工放弃需原因）**
- Given 未填原因放弃
- When 提交
- Then 拒绝 E2001
- 验证方式：自动

**AC6（失败可查询）**
- Given 产生 2 条失败
- When 按任务查询
- Then 返回 2 条含错误码与尝试次数
- 验证方式：自动

**AC7（恢复后可重打成功）**
- Given 任务 ABANDONED，mock 驱动恢复
- When 重打
- Then 可成功输出
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E4001 | 打印机离线/缺纸 | 是 |
| E4002 | Hardware Agent 不可达 | 是 |
| E7001 | 模板缺失 | 否 |
| E7002 | 渲染失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 离线/缺纸 | 处理后重打，任务保留 |
| Agent 崩溃 | F98 看门狗拉起后重打 |
| 放弃 | 人工重打或改用其他打印机 |
