# F69 药袋标签

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

打印药袋标签：患者姓名、用法用量、药品名称与数量；中药另需付数、煎法、服法、代煎/自煎与预计可取时间。

---

## 2. 依赖

- 依赖：F66、M06（处方与明细）、M07（`herb_dispense` 代煎/自煎、可取时间）、M03（过敏史提示）
- 被依赖：M07 发药后打印、UI

---

## 3. 涉及的表

只读：`prescription`、`prescription_item`、`herb_prescription_item`、`herb_dispense`、`patient`；
写入：`print_job`

---

## 4. 规则

**R1 一张处方一个标签。** 成药标签列全部发药明细；中药标签列付数与煎服法。

**R2 用法必出。** 成药：单次用量 + 频次 + 途径；缺失 → 渲染失败 E7002（用药安全）。

**R3 中药标签要素。** 付数、煎法、服法、代煎/自煎、预计可取时间（代煎场景）。

**R4 过敏提示。** 若患者有过敏史（M03），标签末尾打印"过敏史提示"行（提醒，不阻断）。

**R5 患者标识。** 姓名 + 性别/年龄 + 处方号（或就诊号），便于核对发药。

**R6 已发药才打印。** 处方未发药时拒绝（E3001）——标签是随药走的。

---

## 5. 验收标准

**AC1（成药标签）**
- Given 已发药处方，含"1片 tid 口服"
- When 打印标签
- Then 文本含药名、数量、用法、患者姓名
- 验证方式：自动（mock）

**AC2（中药标签含煎服法）**
- Given 中药代煎发药，7 付
- When 打印
- Then 含付数 7、煎法、服法、代煎、可取时间
- 验证方式：自动

**AC3（用法缺失拒绝）**
- Given 成药明细缺用法
- When 打印
- Then 拒绝 E7002
- 验证方式：自动

**AC4（过敏提示）**
- Given 患者有青霉素过敏史
- When 打印
- Then 标签含过敏提示行
- 验证方式：自动（跨 M03）

**AC5（未发药拒绝）**
- Given 处方 CONFIRMED 未发药
- When 打印标签
- Then 拒绝 E3001
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3001 | 处方未发药 | 否 |
| E7002 | 用法缺失导致渲染失败 | 是 |
