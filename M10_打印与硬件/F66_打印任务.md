# F66 打印任务

[TYPE: SERVICE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

打印的**唯一入口与事实来源**：创建任务（含模板选择、数据快照、渲染固化）→ 排队 → 执行 → 记录结果。所有打印（处方笺/凭条/标签）都必须经过本服务。

---

## 2. 依赖

- 依赖：`print_template`（F67/F68/F69 的模板）、`core/hardware.py` 驱动、M14（诊所信息配置）
- 被依赖：F67/F68/F69/F70/F71、M06/M07/M09 的打印调用

---

## 3. 涉及的表

`print_job`、`print_status_log`、`print_failure`、`print_template`

---

## 4. 规则

**R1 单号 `PJ{yyyyMMddHHmmss}{3位}`**（契约 §1.2），含时间戳便于重打印定位；事务内取号。

**R2 创建即渲染。** 任务创建时把业务数据快照渲染成文本并**固化到 `rendered_text`**（R-M10-2）。重打时用这份固化结果，**不重新取数**——保证重打件与原件一致，且上游单据后续变更不影响已出的凭证。

**R3 状态机（契约 §2.7）。** `PENDING → PRINTING → SUCCESS | FAILED`；`FAILED → RETRYING → PRINTING`；`FAILED → ABANDONED`。每次转换写 `print_status_log`。

**R4 幂等。** `idempotent_key` 相同且任务尚未终态时，返回已存在任务，不重复排队（R-M10-10）。

**R5 执行器与驱动分离。** 任务执行器只负责状态流转与记录，实际输出交给 `hardware.print()`；驱动失败 → FAILED + `print_failure`（R-M10-5）。

**R6 重试上限。** `print.max_retry`（默认 3）；超限 → `ABANDONED` + 高风险审计（R-M10-7）。

**R7 审计。** 创建、重打印、放弃均写 `audit_operation`；放弃（凭证缺失）写 `audit_high_risk`。

**R8 任务可查询。** 支持按业务单据（`biz_type` + `biz_id`）、状态、时间区间查询。

## 5. 验收标准

**AC1（创建任务并固化渲染结果）**

- Given 一张已确认处方
- When 创建打印任务
- Then 生成 `PJ` 单号，`rendered_text` 非空，状态 PENDING
- 验证方式：自动

**AC2（单号格式）**

- Given 创建任务
- When 查单号
- Then 形如 `PJ{yyyyMMddHHmmss}{3位}`
- 验证方式：自动

**AC3（幂等）**

- Given 相同 `idempotent_key` 提交两次
- When 第二次
- Then 不产生第二个任务
- 验证方式：自动

**AC4（执行成功）**

- Given 任务 PENDING，mock 驱动正常
- When 执行
- Then 状态 SUCCESS，有 `printed_at`
- 验证方式：自动（mock）

**AC5（驱动失败转 FAILED）**

- Given mock 驱动配置为失败
- When 执行
- Then 状态 FAILED，写 `print_failure`，异常码 E4001/E7002
- 验证方式：自动（mock）

**AC6（状态日志完整）**

- Given 一次 成功/失败 全流程
- When 查 `print_status_log`
- Then 每次转换都有记录
- 验证方式：自动

**AC7（渲染结果不被上游变更影响）**

- Given 任务已创建，之后处方金额被改
- When 重打
- Then 打印内容与首次一致（用固化文本）
- 验证方式：自动

**AC8（超限放弃）**

- Given 重试次数已达上限
- When 再次重试
- Then 状态 ABANDONED，写高风险审计
- 验证方式：自动

## 6. 异常码

| 码     | 场景                 | 可重试 |
| ----- | ------------------ | --- |
| E7001 | 模板缺失               | 否   |
| E7002 | 渲染失败（数据缺字段）        | 是   |
| E4001 | 打印机离线/缺纸           | 是   |
| E4002 | Hardware Agent 不可达 | 是   |

---

## 7. 失败恢复

| 失败点     | 恢复方式                                        |
| ------- | ------------------------------------------- |
| 创建任务中断电 | 事务回滚，任务不存在，业务不受影响                           |
| 执行中崩溃   | 任务停在 PRINTING；重启后由 F96 崩溃恢复标记为 FAILED 并允许重打 |
| 驱动不可用   | 任务 FAILED，**业务不回滚**（R-M10-6），提示稍后重打         |
