# F22 医疗事实提取

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

从转写文本（或医生直接输入的文本）中提取结构化医疗事实：症状、持续时间、既往史、用药史、生命体征、过敏信息、家族史等。

---

## 2. 依赖

- 依赖：F21（转写文本）、F26（任务管理）、M14（配置）
- 被依赖：F23（草稿生成的输入）、F25（风险提醒可基于提取的事实）

---

## 3. 涉及的表

`ai_task`、`ai_fact`（M04 自有）

---

## 4. 规则

**R1 提取结果结构化。** 输出为标准事实类型：症状/体征、持续时间、程度、诱因、缓解因素、既往病史、用药史、过敏、手术史、家族史、生活习惯。

**R2 提取结果必须可审核。** 每条事实标注：
- 来源文本片段（可追溯到原话）
- 置信度
- 医生可逐条**采纳 / 修改 / 丢弃**

**R3 不得臆测。** 文本中未提及的事实**不得生成**。宁可少提不可编造。

**R4 过敏信息高优先级。** 提取到疑似过敏信息时**重点标注**，提示医生核实并录入 F13 过敏史（安全红线）。

**R5 数值型事实结构化。** 体温、血压、天数等提取为数值 + 单位，便于落入 F14 生命体征。

**R6 否定识别。** 必须正确处理否定表达（"没有发烧" ≠ "发烧"）。**否定识别错误是本功能最危险的失败模式。**

**R7 不生成诊断/证型/舌脉。** 诊断结论、中医证型、舌象脉象**不在提取范围内**（R-M04-3），只能由医生填写。

**R8 结果入库留痕。** `ai_fact` 保存提取结果与医生审核结果（采纳/修改/丢弃），便于回溯 AI 表现。

**R9 失败可降级。** 提取失败不影响医生手工填写病历。

---

## 5. 验收标准

**AC1（症状提取）**
- Given 转写文本"我咳嗽三天了，还有点发烧"
- When 执行提取
- Then 提取出症状"咳嗽"持续"3天"、"发热"，各条含来源片段与置信度
- 验证方式：自动（mock 提取服务）

**AC2（可审核）**
- Given 提取出 5 条事实
- When 医生逐条操作
- Then 可采纳/修改/丢弃，操作结果入库留痕
- 验证方式：自动

**AC3（不臆测）**
- Given 文本中未提及任何既往病史
- When 执行提取
- Then 不生成任何既往病史事实
- 验证方式：自动

**AC4（否定识别）**【关键】
- Given 文本"我没有发烧，也不咳嗽"
- When 执行提取
- Then **不生成**"发热""咳嗽"症状事实；正确识别为否定
- 验证方式：自动

**AC5（过敏重点标注）**
- Given 文本"我对青霉素过敏"
- When 执行提取
- Then 提取为过敏事实并**重点标注**，提示医生核实录入 F13
- 验证方式：自动

**AC6（数值结构化）**
- Given 文本"体温三十八度五"
- When 执行提取
- Then 提取为数值 38.5 + 单位 ℃
- 验证方式：自动

**AC7（不生成诊断与舌脉）**
- Given 文本中医生说了"舌红苔黄，脉弦"
- When 执行提取
- Then **不生成**舌象/脉象事实（这些归 F108，只能医生填）；也不生成诊断结论
- 验证方式：自动

**AC8（失败降级）**
- Given 提取服务不可用
- When 触发提取
- Then 任务 FAILED，医生可手工填写，不阻塞
- 验证方式：自动（mock 失败）

**AC9（崩溃恢复）**
- Given 提取任务执行中强杀
- When 重启
- Then 任务状态明确，可重试；无重复事实
- 验证方式：自动

**AC10（基于修正文本重提）**
- Given 医生修正了转写文本
- When 重新提取
- Then 基于修正文本，结果随之更新，旧结果保留可对比
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E5001 | 网络不可达 | 是 |
| E5003 | 提取超时 | 是 |
| E5004 | 返回不可解析 | 是 |
| E5006 | 提取服务返回内容不合规 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 服务失败 | FAILED + 可重试；医生可手工填写 |
| 部分事实提取失败 | 已成功的事实保留可用；失败部分可单独重试 |
| 崩溃 | 由 F26 管理状态与重试 |
