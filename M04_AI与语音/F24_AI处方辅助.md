# F24 AI 处方辅助

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: M]

---

## 1. 职责

基于诊断与病历内容，给出候选药品/饮片建议，供医生参考采纳。

**本功能只能"建议"，其产出必须经 M06 处方的完整规则校验与医生确认。**

---

## 2. 依赖

- 依赖：M03（诊断、辨证）、M06（药品资料与处方规则，**通过接口**）、F26
- 被依赖：M06 F34 / F111（医生采纳后进入处方）

---

## 3. 涉及的表

`ai_task`、`ai_suggestion`（M04 自有）
**只读** `drug` / `herb`（M06 所有，通过接口）

---

## 4. 规则

**R1 只建议不写入。** AI 建议只存 `ai_suggestion`，**不写入 `prescription`**。医生采纳后走 M06 的正常开方流程。

**R2 建议必须匹配真实药品。** 建议中的药品名必须能匹配到系统药品库（F32/F110 资料）中的实际药品；匹配不到则**不显示该条建议**（避免建议了诊所没有的药）。

**R3 库存校验。** 建议时检查库存可用性；缺货药品标注"库存不足"或不建议。

**R4 必须走完整规则校验。** 医生采纳建议后，该处方**必须完整走 M06 的规则校验**（F35/F113）：过敏、配伍禁忌、剂量上限、皮试要求等。**AI 建议不豁免任何规则。**

**R5 中医方剂建议需含辨证依据。** 若给出中药方建议，必须同时给出对应证型依据（来自 F109），且治法方向需一致。

**R6 不推荐抗生素与注射剂优先。** 建议排序不得系统性优先推荐抗生素或注射剂（避免滥用引导）。

**R7 剂量建议明确。** 建议含剂量与用法；医生必须确认剂量，不可一键全盘采用。

**R8 建议来源留痕。** 采纳的建议在处方中标记来源（AI 建议 + 医生采纳），便于回溯。

**R9 失败降级。** 建议服务不可用 → 医生正常手工开方，不阻塞。

---

## 5. 验收标准

**AC1（生成建议）**
- Given 诊断为 J06.9，药品库有对应药品
- When 触发建议
- Then `ai_suggestion` 生成候选，含药品、剂量、用法建议
- 验证方式：自动（mock 建议服务）

**AC2（不写处方表）**【关键】
- Given 建议已生成
- When 检查 `prescription`
- Then 无任何记录；医生采纳后才走 M06 开方流程
- 验证方式：自动（跨模块）

**AC3（必须匹配真实药品）**
- Given 建议中的药品名在药品库中不存在
- When 展示建议
- Then 该条**不展示**（不允许建议诊所没有的药）
- 验证方式：自动

**AC4（库存校验）**
- Given 某药品库存为 0
- When 生成建议
- Then 该药品标注库存不足或不列出
- 验证方式：自动

**AC5（采纳后走完整规则校验）**【关键】
- Given 患者对某药过敏，AI 恰好建议了该药
- When 医生采纳
- Then M06 规则校验**强制拦截**（不因是 AI 建议而豁免）
- 验证方式：自动（跨模块，需 M06 配合）

**AC6（中医建议含辨证依据）**
- Given 证型为"风热犯肺"，治法"疏风清热"
- When 给出中药建议
- Then 建议附辨证依据，且方药方向与治法一致；方向不符时给出提醒
- 验证方式：自动（跨模块，需 M06/F113 配合）

**AC7（不优先推荐抗生素/注射剂）**
- Given 生成建议列表
- When 检查排序
- Then 抗生素与注射剂不因 AI 建议而被系统性前置
- 验证方式：自动

**AC8（采纳留痕）**
- Given 医生采纳某条建议
- When 查看处方
- Then 标记来源为"AI 建议 + 医生采纳"，采纳人可追溯
- 验证方式：自动

**AC9（失败降级）**
- Given 建议服务不可用
- When 开方
- Then 医生可正常手工开方，界面提示建议不可用但不阻塞
- 验证方式：自动

**AC10（崩溃恢复）**
- Given 建议任务执行中强杀
- When 重启
- Then 任务状态明确可重试；无重复建议
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E5001 | 网络不可达 | 是 |
| E5003 | 建议生成超时 | 是 |
| E5006 | 建议内容不合规（如含库存外药品） | 是 |
| E6006 | 尝试未经确认直接写入处方 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 服务失败 | FAILED + 可重试；降级手工开方 |
| 匹配不到药品 | 丢弃该条建议，保留其余 |
| 崩溃 | F26 管理任务状态 |

---

## 8. 契约缺口

- 需 M06 提供"药品可开方性校验"接口（是否存在、是否停用、库存是否充足），契约在 M06 开发时冻结。
