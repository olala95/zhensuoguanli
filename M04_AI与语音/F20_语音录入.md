# F20 语音录入

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

在接诊过程中录制医患对话，保存录音文件并触发后续 ASR 转写。

---

## 2. 依赖

- 依赖：M02（Visit 上下文）、M14（配置：录音存储路径、是否允许上传）、F21（转写）
- 被依赖：F21

---

## 3. 涉及的表

`ai_audio`（M04 自有）

---

## 4. 规则

**R1 录音需明确启动。** 录音由医生**显式点击开始**，不在接诊时自动录音（隐私与合规）。界面有明确录音中指示。

**R2 录音中不影响其他操作。** 录音期间医生可继续写病历、开处方，不阻塞界面。

**R3 录音文件本地存储。** 默认存本地 `attachments/audio/`，路径可配。文件名含 Visit ID 与时间戳。

**R4 录音可停止、暂停、重录。** 支持中途暂停续录；支持放弃重录（旧文件保留标记废弃，不物理删除直至清理策略执行）。

**R5 录音元数据入库。** `ai_audio` 记录：Visit ID、文件路径、时长、采样信息、开始/结束时间、操作人。

**R6 上传需配置开启。** 若 ASR 服务在云端，上传前需配置 `ai.allow_upload=1`；**默认关闭**，关闭时使用本地 ASR 或不可用则降级手工（R-M04-4）。

**R7 录音与患者绑定。** 录音归属 Visit，患者合并（M01 F04）时录音随之改挂。

**R8 录音不进诊断包。** F104 诊断包导出时**不含录音文件**（体积与隐私）。

**R9 设备不可用不阻塞。** 麦克风不可用 → 提示，医生可继续手工录入。

**R10 录音失败可恢复。** 录音过程中崩溃：已写入的部分可恢复（分段写文件），并记录中断点。

## 5. 验收标准

**AC1（开始录音）**
- Given 接诊中，麦克风可用
- When 点击开始录音
- Then 界面显示录音中指示与计时，文件开始写入本地
- 验证方式：自动（mock 麦克风）

**AC2（暂停与续录）**
- Given 录音中
- When 暂停 30 秒后继续
- Then 录音文件连续，时长不含暂停段（或明确标记暂停段）
- 验证方式：自动

**AC3（停止并入库）**
- Given 录音 2 分钟
- When 点击停止
- Then 文件保存，`ai_audio` 记录完整（Visit、路径、时长、操作人）
- 验证方式：自动

**AC4（录音中不阻塞操作）**
- Given 录音进行中
- When 医生同时写病历
- Then 病历编辑正常，录音继续不受影响
- 验证方式：自动

**AC5（麦克风不可用降级）**
- Given 麦克风不可用或权限被拒
- When 点击录音
- Then 明确提示，医生可继续手工录入，**不阻塞接诊**
- 验证方式：自动（mock 失败）

**AC6（上传配置默认关闭）**
- Given 全新系统
- When 检查 `ai.allow_upload`
- Then 默认值为 0（关闭）；开启需管理员显式操作并写 `audit_high_risk`
- 验证方式：自动

**AC7（设备不可用不影响 ASR 已有文本）**
- Given 已有历史录音与转写
- When 麦克风不可用
- Then 历史数据仍可查看与使用
- 验证方式：自动

**AC8（崩溃恢复）**
- Given 录音 1 分钟时强杀进程
- When 重启
- Then 已录部分文件可恢复（或明确标记为未完成），`ai_audio` 状态明确，不产生空文件
- 验证方式：自动

**AC9（录音不进诊断包）**
- Given 系统中有录音文件
- When 导出诊断包（F104）
- Then 包内不含录音文件
- 验证方式：自动（跨模块）

**AC10（患者合并改挂）**
- Given 录音属于患者 A，A 被合并到 B
- When 合并完成
- Then 录音归属 B（通过改挂接口）
- 验证方式：自动（跨模块）

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E4002 | 麦克风不可用/无权限 | 是 |
| E1002 | 磁盘不足无法保存录音 | 是 |
| E5002 | 录音服务异常 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 录音中崩溃 | 分段写盘，重启后恢复已完成片段并明确标记 |
| 磁盘不足 | 提前检查空间；不足时拒绝开始并提示 |
| 设备被拔出 | 检测到设备丢失，自动停止录音并保存已有内容 |
