# F81 封存

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

对已归档病历做**最强冻结**：封存后不得修改、不得再归档；仅管理员可执行，且**管理员无权修改内容**（03 §9）。

---

## 2. 依赖

- 依赖：F79（归档前置）、F80（Hash 校验前置）
- 被依赖：F82（解封）

---

## 3. 涉及的表

`record_seal`、`record`（状态经 M03 服务接口推进 `ARCHIVED → SEALED`）

---

## 4. 规则

**R1 只有 ARCHIVED 可封存。** 未归档拒绝（E3001）；已封存/已解封不可重复封存。

**R2 封存前强制 Hash 校验。** 链校验失败 → 拒绝封存（F80 R6），**不能把可疑病历封存**。

**R3 封存必填理由与时间。** 记录封存原因、封存人（管理员）、时间；写 `audit_operation`。

**R4 封存后禁止修改与再归档。** F77 修改、F79 归档均检查封存标记 → 拒绝（E3001）。

**R5 封存不影响阅读与导出。** 病历仍可查看、可导出（导出不改变内容）。

**R6 状态推进经 M03 接口。** `ARCHIVED → SEALED` 走 M03 `transition()`，**禁止裸 UPDATE**（R5）。

**R7 幂等。** 同一 `idempotent_key` 不重复封存。

---

## 5. 验收标准

**AC1（封存成功）**
- Given 已归档病历
- When 封存
- Then 状态 SEALED，`record_seal` 有记录
- 验证方式：自动

**AC2（未归档不可封存）**
- Given 病历 CONFIRMED 未归档
- When 封存
- Then 拒绝 E3001
- 验证方式：自动

**AC3（Hash 链异常拒绝封存）**
- Given 链被破坏
- When 封存
- Then 拒绝 E3090
- 验证方式：自动

**AC4（封存后禁止修改）**
- Given 已封存
- When 走修改留痕
- Then 拒绝 E3001
- 验证方式：自动

**AC5（封存后仍可阅读导出）**
- Given 已封存
- When 读取/导出
- Then 正常
- 验证方式：自动

**AC6（封存人留痕）**
- Given 管理员封存
- When 查日志
- Then 含操作人与原因
- 验证方式：自动

**AC7（幂等）**
- Given 相同幂等键提交两次
- When 第二次
- Then 不重复封存
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3001 | 状态不允许封存 | 否 |
| E3090 | Hash 链校验失败 | 否 |
| E6002 | 非管理员封存 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 封存事务中断 | 回滚，可重试 |
| 误封存 | 走 F82 解封（写高风险审计），不可直接改状态 |
