# F83 导出

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: S]

---

## 1. 职责

把病历按格式（PDF / HTML / JSON）导出为文件，并**只记录导出事件**（不含内容副本），供患者留存、转诊、监管调阅。

---

## 2. 依赖

- 依赖：F76（版本快照）、F80（Hash 校验）、F79（归档）
- 被依赖：无

---

## 3. 涉及的表

`record_export`（只记录事件，R-M11-8）

---

## 4. 规则

**R1 导出前强制 Hash 校验。** 链校验失败 → **拒绝导出**（E3090）并写 `audit_high_risk`（F80 R6）：不把可疑病历外流。

**R2 只记录事件不落内容副本。** `record_export` 存 `record_id`、`format`、`target_path`、`file_size`、`exported_by`、`exported_at`、`hash_verified`、`idempotent_key`，**不复制病历正文**（R-M11-8，避免第二份事实来源）。

**R3 导出内容取自版本快照。** 以导出时的**最新版本快照**为准（R-M11-7），不实时拼装（否则与版本不一致）。

**R4 格式白名单。** 仅 `PDF` / `HTML` / `JSON`；其他格式拒绝（E2001）。

**R5 封存病历可导出。** 封存只冻结**修改**，不冻结阅读/导出（F81 R5）。

**R6 导出不推进状态。** 导出是纯读操作，不改变 `record` 状态、**不写版本**。

**R7 文件路径可审计。** `target_path` 必须落在配置的导出目录（`config.export_dir`）内，拒绝路径穿越（`..`）与绝对路径外泄（E3092）。

**R8 幂等。** 同一 `idempotent_key` 不重复生成文件、不重复记事件。

**R9 导出事件只读追加。** `record_export` 只允许 INSERT（表级触发器 E2006）。

---

## 5. 验收标准

**AC1（导出成功并记事件）**
- Given 已确认病历
- When 导出 PDF
- Then 生成文件且 `record_export` 有一条记录
- 验证方式：自动

**AC2（不落内容副本）**
- Given 导出完成
- When 检查 `record_export`
- Then 无正文字段，仅路径/格式/大小/时间
- 验证方式：自动

**AC3（Hash 链异常拒绝导出）**
- Given 链被破坏
- When 导出
- Then 拒绝 E3090 并写高风险审计
- 验证方式：自动

**AC4（格式白名单）**
- Given 请求导出 XLSX
- When 执行
- Then 拒绝 E2001
- 验证方式：自动

**AC5（封存可导出）**
- Given 已封存病历
- When 导出
- Then 成功，状态仍 SEALED
- 验证方式：自动

**AC6（导出不改变状态）**
- Given 导出前 ARCHIVED
- When 导出后查状态
- Then 仍 ARCHIVED，版本数不变
- 验证方式：自动

**AC7（路径穿越被拒）**
- Given `target_path` 含 `..`
- When 导出
- Then 拒绝 E3092
- 验证方式：自动

**AC8（内容取自最新快照）**
- Given 病历已到 v3
- When 导出
- Then 文件内容与 v3 快照一致
- 验证方式：自动

**AC9（幂等）**
- Given 相同幂等键提交两次
- When 第二次
- Then 不重复生成文件/事件
- 验证方式：自动

**AC10（事件只增不改）**
- Given 尝试 UPDATE `record_export`
- When 执行
- Then 数据库拒绝 E2006
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3090 | Hash 链校验失败，拒绝导出 | 否 |
| E3092 | 导出路径非法（穿越/越界） | 否 |
| E2001 | 格式不在白名单 / 参数缺失 | 否 |
| E2006 | 尝试修改导出事件 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 写文件失败 | 事件不落库（同事务语义：先写文件再记事件），可重试 |
| Hash 校验失败 | 拒绝导出 + 高风险审计，转人工核查 |
| 磁盘已满 | 报错并清理临时文件，换盘重试 |

---

## 8. 契约缺口

- `config.export_dir` 默认值需在 M14 配置项中登记（默认 `data/exports/`）。
