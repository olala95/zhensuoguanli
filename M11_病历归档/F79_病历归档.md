# F79 病历归档

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

把已确认（通常已关闭）的病历归入**月度档案**：生成归档号 `AR{yyyyMM}{4位}`，固化归档内容与时间，为后续 Hash 校验与封存做准备。

---

## 2. 依赖

- 依赖：M03（病历内容）、F76（版本）、F78（关闭）、F80（Hash 链）
- 被依赖：F81（封存）、F83（导出）

---

## 3. 涉及的表

`record_archive`、`record`（状态经 M03 服务接口推进到 ARCHIVED）

---

## 4. 规则

**R1 归档号 `AR{yyyyMM}{4位}`**（契约 §1.2），按月归档，事务内取号。

**R2 同一归档周期只归档一次。** 同一病历重复归档拒绝（E3001）；已归档状态由 M03 状态机推进（`CONFIRMED → ARCHIVED`），**禁止裸 UPDATE**（R5）。**例外**：解封后（`UNSEALED`）允许**重新归档**，开**新归档号**（S3 闭环）。

**R3 归档前建议已关闭。** 未关闭时允许归档但记录标记（提醒），**不静默跳过**（F78 R1 同源）。

**R4 归档固化最新版本。** 归档保存归档时的**最新版本号**与快照引用，不重复复制内容（内容在版本里，R-M11-7）。

**R5 Hash 链完整性前置。** 归档前校验 Hash 链（F80 R4）；链校验失败 → **拒绝归档**并告警（不能把已篡改的病历归档）。

**R6 归档原因/操作人留痕。** 写 `audit_operation`；批量归档时逐条记录。

**R7 可按月列出档案。** 按 `archive_month` 查询该月归档清单（含归档号、患者、医生、时间）。

---

## 5. 验收标准

**AC1（归档号格式）**
- Given 归档一份病历
- When 查归档号
- Then 形如 `AR{yyyyMM}{4位}`
- 验证方式：自动

**AC2（状态推进到 ARCHIVED）**
- Given 已确认病历
- When 归档
- Then 病历状态 ARCHIVED（经 M03 状态机）
- 验证方式：自动

**AC3（重复归档被拒）**
- Given 已归档
- When 再次归档
- Then 拒绝 E3001
- 验证方式：自动

**AC4（Hash 链校验失败拒绝归档）**
- Given 人为破坏一条 Hash
- When 归档
- Then 拒绝并告警
- 验证方式：自动（跨 F80）

**AC5（归档固化版本号）**
- Given 病历当前 v2
- When 归档
- Then 归档记录 `version_no=2`
- 验证方式：自动

**AC6（可按月列出）**
- Given 本月归档 3 份
- When 按月查询
- Then 返回 3 条含归档号
- 验证方式：自动

**AC7（只读不复制内容）**
- Given 归档完成
- When 检查 `record_archive`
- Then 只存引用与元信息，不含内容副本
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3001 | 状态不允许归档 / 已归档 | 否 |
| E3090 | Hash 链校验失败，拒绝归档 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 归档事务中断 | 回滚，可重试（幂等） |
| Hash 链异常 | 拒绝归档 + 高风险审计，转人工核查 |
