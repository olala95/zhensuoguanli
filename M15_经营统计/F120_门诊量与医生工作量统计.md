# F120 门诊量与医生工作量统计

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

回答"看了多少人、谁看的、每人产出多少"：门诊量、初复诊构成、按日/按医生的趋势，以及每位医生的接诊人次、开方数、处置执行数与产生的营收。

---

## 2. 依赖

- 依赖：`v_visit_stats` 视图（visit + patient + sys_user）、M09 埋的 `paid_at`
- 被依赖：F119 客单价、UI 报表页、F124 导出

---

## 3. 涉及的表

只读：`v_visit_stats`；写入：无

---

## 4. 规则

**R1 门诊量口径（契约 §7）。** `COUNT(DISTINCT visit.id) WHERE status='COMPLETED'`，**不含 VOID、不含 SUSPENDED**，也不含仍在 IN_PROGRESS 的。

**R2 初诊/复诊判定（契约 §7）。** 该患者在此次 Visit 之前是否存在 `status='COMPLETED'` 的 Visit：无 → 初诊，有 → 复诊。
视图已给出 `prior_completed` 字段，报表按 `prior_completed = 0` 判初诊。
> 注：`visit.is_first_visit` 是开单时的快照，可能与口径不一致，**本报表以视图计算值为准**。

**R3 归集时间。** 门诊量按 `visit.completed_at` 归集；为空时退化为 `registered_at`（并单独计数提示）。

**R4 医生工作量四项。** 按 Visit 的 `doctor_id` 归集：
- 接诊人次（`COMPLETED` 的 Visit 数）
- 开方数（该医生开立的、进入有效状态的处方数）
- 处置执行数（`COMPLETED` 的 `treatment_execution` 数）
- 产生的营收（这些 Visit 对应账单的实收 − 退款，按 `paid_at` 归集）

**R5 医生无归属时的处理。** `doctor_id` 为空的 Visit 单列"未归属"，**不摊给任何医生**。

**R6 中西门诊分类。** 可按 `visit_type` 分组（普通/中医/急诊），便于看业务结构。

**R7 趋势粒度。** 支持按日、按月两种粒度；按月时使用 `substr(date,1,7)`。

**R8 只读。** 查询不写审计（R-M15-3）。

## 5. 验收标准

**AC1（门诊量只算已完成）**
- Given 3 张 COMPLETED、1 张 VOID、1 张 SUSPENDED
- When 查门诊量
- Then 3
- 验证方式：自动

**AC2（初复诊判定）**
- Given 同一患者第 1 次与第 2 次就诊均完成
- When 查构成
- Then 初诊 1、复诊 1
- 验证方式：自动

**AC3（医生工作量四项）**
- Given 医生 A 完成 2 次接诊、开 3 张方、执行 1 项处置
- When 查医生工作量
- Then 四项数值分别正确
- 验证方式：自动

**AC4（医生营收按 paid_at）**
- Given 医生 A 的就诊在昨天完成、今天收款
- When 按今天查
- Then 计入今天的医生营收
- 验证方式：自动

**AC5（未归属不摊派）**
- Given 1 张 doctor_id 为空的已完成就诊
- When 查医生工作量
- Then 出现在"未归属"，不进入任何医生
- 验证方式：自动

**AC6（按 visit_type 分组）**
- Given 普通 2 / 中医 3
- When 按类型分组
- Then 分组计数正确
- 验证方式：自动

**AC7（月度粒度）**
- Given 查询粒度=月
- When 查趋势
- Then 返回按月聚合，各月之和 = 区间总量
- 验证方式：自动

**AC8（只读不写审计）**
- Given 连续查询 10 次
- When 对比审计条数
- Then 无新增
- 验证方式：自动
