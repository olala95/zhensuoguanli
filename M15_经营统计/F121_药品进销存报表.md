# F121 药品进销存报表

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: L（拆 F121.1 期初/期末 / F121.2 期间明细）]

---

## 1. 职责

药品（成药 + 饮片）的月度进销存：期初 → 入库 → 出库（发药）→ 退药 → 报损 → 盘点调整 → 期末，按批次维度，并给出成本与库存金额。

---

## 2. 依赖

- 依赖：`v_stock_ledger` 视图（stock_transaction + stock_batch + drug/herb）、M07 已埋的 `unit_cost_milli` / `amount_fen`
- 被依赖：UI 报表页、F124 导出

---

## 3. 涉及的表

只读：`v_stock_ledger`；写入：无

---

## 4. 规则

**R1 六段式结构（契约 §7）。**
```
期末 = 期初 + 入库 − 出库(发药) + 退药 − 报损 ± 盘点调整
```
按 `trans_type` 归集：`IN` / `OUT` / `RETURN_IN` / `LOSS` / `CHECK_ADJUST`；`SPLIT_OUT`/`SPLIT_IN` **成对抵消，不体现在六段式中**（拆零不改变总量）。

**R2 期初由流水推算（F121.1）。** `期初 = Σ qty_change WHERE occurred_at < 区间起点`；无历史数据时为 0。饮片按 g，成药按单位。

**R3 成本用移动加权平均（契约 §7）。** 入库时按批次成本加权；出库成本取该批次 `unit_cost_milli`。报表给出 `cost_amount_fen = Σ amount_fen`。

**R4 按批次维度（契约 §7）。** 明细可按批次展开，展示批次号、效期、供应商批号；同一品目多批次时汇总行与批次行并存。

**R5 盘点差异单独列示。** 盘点调整不并入"出库"，单列一列，避免掩盖损耗（契约 §7）。

**R6 成药与饮片分开统计。** 单位不同（盒/片 vs g），**不做跨单位相加**；库存金额各自汇总。

**R7 负库存告警。** 若期末出现负值，报表标红并列出（正常应为 0 或正数，出现负值说明流水或盘点有异常）。

**R8 效期与呆滞。** 附带展示批次效期与近效期数量（消费 F49 数据），供采购决策（可选列）。

**R9 只读。** 不写审计。

## 5. 验收标准

**AC1（六段式平衡）**
- Given 期初 100、入库 50、发药 30、退药 5、报损 3、盘点 -2
- When 查进销存
- Then 期末 = 120
- 验证方式：自动

**AC2（期初由流水推算）**
- Given 区间前的历史流水
- When 查期初
- Then 等于区间前 Σ qty_change
- 验证方式：自动

**AC3（拆零不体现）**
- Given 区间内发生一次拆零（-1 包装 +24 片）
- When 查六段式
- Then 拆零两行抵消，不出现在入库/出库
- 验证方式：自动

**AC4（盘点差异单列）**
- Given 盘点调整 -2
- When 查报表
- Then 出现在"盘点调整"列，不在"出库"
- 验证方式：自动

**AC5（成药与饮片分开）**
- Given 同时有成药与饮片流水
- When 查报表
- Then 两类分别小计，不做单位混加
- 验证方式：自动

**AC6（批次维度可展开）**
- Given 一品目两个批次
- When 展开批次
- Then 两行批次 + 汇总行，数量与金额对得上
- 验证方式：自动

**AC7（成本金额就位）**
- Given 任意出库行
- When 查报表
- Then `amount_fen` 非空为整数（M07 出库流水已埋成本）
- 验证方式：自动

**AC8（负库存告警）**
- Given 构造出负期末
- When 查报表
- Then 该行被标记告警
- 验证方式：自动（构造数据）

**AC9（只读不写审计）**
- Given 连续查询 10 次
- When 对比审计条数
- Then 无新增
- 验证方式：自动

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 流水与库存不一致 | 报表以流水为准并标注差异，提示走盘点（M07 F48）校正 |
| 视图缺失 | 明确提示执行迁移 |
