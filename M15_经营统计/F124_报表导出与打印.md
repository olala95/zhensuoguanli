# F124 报表导出与打印

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: S]

---

## 1. 职责

把 F119–F123 的报表结果导出为 CSV（Excel 可直接打开）并支持打印；导出属数据外流，写高风险审计。

> 打印排版（票据、处方笺）归 M10；本 F 只负责**报表**的导出与打印预览数据准备。

---

## 2. 依赖

- 依赖：F119–F123、M14（日志目录）、M12
- 被依赖：UI 报表页

---

## 3. 涉及的表

只读：各 `v_*` 视图；写入：`report_snapshot`（可选缓存）、导出文件落盘

---

## 4. 规则

**R1 导出格式。** CSV / UTF-8 **带 BOM**（Excel 双击不乱码），首行为表头；文件名 `{报表}_{区间}_{生成时间}.csv`。

**R2 金额导出两列。** 同时导出 `*_fen`（整数）与 `*_yuan`（字符串），避免 Excel 二次精度处理（R-M15-4）。

**R3 口径随文件带出。** 文件末尾附一行 `口径说明`（区间、口径、生成时间），便于离手后仍可复核。

**R4 高风险审计。** 导出 = 经营数据外流，写 `audit_high_risk`，记录：报表类型、区间、行数、文件名、操作人。

**R5 权限。** 需 `report.export`；仅有 `report.view` 时拒绝导出（E6002）。

**R6 落盘位置。** 写到日志目录下的 `reports/` 子目录（与系统日志同分区策略：可轮转、非业务数据）。

**R7 上限保护。** 单次导出行数上限 50000，超出拒绝并提示缩小区间（避免单机卡死）。

**R8 不缓存敏感明细。** 患者级明细导出不写入 `report_snapshot`（快照只存汇总）。

**R9 打印数据。** `report.print_data(kind)` 返回带表头、口径、页脚的结构化数据供前端渲染，**不在此处做打印硬件交互**（归 M10 F70）。

---

## 5. 验收标准

**AC1（CSV 带 BOM）**

- Given 导出日营收
- When 检查文件头
- Then 以 UTF-8 BOM 开头，首行为表头
- 验证方式：自动（读文件字节）

**AC2（金额两列）**

- Given 导出结果
- When 看列
- Then 同时有 `*_fen` 与 `*_yuan`
- 验证方式：自动

**AC3（口径随文件）**

- Given 导出文件
- When 读末行
- Then 含区间与口径说明
- 验证方式：自动

**AC4（高风险审计）**

- Given 一次导出
- When 查 `audit_high_risk`
- Then 有记录含报表类型、区间、行数
- 验证方式：自动

**AC5（越权拒绝）**

- Given 只有 report.view 的角色
- When 导出
- Then 拒绝 E6002 并写 `audit_permission`
- 验证方式：自动

**AC6（行数上限）**

- Given 请求导出超 50000 行
- When 提交
- Then 拒绝并提示缩小区间
- 验证方式：自动（构造数据）

**AC7（文件落盘可列目录）**

- Given 导出完成
- When 查导出目录
- Then 文件存在且可读取
- 验证方式：自动

**AC8（打印数据结构化）**

- Given 请求 print_data
- When 看返回
- Then 含表头、行、口径、页脚
- 验证方式：自动

## 6. 异常码

| 码     | 场景          | 可重试 |
| ----- | ----------- | --- |
| E6002 | 无导出权限       | 否   |
| E3081 | 导出行数超过上限    | 否   |
| E1002 | 磁盘空间不足/写入失败 | 否   |

---

## 7. 失败恢复

| 失败点   | 恢复方式                  |
| ----- | --------------------- |
| 写文件失败 | 明确报出 E1002，不返回半成品     |
| 导出中断  | 文件未生成完整则删除，避免留下半截 CSV |
