# F30 结果录入（外送回录）

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

> 原功能点改造：全部外送后，结果来源为"手工回录 + 报告图片附件"，不再有仪器自动导入。

---

## 1. 职责

将外送机构返回的检验结果录入系统：结构化数值录入 + 报告图片附件上传，并标记异常值。

---

## 2. 依赖

- 依赖：F117（回报登记触发）、F29（条码匹配）、M14（附件存储）、M12
- 被依赖：M03（F16 引用）、F31（报告查看）、M04（AI 可读取）

---

## 3. 涉及的表

`lab_result`、`lab_result_attachment`（M05 自有）
附件存文件系统 `attachments/lab/`，元信息入库

---

## 4. 规则

**R1 两种录入方式并存。**
- **结构化录入**：逐项录入项目名称、结果值、单位、参考范围
- **附件上传**：上传报告图片/PDF（可多张），作为原始凭证

**二者至少有一种**；建议先传附件再录关键值。

**R2 附件不可编辑只可追加。** 附件保存后不可修改；可追加新附件（如更正报告）。删除附件需原因并留痕。

**R3 异常值自动标记。** 录入结果值后，若项目配置了参考范围且值超出 → 自动标记异常并高亮。**是否危急值由医生判断**，系统只提示。

**R4 结果更正留历史。** 结果被更正时不覆盖原值：新增一条更正记录，标记 `is_correction=1` 与更正原因，原值保留。**已引用该结果的病历（M03 F16）会收到更新提示。**

**R5 OCR 辅助需人工确认。** 若使用 OCR 识别报告图片，**识别结果必须先经人工核对**才可入库；未经确认的 OCR 结果不得直接成为正式结果。

**R6 回报时间记录。** 记录机构实际回报时间与录入时间（两者可不同）。

**R7 结果关联申请单与标本。** 结果必须关联到具体申请单与标本条码，不可孤立存在。

**R8 录入后进入待阅。** 结果录入后申请单置 `REPORTED`，需医生阅读（F31）后标记 `REVIEWED` 并关联病历。

**R9 隐私。** 报告附件含患者信息，存储路径受权限控制；诊断包导出不含附件（F104）。

## 5. 验收标准

**AC1（结构化录入）**
- Given 血常规回报：白细胞 10.5（参考 4–10）
- When 录入
- Then 结果入库，**自动标记异常**（超出参考范围）
- 验证方式：自动

**AC2（附件上传）**
- Given 上传 2 张报告图片
- When 保存
- Then 附件入库并存储文件，可在 F31 查看
- 验证方式：自动

**AC3（附件不可编辑）**
- Given 已上传附件
- When 尝试修改
- Then 不可编辑，只可追加；删除需原因并留痕
- 验证方式：自动

**AC4（结果更正留历史）**
- Given 白细胞原录 10.5，机构更正为 9.8
- When 更正
- Then 新增更正记录，原值保留，标记更正原因
- 验证方式：自动

**AC5（更正通知已引用病历）**
- Given M03 病历引用了该结果
- When 结果被更正
- Then 病历中提示"引用的结果已于 X 更新"，已确认病历内容不被自动改
- 验证方式：自动（跨模块，需 M03 配合）

**AC6（OCR 需人工确认）**
- Given OCR 识别出一组数值
- When 未经人工核对
- Then 不得成为正式结果；核对确认后才入库
- 验证方式：自动（mock OCR）

**AC7（必须关联申请单）**
- Given 尝试录入无申请单的结果
- When 保存
- Then 拒绝
- 验证方式：自动

**AC8（异常不判定危急值）**
- Given 结果超出参考范围
- When 查看
- Then 标记"异常"由系统；"危急值"由医生判断标记，系统不自动定危急
- 验证方式：自动

**AC9（录入后进入待阅）**
- Given 结果录入完成
- When 查看申请单
- Then 状态 REPORTED（待医生阅）
- 验证方式：自动

**AC10（隐私：诊断包不含附件）**
- Given 存在报告附件
- When 导出诊断包（F104）
- Then 包内不含附件文件
- 验证方式：自动（跨模块）

**AC11（崩溃一致性）**
- Given 附件上传中强杀
- When 重启
- Then 无半写附件记录；可重新上传
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 结果无关联申请单 | 否 |
| E2002 | 数值格式错误 | 否 |
| E1002 | 磁盘不足无法保存附件 | 是 |
| E2009 | 附件格式不支持 | 否 |
| E5004 | OCR 结果不可解析 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 上传中断 | 支持重新上传；不产生半写记录 |
| 磁盘不足 | 提前检查；不足时拒绝并提示 |
| OCR 失败 | 不影响手工录入；可跳过 OCR |
| 崩溃 | 事务保护结果记录；附件文件由校验和验证完整性 |
