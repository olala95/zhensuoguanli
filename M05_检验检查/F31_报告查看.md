# F31 报告查看

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

医生查看检验结果：结构化数值、异常标记、报告附件，并标记"已阅"与关联病历。

---

## 2. 依赖

- 依赖：F30（结果数据）、M03（F16 关联病历）、M10（打印报告给患者）
- 被依赖：M03、M15

---

## 3. 涉及的表

`lab_result`、`lab_result_attachment`、`lab_order`（M05 自有，只读为主；标记已阅会写 `lab_order`）

---

## 4. 规则

**R1 异常值突出显示。** 超出参考范围的值高亮并标注 ↑/↓；正常值普通显示。

**R2 附件可查看与打印。** 报告图片可放大查看、可打印（走 M10）给患者。

**R3 医生阅后标记。** 医生查看后标记 `REVIEWED`（记录阅片人与时间）。**这是临床责任动作**，不可自动标记。

**R4 关联病历。** 医生可一键将结果关联到本次病历（M03 F16 引用），关联后病历中显示引用。

**R5 历史对比（可选）。** 若患者有同类项目的历史结果，可展示历次数值趋势（P1，有价值但非必需）。

**R6 待阅列表。** 提供"待阅结果"列表：已回报未阅的结果，按回报时间倒序，超期未阅高亮。

**R7 打印给患者的报告含必要信息。** 打印内容含患者姓名、项目、结果、参考范围、异常标记、机构名称、报告日期。**不含医生内部备注。**

**R8 查看附件写审计？否。** 查看是高频动作不写审计；但**导出/打印**写审计（涉及隐私外流）。

---

## 5. 验收标准

**AC1（异常高亮）**
- Given 白细胞 10.5（参考 4–10）
- When 查看报告
- Then 该值高亮并标注 ↑
- 验证方式：自动

**AC2（附件查看）**
- Given 报告含 2 张附件
- When 查看
- Then 可打开查看，可放大
- 验证方式：自动

**AC3（标记已阅）**
- Given 医生查看报告
- When 点击"已阅"
- Then 申请单置 REVIEWED，记录阅片人与时间
- 验证方式：自动

**AC4（不自动标记已阅）**
- Given 结果已回报
- When 医生未操作
- Then 状态仍为 REPORTED（待阅）
- 验证方式：自动

**AC5（关联病历）**
- Given 医生点击"关联到病历"
- When 执行
- Then M03 病历中新增该结果引用（F16）
- 验证方式：自动（跨模块）

**AC6（待阅列表）**
- Given 有 3 条已回报未阅结果
- When 查看待阅
- Then 列出 3 条，按回报时间倒序
- 验证方式：自动

**AC7（打印报告）**
- Given 打印报告给患者
- When 执行
- Then 含必要信息（患者、项目、结果、参考范围、机构、日期），**不含内部备注**；写审计
- 验证方式：自动（跨模块，需 M10 配合）

**AC8（查看附件不写审计）**
- Given 医生查看附件
- When 检查审计
- Then 无查看审计（高频动作不膨胀审计表）
- 验证方式：自动

**AC9（历史对比）**
- Given 患者有 3 次血常规结果
- When 查看
- Then 可展示历次数值趋势（P1 功能，若实现）
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3029 | 结果不存在或已作废 | 否 |
| E7001 | 报告打印失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 附件文件丢失 | 提示附件不可用，结构化数值仍可查看 |
| 打印失败 | 可重打（M10 F71） |
| M03 关联失败 | 提示重试；结果本身不受影响 |
