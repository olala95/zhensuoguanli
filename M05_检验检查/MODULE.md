# M05 检验检查（全部外送）

> 阶段：第二阶段
> 依赖：M02（Visit）、M01（患者）、M09（收费）、M14、M12
> 被依赖：M03（F16 引用结果）、M15 报表、M10（条码打印）

---

## 1. 模块职责

外送检验的全流程：项目目录、开单申请、标本条码、送检登记、结果回录、报告查看，以及与外送机构的月度对账。

**本模块不含任何仪器对接**（LIS / 串口 / HL7）。检验全部外送，结果以手工回录 + 报告图片附件方式录入。

## 3. 模块级规则

**R-M05-1 全部外送，无仪器对接。** 不实现任何 LIS、串口、HL7 接口。结果来源只有两种：手工录入 + 报告图片附件（可 OCR 辅助但需人工确认）。

**R-M05-2 双价格模型。** 每个外送项目有**收费价**（向患者收）与**结算价**（付给机构）。差额是诊所毛利，是 F118 对账的基础。

**R-M05-3 开单即收费。** 检验申请单生成后走 M09 账单收费（与其他项目一起结算）。未收费的申请单不可送检。

**R-M05-4 标本条码用于外送核对。** 条码用于标本管标识与机构回单匹配；**条码本身不含患者隐私明文**（只含条码号，患者信息在系统内关联）。

**R-M05-5 报告周期可预期。** 每个项目配置预计报告天数；超过预期未回报 → 在待回报列表中标记超期并提醒（F117）。

**R-M05-6 结果回录需医生阅。** 结果回报后进入"待医生阅"状态；医生阅读并关联到病历（M03 F16）后标记 REVIEWED。

**R-M05-7 异常值标记。** 结果中超出参考范围的值标记异常并高亮；**是否危急值由医生判断**，系统只做参考范围提示。

**R-M05-8 附件不可篡改。** 报告图片附件保存后不可编辑（只可追加）；删除需原因并留痕。

**R-M05-9 取消与退费联动。** 申请单取消（未送检）→ 触发 M09 退款；已送检不可取消。

**R-M05-10 患者合并时改挂。** 提供 `patient.reassign()` 支持（M01 F04 用）。

## 4. 状态机引用

```
lab_order: DRAFT → ORDERED（已开单收费）→ SAMPLED（已采样）→ DELIVERED（已送检）
         → REPORTED（已回报）→ REVIEWED（医生已阅）
ORDERED / SAMPLED → CANCELLED（作废退费）
```

## 5. 对外接口

| 接口 | 说明 | 消费方 |
|---|---|---|
| `lab.order(visitId, items)` | 开单 | M02 工作台、M03 医嘱 |
| `lab.results(visitId)` | 取结果 | M03 F16 |
| `lab.resultRef(resultId)` | 取引用快照 | M03 |
| `lab.pendingList()` | 待回报列表 | 界面、F117 |
| `voidByVisit(visitId)` | Visit 作废时取消未确认单据 | M02 F125 |
| `patient.reassign(from, to)` | 患者合并改挂 | M01 F04 |
