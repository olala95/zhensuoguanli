# F29 标本条码

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

为采样标本生成并打印条码标签，用于标本管标识与外送机构回单匹配。

---

## 2. 依赖

- 依赖：F28（申请单）、M14（编号服务）、**M10（打印标签）**、F74（扫码枪）
- 被依赖：F117（送检核对）、F30（结果匹配）

---

## 3. 涉及的表

`lab_specimen`（M05 自有）

---

## 4. 规则

**R1 一标本一码。** 一个标本一个条码；一个申请单含多项目但同类型标本可共用一管（一码），不同类型标本各一码。

**R2 条码号格式固定。** `BC{yyyyMMdd}{6位}`，Code128 编码（外送机构通用）。

**R3 条码不含隐私明文。** 条码内容**只有条码号**，不含患者姓名/身份证。患者信息通过条码号在系统内关联。

**R4 标签内容。** 标签上打印：条码 + 患者姓名（部分）、标本类型、采样日期。姓名可配置为脱敏。

**R5 扫码回查。** 用扫码枪（F74）扫条码可快速定位到申请单与患者。

**R6 支持补打。** 标签丢失或打印失败可补打**同一条码号**（不生成新号），补打标记次数。

**R7 条码状态。** `PREPARED`（已生成未采样）→ `SAMPLED`（已采样）→ `DELIVERED`（已送检）→ `RESULTED`（已回报）。

**R8 打印失败可恢复。** 打印失败不影响条码生成；可后续补打（M10 F71）。

**R9 采样时间记录。** 采样时记录时间与采样人，用于标本时效性判断。

**R10 作废标本条码作废。** 申请单取消时，其标本条码标记作废，**不回收号码**（保留追溯）。

## 5. 验收标准

**AC1（生成条码）**
- Given 申请单含血常规（血标本）
- When 生成标本
- Then 生成条码 `BC{今日}{6位}`，状态 PREPARED
- 验证方式：自动

**AC2（一标本一码）**
- Given 申请单含血常规与尿常规
- When 生成标本
- Then 生成 2 个条码（不同标本类型）
- 验证方式：自动

**AC3（同类型共用）**
- Given 申请单含血常规与血生化（均为血标本）
- When 生成标本
- Then 共用 1 个条码（配置允许时）
- 验证方式：自动

**AC4（条码不含隐私）**
- Given 生成条码
- When 解析条码内容
- Then 只有条码号，**无姓名/身份证**
- 验证方式：自动

**AC5（打印标签）**
- Given 条码已生成
- When 打印标签
- Then 通过 M10 打印，标签含条码、姓名（可脱敏）、标本类型、日期
- 验证方式：自动（跨模块，需 M10 配合）

**AC6（补打同号）**
- Given 标签打印失败
- When 补打
- Then 使用**同一条码号**，重打次数 +1
- 验证方式：自动

**AC7（扫码回查）**
- Given 用扫码枪扫某条码
- When 系统响应
- Then 定位到对应申请单与患者
- 验证方式：自动（mock 扫码枪）

**AC8（采样时间）**
- Given 标记采样
- When 保存
- Then 记录采样时间与采样人，条码状态 SAMPLED
- 验证方式：自动

**AC9（作废不回收）**
- Given 申请单取消
- When 查看其条码
- Then 标记作废，号码保留不复用
- 验证方式：自动

**AC10（崩溃一致性）**
- Given 条码生成中强杀
- When 重启
- Then 条码要么完整要么不存在；无重复条码号
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E4003 | 扫码枪不可用（可手工输入） | 是 |
| E7001 | 标签打印失败（可补打） | 是 |
| E3028 | 条码状态不允许该操作 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 打印失败 | 条码仍有效，可补打（M10 F71） |
| 扫码失败 | 支持手工输入条码号 |
| 崩溃 | 事务保护条码唯一性 |
