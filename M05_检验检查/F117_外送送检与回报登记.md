# F117 外送送检与回报登记

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

> 新增功能点。原始 107 个功能点按"院内检验"设计，外送模式下缺少送检交接与回报登记环节。

---

## 1. 职责

管理标本送出的交接（送检登记）与结果回来的登记（回报登记），并跟踪超期未回报。

---

## 2. 依赖

- 依赖：F28（申请单）、F29（标本条码）、F27（报告周期）、F30（结果录入）、M10（打印送检单）
- 被依赖：F118（对账以送检记录为依据）、F30

---

## 3. 涉及的表

`lab_delivery`（M05 自有）

---

## 4. 规则

**R1 送检登记按机构批量。** 同一机构的一批标本一起送出：生成一条送检记录（含送检日期、机构、标本清单、送检人、交接方式）。

**R2 送检单打印。** 送检时可打印送检清单（含条码号、患者姓名、项目、标本类型、临床信息），随标本交机构。走 M10 打印。

**R3 扫码核对。** 送检前用扫码枪（F74）逐个扫标本条码核对，防止漏送或错送。**支持手工勾选替代**（扫码枪不可用时）。

**R4 送检后状态推进。** 送检登记成功 → 标本置 DELIVERED、申请单置 DELIVERED，记录送出时间。

**R5 回报登记。** 机构返回结果时登记：回报日期、方式（纸质/电子/电话）、接收人。回报后申请单置 REPORTED，进入 F30 录入。

**R6 超期提醒。** 按项目的报告周期计算预计回报日；超过未回报 → 在待回报列表中标记"超期"并提示随访。

**R7 待回报列表。** 提供统一的"已送检待回报"视图：按机构分组、按超期天数排序、支持按条码/患者搜索。

**R8 部分回报。** 一批送检可能部分先回：支持按申请单粒度回报，不要求整批齐回。

**R9 丢失/异常登记。** 标本丢失、结果无法出具（如标本溶血）可登记异常，标记申请单状态并触发退款流程（M09）。

**R10 送检记录不可删。** 送检与回报记录是交接凭证，只可追加更正，**不可删除**（对账与纠纷追溯需要）。

## 5. 验收标准

**AC1（批量送检登记）**
- Given A 机构有 3 个标本待送
- When 生成送检记录
- Then 一条记录含 3 个标本，状态 DELIVERED，记录送检人与时间
- 验证方式：自动

**AC2（扫码核对）**
- Given 送检前扫码
- When 扫到 3 个条码
- Then 与待送清单一致；扫到清单外条码时报警
- 验证方式：自动（mock 扫码枪）

**AC3（扫码枪不可用时手工替代）**
- Given 扫码枪不可用
- When 送检
- Then 可手工勾选标本，不阻塞
- 验证方式：自动（mock 失败）

**AC4（送检单打印）**
- Given 送检登记完成
- When 打印送检单
- Then 含条码号、患者姓名、项目、标本类型、临床信息
- 验证方式：自动（跨模块，需 M10 配合）

**AC5（回报登记）**
- Given 机构返回结果
- When 登记回报
- Then 申请单置 REPORTED，记录回报日期/方式/接收人
- 验证方式：自动

**AC6（部分回报）**
- Given 一批 3 个标本，先回 1 个
- When 回报登记
- Then 仅该申请单置 REPORTED，其余仍为待回报
- 验证方式：自动

**AC7（超期提醒）**
- Given 项目报告周期 1 天，送检后 3 天未回报
- When 查看待回报列表
- Then 标记"超期 2 天"并高亮
- 验证方式：自动（mock 时间）

**AC8（标本异常登记）**
- Given 机构通知标本溶血无法检测
- When 登记异常
- Then 申请单标记异常，引导走 M09 退款
- 验证方式：自动（跨模块，需 M09 配合）

**AC9（记录不可删）**
- Given 已存在送检记录
- When 尝试删除
- Then 拒绝；只可追加更正说明
- 验证方式：自动

**AC10（崩溃一致性）**
- Given 送检登记执行中强杀
- When 重启
- Then 记录要么完整要么不存在；标本状态与记录一致
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3030 | 标本状态不允许送检 | 否 |
| E3031 | 标本异常无法出具结果 | 否（引导退款） |
| E4003 | 扫码枪不可用（可手工） | 是 |
| E7001 | 送检单打印失败（可补打） | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 打印送检单失败 | 送检记录仍有效，可补打 |
| 崩溃 | 事务保证标本状态与送检记录一致 |
| 扫码失败 | 手工勾选替代 |
