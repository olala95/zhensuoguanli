# F112 中药处方计价

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

> 新增功能点。饮片计价与成药完全不同：单价(元/g) × 剂量(g) × 付数，逐味计算后汇总。

---

## 1. 职责

按契约 §3.2 计算饮片/颗粒处方金额：逐味小计 + 代煎费 + 包装费。

---

## 2. 依赖

- 依赖：F110（饮片单价）、F111（剂量与付数）、M14（代煎费配置）
- 被依赖：M09 收费、M15 报表

---

## 3. 涉及的表

`prescription_pricing`（M06 自有）

---

## 4. 规则

**R1 计价公式固定（契约 §3.2）。**
```
每味小计(分) = round(单价(毫元/g) × 剂量(g) × 付数 / 10)
饮片合计 = Σ 每味小计
处方金额 = 饮片合计 + 代煎费(分) + 包装费(分)
```

**R2 每味独立舍入。** 每味小计先舍入到分，再求和。**不在总额级二次舍入。**

**R3 付数变更必须全量重算。** 改付数后所有味的小计重算，**不得按比例缩放总额**（避免舍入误差累积）。

**R4 代煎费规则。** 代煎费按配置：可按付数计（代煎费 × 付数）或按处方计（固定）。配置决定，不是硬编码。

**R5 颗粒按包装计价。** 颗粒处方走成药规则（单价 × 数量），不按克 × 付数。

**R6 尾差记录。** 若存在尾差（如分拆计算导致），记录在 `prescription_pricing.tail_diff`，**不隐式吸收**。

**R7 价格取开方时价。** 饮片调价后，已开处方按开方时价（F110 AC6）。

**R8 金额整数分。** 全部金额存整数分；单价可存毫元。

**R9 计价结果可查看。** 界面展示每味小计与合计，便于患者核对（中药处方金额患者常问明细）。

**R10 计价失败拒绝确认。** 计价异常 → 拒绝处方提交/确认（不允许无金额的处方进入收费）。

## 5. 验收标准

**AC1（基本计价）**
- Given 黄芪 15g × 0.05 元/g × 7 付 = 5.25 元；白术 10g × 0.08 × 7 = 5.60 元
- When 计价
- Then 每味小计正确，合计 10.85 元（1085 分）
- 验证方式：自动

**AC2（逐味舍入）**
- Given 某味计算结果为 3.333 元
- When 计价
- Then 该味小计舍入到 3.33 元（ROUND_HALF_UP）
- 验证方式：自动

**AC3（付数变更全量重算）**
- Given 7 付金额 10.85 元
- When 改为 14 付
- Then 重新逐味计算（不是简单 ×2）
- 验证方式：自动

**AC4（代煎费按付数）**
- Given 配置为按付数计，代煎费 1 元/付，7 付
- When 计价
- Then 代煎费 7 元
- 验证方式：自动

**AC5（代煎费按处方）**
- Given 配置为按处方计，代煎费 5 元
- When 计价（无论付数）
- Then 代煎费 5 元
- 验证方式：自动

**AC6（颗粒按包装）**
- Given 颗粒 3 盒 × 45 元
- When 计价
- Then 135 元，不按克计算
- 验证方式：自动

**AC7（尾差记录）**
- Given 计算存在尾差
- When 计价
- Then 尾差显式记录在 `prescription_pricing.tail_diff`
- 验证方式：自动

**AC8（价格取开方时价）**
- Given 开方后饮片调价
- When 查看处方金额
- Then 仍按开方时价
- 验证方式：自动

**AC9（金额整数分）**
- Given 处方金额 10.85 元
- When 检查存储
- Then 为 1085
- 验证方式：自动

**AC10（计价失败拒绝确认）**
- Given 计价服务异常
- When 提交处方
- Then 拒绝提交，无金额的处方不进入收费
- 验证方式：自动（注入异常）

**AC11（明细可查看）**
- Given 处方已计价
- When 查看
- Then 可看到每味小计与合计
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2002 | 金额/剂量格式错误 | 否 |
| E3043 | 计价失败，拒绝提交 | 是 |
| E3044 | 单价缺失（饮片未定价） | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 计价异常 | 拒绝提交；提示检查饮片单价配置 |
| 崩溃 | 计价结果不半写；重新计价 |
| 单价缺失 | 提示补录饮片单价，不允许按 0 计价 |
