# F36 皮试

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

记录皮试（皮肤敏感试验）的执行与结果，作为需皮试药品处方确认的前置条件。

---

## 2. 依赖

- 依赖：F32（药品 `require_skin_test` 标记）、F35.2（校验消费）、M12
- 被依赖：F37（确认前置）、M08（皮试本身可作为处置执行）

---

## 3. 涉及的表

`skin_test`（M06 自有）

---

## 4. 规则

**R1 皮试记录必填项。** 药品、批号（**哪个批次的药做的皮试**）、执行时间、执行人、结果（阴性/阳性）、观察时间。

**R2 批号必记。** 皮试结果只对**该批次**药品有效——换批次需重新皮试。这是临床规范，不可省略。

**R3 结果有效期。** 皮试结果有有效期（默认 24 小时，可配）；超过有效期需重做。

**R4 阳性即拦截。** 结果阳性 → 该药品**不得**开方确认（F35.2 强制）。

**R5 阳性记录长期保留。** 阳性结果应提示录入 M03 过敏史（F13）——**皮试阳性本身就是过敏证据**。系统提示医生补充过敏记录。

**R6 皮试可关联处方。** 皮试记录可关联到处方（先皮试后开方）或独立记录（预做皮试）。

**R7 结果不可随意修改。** 结果录入后修改需原因并留痕；**阳性改阴性尤其敏感**，写 `audit_high_risk`。

**R8 执行人记录。** 皮试执行人（护士/医生）必须记录。

**R9 未做皮试时的引导。** 开需皮试药品时，若无可用的阴性皮试记录 → 引导去做皮试（可生成 M08 处置执行单）。

---

## 5. 验收标准

**AC1（记录皮试）**
- Given 为某青霉素药品做皮试，结果阴性
- When 记录（含药品、批号、执行人、时间）
- Then 记录完整
- 验证方式：自动

**AC2（批号必填）**
- Given 未填批号
- When 保存
- Then 拒绝并提示
- 验证方式：自动

**AC3（换批次需重做）**
- Given 皮试针对批次 A，现处方药品批次为 B
- When 确认处方
- Then 拦截，提示需针对批次 B 重做皮试
- 验证方式：自动

**AC4（有效期）**
- Given 皮试 24 小时前做的
- When 确认处方
- Then 拦截，提示已过期需重做
- 验证方式：自动（mock 时间）

**AC5（阳性拦截）**
- Given 皮试结果阳性
- When 确认含该药处方
- Then 拒绝确认
- 验证方式：自动

**AC6（阳性提示录入过敏史）**
- Given 皮试阳性
- When 查看
- Then 提示医生补充 M03 过敏记录（F13）
- 验证方式：自动（跨模块）

**AC7（阳性改阴性高风险）**
- Given 阳性结果被改为阴性
- When 保存（需填原因）
- Then 写 `audit_high_risk` 含原因
- 验证方式：自动

**AC8（无皮试时引导执行）**
- Given 开需皮试药品且无记录
- When 提交/确认
- Then 引导去做皮试，可生成 M08 处置执行单
- 验证方式：自动（跨模块，需 M08 配合）

**AC9（执行人记录）**
- Given 皮试由护士 C 执行
- When 查看记录
- Then 执行人为 C
- 验证方式：自动

**AC10（崩溃一致性）**
- Given 皮试记录保存中强杀
- When 重启
- Then 记录要么完整要么不存在
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 皮试必填缺失（批号/结果/执行人） | 否 |
| E3035 | 皮试未做/阳性/过期/批次不符 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 保存失败 | 保留内容重试 |
| 崩溃 | 事务保护 |
