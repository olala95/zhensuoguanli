# F39 用药指导

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: S]

---

## 1. 职责

基于处方用法用量生成患者可理解的用药说明，用于打印（M10）或口头交代。

---

## 2. 依赖

- 依赖：F34 / F111（处方明细与用法）、F32（药品资料）、M10（打印）
- 被依赖：M10 药袋标签与用药说明单

---

## 3. 涉及的表

`medication_guide`（M06 自有）

---

## 4. 规则

**R1 由用法结构化生成。** 基于给药途径、单次剂量、频次、天数自动生成白话说明（如"每日 3 次，每次 2 片，饭后服用，共 3 天"）。

**R2 可人工补充。** 医生可补充注意事项（如"服药期间忌酒""可能出现嗜睡，勿驾车"）。

**R3 中药煎法说明。** 饮片处方需含：煎法（水煎、先煎后下等脚注说明）、服法（每日几次、饭前/后）、付数。生成给患者的煎药说明。

**R4 禁忌提示。** 自动带出药品的关键禁忌提示（如与酒精相互作用）— 来自药品资料的可配置说明。

**R5 生成内容可编辑。** 生成后可修改，修改留痕。

**R6 与药袋标签联动。** 用药指导内容可打印在药袋标签或单独说明单（M10 F69）。

**R7 不替代医嘱。** 用药指导是处方的说明，**不是医嘱**（M03 F18）；二者不冲突但职责不同。

**R8 语言通俗。** 面向患者，避免专业术语（"tid"应写为"每日 3 次"）。

---

## 5. 验收标准

**AC1（自动生成）**
- Given 处方用法"口服 0.5g tid ×3天"
- When 生成用药指导
- Then 生成"每日 3 次，每次 X，共 3 天"的白话说明
- 验证方式：自动

**AC2（可编辑）**
- Given 生成的说明
- When 医生补充"服药期间忌酒"
- Then 补充说明保存，留痕
- 验证方式：自动

**AC3（中药煎法说明）**
- Given 饮片处方含"先煎"脚注与付数 7
- When 生成指导
- Then 含先煎说明、每日服法、共 7 付
- 验证方式：自动（跨模块，需 F111 配合）

**AC4（术语白话化）**
- Given 频次 tid
- When 生成
- Then 显示为"每日 3 次"，不出现 tid
- 验证方式：自动

**AC5（禁忌提示）**
- Given 药品配置了"忌酒"提示
- When 生成
- Then 指导中包含该提示
- 验证方式：自动

**AC6（打印联动）**
- Given 用药指导已生成
- When 打印药袋标签/说明单
- Then 内容正确打印
- 验证方式：自动（跨模块，需 M10 配合）

**AC7（崩溃保护）**
- Given 生成中强杀
- When 重启
- Then 处方不受影响，可重新生成
- 验证方式：自动

| 码 | 场景 | 可重试 |

| E3041 | 处方未确认，不可生成指导 | 否 |
| E1010 | 审计写入失败 | 是 |

|---|---|

| 打印失败 | 可重打（M10 F71） |
