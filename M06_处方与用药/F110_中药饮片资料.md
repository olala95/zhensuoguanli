# F110 中药饮片资料

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

> 新增功能点（中医需求）。饮片资料结构与成药差异大：需性味归经、常用量、毒性标记、配伍禁忌关系。

---

## 1. 职责

维护中药饮片目录：名称、炮制规格、性味归经、常用剂量范围、毒性标记、配伍禁忌关系。

---

## 2. 依赖

- 依赖：M14（`sys_dict` 炮制规格、脚注、性味）、M12、F128（批量导入）
- 被依赖：F111（开饮片方）、F113（规则校验）、M07 F114（饮片库存）

---

## 3. 涉及的表

`herb`（M06 自有）、`herb_compatibility`（M06 自有，配伍禁忌）

---

## 4. 规则

**R1 必填字段。** 名称、炮制规格（生/炒/炙/煅/炭…）、单位（**克**）、常用量范围（min–max 克）、单价（毫元/克）。

**R2 性味归经可选但建议填。** 四气（寒热温凉）、五味（酸苦甘辛咸）、归经、功效。用于 F113 的治法方向提醒。

**R3 剂量上限与毒性标记（安全关键）。**
- `max_dose_g`：单味单次最大剂量（用于 F113 提醒）
- `is_toxic`：是否毒性饮片（**超限量时强制二次确认 + 高风险审计**）

**R4 配伍禁忌表。** `herb_compatibility` 记录十八反十九畏等禁忌药对（双向）。命中时**提醒不阻断**（F113）。

**R5 调价留历史。** 与 F32 相同：新增有效期记录，旧价保留，**已开处方按开方时价**。

**R6 停用不删除。** 有库存或历史处方的饮片只能停用。

**R7 拼音码用于搜索。** 支持拼音首字母快速定位（配合 F33）。

**R8 唯一键。** 名称 + 炮制规格。

**R9 变更审计。** 尤其**毒性标记与剂量上限变更写 `audit_high_risk`**（安全相关）。

**R10 颗粒剂特殊处理。** 颗粒剂按成药管理（有包装规格、按袋/盒计价），但在资料中标记 `form=GRANULE`，仍关联中医证型使用。

---

## 5. 验收标准

**AC1（创建饮片）**
- Given 录入"黄芪（生）"，常用量 10–30g，单价 0.05 元/g
- When 保存
- Then 数据正确，单价以毫元存储（50），单位为克
- 验证方式：自动

**AC2（必填校验）**
- Given 缺常用量范围
- When 保存
- Then 拒绝并提示
- 验证方式：自动

**AC3（毒性标记影响规则）**
- Given 标记某饮片 `is_toxic=1`
- When 处方中该饮片超限量
- Then 强制二次确认 + `audit_high_risk`
- 验证方式：自动（跨模块，需 F113 配合）

**AC4（剂量上限提醒）**
- Given 常用量上限 30g，处方开了 45g
- When 保存处方
- Then 触发超量提醒（不阻断）
- 验证方式：自动（跨模块，需 F113 配合）

**AC5（配伍禁忌配置）**
- Given 配置"甘草反甘遂"禁忌对
- When 处方中同时出现
- Then 触发提醒（不阻断）
- 验证方式：自动（跨模块，需 F113 配合）

**AC6（调价不影响已开处方）**
- Given 开方时价 0.05 元/g，后调为 0.06
- When 查看该处方金额
- Then 按 0.05 计算
- 验证方式：自动

**AC7（停用不删）**
- Given 停用某饮片
- When 开方搜索
- Then 不出现；历史处方仍显示
- 验证方式：自动

**AC8（毒性标记变更高风险审计）**
- Given 修改 `is_toxic` 或 `max_dose_g`
- When 保存
- Then 写 `audit_high_risk`
- 验证方式：自动

**AC9（批量导入）**
- Given 导入 300 条饮片
- When 导入
- Then 成功，可在 F111 中选择
- 验证方式：自动（跨模块，需 F128 配合）

**AC10（拼音搜索）**
- Given 饮片"黄芪"拼音码 hq
- When 输入 hq
- Then 定位到该饮片
- 验证方式：自动（跨模块，需 F33 配合）

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 必填缺失 | 否 |
| E2004 | 名称+炮制规格重复 | 否 |
| E2002 | 价格/剂量格式错误 | 否 |
| E3001 | 有库存/历史处方不可删除 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 保存失败 | 保留内容重试 |
| 导入失败 | 整体回滚，错误可定位 |
| 崩溃 | 事务保护 |

---

## 8. 契约缺口

- 配伍禁忌表（十八反十九畏）需初始化内置基础数据，或由 F128.4 导入。
