# F32 药品资料

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

维护成药/西药目录：基本信息、规格剂型、价格、分类标记（处方药/抗生素/皮试要求）、停用管理。

## 2. 依赖

- 依赖：M14（`sys_dict` 剂型/单位、配置）、M12、F128（批量导入）
- 被依赖：F33、F34、M07（入库与库存）、F35（规则校验）

---

## 3. 涉及的表

`drug`（M06 自有）

---

## 4. 规则

**R1 必填字段。** 通用名、剂型、规格、单位、批准文号、是否处方药。商品名、厂家、拼音码可选（拼音码用于搜索）。

**R2 唯一键。** 批准文号 + 规格 + 厂家。导入时按此 upsert（F128）。

**R3 安全相关标记必准确。** 以下标记直接影响规则校验，**录入时必须谨慎**：
- `is_antibiotic`（抗生素）
- `require_skin_test`（需皮试）
- `is_injection`（注射剂）
- `max_single_dose` / `max_daily_dose`（剂量上限，用于 F35 提醒）

**R4 价格可多档。** 支持零售价与会员价（若配置启用）；**默认零售价必填**。价格整数分。

**R5 调价留历史。** 同 F27 R3：调价新增有效期记录，旧价格保留；**已开处方按开方时价格结算**。

**R6 停用不删除。** 有库存或历史处方的药品不可删除，只能停用；停用后不出现在开方搜索（但历史处方仍显示）。

**R7 拆分属性（供 M07）。** 记录整盒/整瓶的包装数量与最小发药单位（盒/片/支/ml），供拆零（M07 F44）使用。

**R8 医保字段不需要。** 明确不做医保，无需医保目录、医保类别、报销比例字段。

**R9 变更审计。** 药品信息变更写审计；**价格与安全标记变更写 `audit_high_risk`**。

## 5. 验收标准

**AC1（创建药品）**
- Given 录入"阿莫西林胶囊 0.25g×24粒"，批准文号、规格、单位完整
- When 保存
- Then 数据正确，价格整数分存储
- 验证方式：自动

**AC2（必填校验）**
- Given 缺批准文号
- When 保存
- Then 拒绝并提示
- 验证方式：自动

**AC3（安全标记影响规则）**
- Given 标记某药 `require_skin_test=1`
- When 开该药处方且无皮试记录
- Then 处方无法确认（F36 前置）
- 验证方式：自动（跨模块）

**AC4（抗生素标记可用于统计）**
- Given 标记某药为抗生素
- When M15 统计抗生素使用率
- Then 该药处方被计入
- 验证方式：自动（跨模块，需 M15 配合）

**AC5（调价留历史且不影响已开处方）**
- Given 某药价 10 元，开处方后调为 12 元
- When 查看该处方金额
- Then 仍为 10 元
- 验证方式：自动

**AC6（停用不删）**
- Given 停用某药
- When 开方搜索
- Then 不出现；历史处方中仍正常显示药名
- 验证方式：自动

**AC7（有库存药品不可删除）**
- Given 某药有库存
- When 尝试删除
- Then 拒绝，提示只能停用
- 验证方式：自动

**AC8（安全标记变更高风险审计）**
- Given 修改 `require_skin_test` 标记
- When 保存
- Then 写 `audit_high_risk` 含 before/after
- 验证方式：自动

**AC9（批量导入 upsert）**
- Given 导入 100 条药品，其中 10 条已存在
- When 导入（更新模式）
- Then 新增 90、更新 10，无重复
- 验证方式：自动（跨模块，需 F128 配合）

**AC10（无医保字段）**
- Given 检查 `drug` 表结构
- When 审查字段
- Then 不含任何医保相关字段
- 验证方式：自动（结构检查）

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 必填缺失 | 否 |
| E2004 | 唯一键冲突 | 否 |
| E2002 | 价格格式错误 | 否 |
| E3001 | 有库存/历史处方不可删除 | 否 |
| E1010 | 审计写入失败 | 是 |

| 崩溃 | 事务保护 |
