# F127 处方模板与经验方

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: M]

> 新增功能点。AI 草稿（M04 F23/F24）解决"从语音到草稿"，模板解决"零输入秒开"——
> 日接诊量大的诊所，常用方不该每次重敲。

## 1. 职责

处方模板与经验方的维护、检索、一键套用、从既有处方另存为模板。

## 4. 规则

**R1 模板分类。** `template_type`：`WEST`（成药）/ `HERB`（饮片）/ `GRANULE`（颗粒）。
`scope`：`SYSTEM`（系统内置）/ `USER`（个人）/ `CLINIC`（全院共享）。

**R2 经验方 = 带证型关联的饮片模板。** `syndrome_name` / `syndrome_code` 可空；非空即为经验方，
界面按证型检索（"肝郁脾虚有哪些方"）。

**R3 套用是复制不是引用。** 套用模板 = 把明细**复制**进当前处方；之后改模板不影响已开处方，
改处方也不影响模板。**禁止用外键引用模板**（会导致历史处方被模板变更污染）。

**R4 套用后必须过规则校验。** 模板不豁免 F35 / F113，套用得到的处方与手工开方完全同责（R-M06-4 精神）。

**R5 剂量与付数可覆盖。** 套用时允许传入 `doses`（付数）与逐味剂量覆盖；
不传则用模板默认值（付数取系统默认 7 付，契约 §8）。

**R6 停用药品的处理。** 模板明细引用了已停用药品 → 套用时**跳过该行并明确提示**，
**不静默丢弃**（医生以为开了 6 味实际只有 5 味是事故）。

**R7 权限。** `SYSTEM` 模板只读（ADMIN 可维护）；`USER` 模板仅本人可改；`CLINIC` 模板由 ADMIN 维护。
删除走软删，不物理删。

**R8 使用计数。** 每次套用 `usage_count + 1`，检索按使用频次排序（常用方靠前）。

**R9 从处方另存为模板。** 支持把一张已确认处方存为模板，存的时候记录来源处方号，便于溯源。

**R10 模板内容不可含已作废编号。** 模板不生成处方号，处方号在真正开方时取（契约 §1.1）。

## 5. 验收标准

**AC1（创建饮片模板）**
- Given 医生创建模板"逍遥散加减"，含 6 味饮片与剂量
- When 保存
- Then 模板与明细均落库，`scope=USER`、`owner_id=本人`
- 验证方式：自动

**AC2（套用生成处方明细）**
- Given 存在模板"逍遥散加减"
- When 在饮片处方中套用，付数传 7
- Then 处方明细 6 味，付数 7，金额按 F112 计算
- 验证方式：自动

**AC3（套用是复制）**【关键】
- Given 套用后修改了原模板的某味剂量
- When 查看已套用的处方
- Then 处方剂量**不变**
- 验证方式：自动

**AC4（模板不豁免规则）**【关键】
- Given 模板含毒性超量饮片，患者无过敏
- When 套用并提交
- Then 同样要求二次确认（F113 AC1）
- 验证方式：自动

**AC5（停用药品跳过但提示）**
- Given 模板含 3 味，其中 1 味已停用
- When 套用
- Then 生成 2 味，返回提示"XX 已停用已跳过"
- 验证方式：自动

**AC6（按证型检索经验方）**
- Given 存在 `syndrome_name='肝郁脾虚'` 的经验方 2 首
- When 按证型检索
- Then 返回这 2 首
- 验证方式：自动

**AC7（付数覆盖）**
- Given 模板默认 7 付
- When 套用传 `doses=14`
- Then 处方付数 14，金额重算（F112 R3）
- 验证方式：自动

**AC8（使用计数递增）**
- Given 模板被套用 3 次
- When 检索模板
- Then `usage_count=3`，排序靠前
- 验证方式：自动

**AC9（越权改他人模板被拒绝）**
- Given 医生 A 的 `USER` 模板
- When 医生 B 尝试修改
- Then 拒绝，写 `audit_permission`
- 验证方式：自动

**AC10（从处方另存为模板）**
- Given 一张已确认处方（5 味）
- When 另存为模板
- Then 新模板 5 味，记录来源处方号
- 验证方式：自动

**AC11（软删）**
- Given 删除模板
- When 查询
- Then 查不到，但物理行仍在（`deleted_at` 非空）
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 缺少模板名称或明细 | 否 |
| E2003 | 引用的药品/饮片不存在 | 否 |
| E6002 | 越权修改他人模板 | 否 |
| E3043 | 套用后计价失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 套用中途失败 | 整体回滚，不留半张处方 |
| 明细含不存在的药品 | 套用前校验，直接拒绝（不套用到一半才报错） |
| 崩溃 | 模板只读数据不写业务表，无半写风险 |
