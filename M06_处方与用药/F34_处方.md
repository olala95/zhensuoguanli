# F34 处方（成药 / 西药）

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: **L — 已拆分为 4 个子项**]

## 1. 职责

开立成药（西药/中成药）处方：选药、录剂量与用法、计价、提交待确认。

---

## 2. 拆分

| 子项 | 内容 | 优先级 |
|---|---|---|
| **F34.1** 处方开立与明细编辑 | 选药、数量、剂量、用法、频次 | P0 |
| **F34.2** 成药计价 | 按契约 §3.1 计算金额 | P0 |
| **F34.3** 处方草稿与提交 | 保存草稿、提交待确认 | P0 |
| **F34.4** 处方修改与复制 | 未确认处方的修改、复诊复制上次方 | P1 |

## 5. 规则

**R1 处方挂 Visit，含患者快照。** 每张处方关联 Visit 与患者，并保存患者姓名/性别/年龄快照。

**R2 明细必填项。** 每行：药品、数量、单次剂量、给药途径、频次、用药天数。**用法用量不能为空**（发药与用药指导需要）。

**R3 库存预检。** 选药时提示库存；**库存不足不阻断开方**（可开方后补货或换药），但明确提示。

**R4 计价按契约。** 行小计 = 单价(分) × 数量，处方金额 = Σ 行小计，**行级舍入**（契约 §3.1）。

**R5 规则校验在提交时触发。** 保存草稿可不校验；**提交（PENDING）时必须完整跑 F35 规则校验**，命中强制项则拒绝提交。

**R6 诊断驱动提示。** 无诊断时提示"当前无诊断"，不阻断，写审计。

**R7 给药途径与频次结构化。** 从字典选择（口服/肌注/静滴/外用…；qd/bid/tid…），便于用药指导（F39）生成。

**R8 草稿可保存。** 未完成的处方可存草稿，崩溃后可恢复（配合 M03 草稿机制）。

**R9 复诊可复制上次方（F34.4）。** 可复制该患者上一次的处方作为模板，**复制后必须可编辑**，且复制行为留痕（不是"一键照抄确认"）。

**R10 一张 Visit 可开多张处方。** 如成药一张、饮片一张（类型不同），或分次开方。

## 6. 验收标准

### F34.1 开立与明细

**AC1（开一张成药处方）**
- Given 患者、Visit、诊断齐备
- When 选药"阿莫西林胶囊"、数量 2 盒、用法"口服 0.5g tid ×3天"
- Then 处方生成，明细完整
- 验证方式：自动

**AC2（用法必填）**
- Given 未填用法用量
- When 提交
- Then 拒绝并提示
- 验证方式：自动

**AC3（库存不足提示不阻断）**
- Given 药品库存不足
- When 开方
- Then 提示库存不足，**允许继续开方**
- 验证方式：自动

**AC4（患者快照）**
- Given 开方时患者姓名"张三"
- When 之后改名
- Then 处方中快照仍为"张三"
- 验证方式：自动

### F34.2 计价

**AC5（行级舍入）**
- Given 单价 3.33 元 × 数量 3
- When 计价
- Then 行小计按契约 §3.1 舍入到分，处方金额为各行之和
- 验证方式：自动

**AC6（金额整数分）**
- Given 处方金额 12.34 元
- When 检查存储
- Then 为整数 1234
- 验证方式：自动

### F34.3 草稿与提交

**AC7（提交触发规则校验）**
- Given 处方含患者过敏药品
- When 提交
- Then F35 强制拦截，提交失败
- 验证方式：自动（跨模块，需 F35 配合）

**AC8（草稿可恢复）**
- Given 处方草稿未提交
- When 强杀进程后重启
- Then 草稿可恢复继续编辑
- 验证方式：自动

**AC9（无诊断提示）**
- Given 无诊断
- When 开方
- Then 提示但不阻断，写审计
- 验证方式：自动

### F34.4 修改与复制

**AC10（未确认可修改）**
- Given 处方处于 DRAFT/PENDING
- When 修改明细
- Then 可修改，写审计
- 验证方式：自动

**AC11（已确认不可直接改）**
- Given 处方 CONFIRMED
- When 尝试修改
- Then 拒绝，需作废重开或走退药
- 验证方式：自动

**AC12（复制上次方可编辑）**
- Given 复制患者上次处方
- When 复制后
- Then 内容填入且**完全可编辑**；复制行为留痕
- 验证方式：自动

**AC13（崩溃一致性）**
- Given 处方保存中强杀
- When 重启
- Then 处方要么完整（含明细与计价）要么不存在
- 验证方式：自动

## 7. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 明细必填缺失 | 否 |
| E3020 | 命中过敏原，强制拦截 | 否（需显式说明） |
| E3033 | 已确认处方不可修改 | 否 |
| E3034 | 库存不足（提示不阻断） | 是 |
| E1010 | 审计写入失败 | 是 |

---

## 8. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 保存失败 | 保留内容重试 |
| 规则校验服务失败 | **拒绝提交**（不允许无校验提交）；提示重试 |
| 崩溃 | 草稿机制 + 事务保护 |
