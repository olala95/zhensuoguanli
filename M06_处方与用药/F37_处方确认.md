# F37 处方确认

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

> **关键不可逆点。** 确认后处方不可直接编辑，已发药不可作废。

---

## 1. 职责

医生对处方做确认签名，使其进入可执行（发药/收费）状态。

---

## 2. 依赖

- 依赖：F34/F111（处方内容）、F35（规则校验）、F36（皮试）、M12
- 被依赖：M07 发药、M09 收费、M10 打印

---

## 3. 涉及的表

`prescription`（M06 自有，写状态与签名）

---

## 4. 规则

**R1 确认前强制校验。**
| 项 | 强度 |
|---|---|
| 规则校验（F35）完整通过 | **强制** |
| 过敏无强制继续的未决项 | **强制** |
| 需皮试药品有有效阴性皮试 | **强制** |
| 明细完整（用法用量） | **强制** |
| 有诊断 | 提示 |
| 库存充足 | 提示 |

**R2 确认即签名。** 记录签名人、时间、方式。签名后处方具备法律效力。

**R3 确认后锁定。** `CONFIRMED` 后不可直接编辑明细；如需修改 → 未发药走作废重开（F38），已发药走退药（M07 F46）。

**R4 确认前预览。** 展示完整处方预览（含金额、用法、皮试状态、规则命中与医生处置），医生确认后签名。

**R5 确认后自动生成账单明细。** 通过 M09 接口向账单添加处方金额明细（**幂等，不重复添加**）。

**R6 确认后进入待发药。** 状态可供 M07 查询并发药。

**R7 中药处方额外校验。** 饮片处方需含脚注、煎法、服法、付数（契约 §8）；缺失则拒绝确认。

**R8 毒性饮片二次确认。** 含毒性饮片且超限量 → 二次确认 + `audit_high_risk`（F113）。

**R9 确认写审计但非高风险。** 正常业务操作写 `audit_operation`；**不是**高风险（高风险是作废、退药）。

**R10 不可取消确认。** 确认后不可回到 PENDING。

## 5. 验收标准

**AC1（正常确认）**
- Given 处方明细完整、规则通过、皮试有效
- When 医生签名确认
- Then 状态 CONFIRMED，签名记录完整，账单新增明细（幂等），审计完整
- 验证方式：自动

**AC2（规则未通过拒绝）**
- Given 存在未处置的过敏强制拦截
- When 确认
- Then 拒绝
- 验证方式：自动

**AC3（皮试缺失拒绝）**
- Given 需皮试药品无有效皮试
- When 确认
- Then 拒绝并引导皮试
- 验证方式：自动

**AC4（确认后锁定）**
- Given 处方 CONFIRMED
- When 尝试修改明细
- Then 拒绝
- 验证方式：自动

**AC5（账单幂等）**
- Given 确认操作重复触发 2 次
- When 检查账单
- Then 只有一行处方明细
- 验证方式：自动（跨模块，需 M09 配合）

**AC6（中药处方必填校验）**
- Given 饮片处方缺煎法或付数
- When 确认
- Then 拒绝并提示
- 验证方式：自动（跨模块，需 F111 配合）

**AC7（毒性饮片二次确认）**
- Given 处方含毒性饮片超限量
- When 确认
- Then 二次确认弹窗，确认后写 `audit_high_risk`
- 验证方式：自动（跨模块，需 F113 配合）

**AC8（不可取消确认）**
- Given 已确认
- When 尝试回到 PENDING
- Then 拒绝
- 验证方式：自动

**AC9（事务性）**
- Given 确认时账单接口失败
- When 执行
- Then 整体回滚，处方保持 PENDING
- 验证方式：自动（注入失败）

**AC10（崩溃一致性）**
- Given 确认执行中强杀
- When 重启
- Then 处方要么 PENDING 要么 CONFIRMED；若 CONFIRMED 则签名与账单明细齐备
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3020 | 过敏未处置 | 否 |
| E3035 | 皮试未满足 | 否 |
| E3038 | 中药处方必填缺失 | 否 |
| E3039 | 处方已确认，不可重复确认 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 签名验证失败 | 不变更状态，可重试 |
| 账单接口失败 | 整体回滚（AC9） |
| 崩溃 | 事务保证；无"已确认无签名/无账单"状态 |
