# F111 中药饮片处方

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: **L — 已拆分为 4 个子项**]

> 新增功能点（中医需求）。饮片处方与成药处方结构完全不同：逐味药 + 剂量 + 脚注 + 付数 + 煎法服法。

---

## 1. 职责

开立中药饮片处方（及颗粒处方）：逐味选药、录剂量与脚注、定付数、写煎法服法。

---

## 2. 拆分

| 子项 | 内容 | 优先级 |
|---|---|---|
| **F111.1** 饮片逐味录入 | 选药、剂量、脚注 | P0 |
| **F111.2** 付数、煎法与服法 | 剂数、煎法、服法、代煎标记 | P0 |
| **F111.3** 颗粒处方 | 按袋/盒计价的颗粒方 | P1 |
| **F111.4** 处方修改与经验方套用 | 编辑、复制、套用 F127 经验方 | P1 |

## 5. 规则

**R1 逐味录入（F111.1）。** 每行一味饮片：饮片名（含炮制规格）、剂量（克）、脚注（先煎/后下/包煎/烊化/冲服/另煎，可空）。

**R2 君臣佐使可标注（可选）。** 支持标注君/臣/佐/使，便于体现配伍思路（P2，可选）。

**R3 付数必填（F111.2）。** 默认取配置 `tcm.default_doses`（默认 7 付）。付数是计价与发药的关键乘数。

**R4 煎法与服法必填。** 煎法（水煎/代煎）、服法（每日几次、饭前/后、温服/冷服）。缺一则**不可确认**（F37 R7）。

**R5 代煎标记。** 标记代煎时计代煎费（F112）并影响 M07 F115 的发药流程。

**R6 味数上限提醒。** 味数超过配置阈值（如 20 味）时提醒（不阻断），避免大处方。

**R7 证型驱动提示。** 读取 M03 F109 的证型与治法，若方药性味方向与治法明显不符（如治法散寒却多用寒凉药）→ **提醒不阻断**（F113）。

**R8 颗粒处方（F111.3）。** 颗粒按袋/盒计价，走成药计价规则，但仍需记录证型与治法。可以做为一个独立处方类型。

**R9 经验方套用（F111.4）。** 可套用 F127 的经验方模板，套用后**必须可编辑**（剂量需随证加减）。

**R10 处方号与成药共用序列。** 类型在字段中（R-M06-1）。

## 6. 验收标准

### F111.1 逐味录入

**AC1（录入饮片方）**
- Given 录入黄芪 15g、白术 10g（炒）、甘草 6g（炙，后下）
- When 保存
- Then 三味药正确存储，含剂量与脚注
- 验证方式：自动

**AC2（脚注可选）**
- Given 某味药无特殊煎法
- When 保存
- Then 脚注为空，允许
- 验证方式：自动

**AC3（君臣佐使标注）**
- Given 标注黄芪为君
- When 保存
- Then 标注正确存储（若实现）
- 验证方式：自动

### F111.2 付数与煎服法

**AC4（付数默认）**
- Given 配置为 7 付
- When 新建饮片处方
- Then 付数默认 7
- 验证方式：自动

**AC5（煎法服法必填）**
- Given 缺服法
- When 确认处方（F37）
- Then 拒绝并提示
- 验证方式：自动（跨模块）

**AC6（代煎标记与费用）**
- Given 标记代煎
- When 计价（F112）
- Then 计代煎费
- 验证方式：自动（跨模块）

**AC7（味数上限提醒）**
- Given 录入 25 味（阈值 20）
- When 保存
- Then 提醒味数较多，不阻断
- 验证方式：自动

### F111.3 颗粒

**AC8（颗粒处方）**
- Given 开颗粒处方，按袋计价
- When 保存与计价
- Then 金额按袋数×单价计算
- 验证方式：自动

### F111.4 修改与套用

**AC9（经验方套用可编辑）**
- Given 套用经验方"玉屏风散"
- When 套用后
- Then 药味与剂量填入，且**全部可编辑**（可加减药味、改剂量）
- 验证方式：自动（跨模块，需 F127 配合）

**AC10（未确认可修改）**
- Given 处方 DRAFT/PENDING
- When 修改某味剂量
- Then 可修改，写审计
- 验证方式：自动

**AC11（证型方向提醒）**
- Given 治法"疏风散寒"，方中多用寒凉药
- When 保存
- Then 给出方向不符提醒，**不阻断**
- 验证方式：自动（跨模块，需 F113 配合）

**AC12（崩溃一致性）**
- Given 处方保存中强杀
- When 重启
- Then 处方要么完整（含全部药味与付数）要么不存在
- 验证方式：自动

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 付数/煎法/服法必填缺失 | 否 |
| E2002 | 剂量格式错误 | 否 |
| E3042 | 味数过多（提醒） | 是 |
| E3033 | 已确认不可修改 | 否 |
| E1010 | 审计写入失败 | 是 |
