# F33 药品搜索

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

在开方、入库等场景中快速定位药品：支持拼音码、通用名、商品名、条码多条件检索。

---

## 2. 依赖

- 依赖：F32 / F110（药品与饮片资料）、M07（库存可用性，只读通过接口）
- 被依赖：F34 / F111（开方）、M07 F40（入库）

---

## 3. 涉及的表

`drug`、`herb`（M06 自有，只读）
**只读** `stock` / `herb_stock`（M07 所有，通过接口或视图）

---

## 4. 规则

**R1 多条件检索。** 支持：拼音首字母（amsl → 阿莫西林）、通用名模糊、商品名模糊、条码精确。

**R2 库存状态可见。** 搜索结果中显示可用库存；**零库存药品仍显示但标记缺货**（医生可能需要换药，需要知道缺什么）。

**R3 停用药品默认隐藏。** 停用药品不在默认结果中；可通过开关查看（历史处方需要）。

**R4 常用药品优先。** 按医生使用频次排序，常用药品前置。

**R5 结果限制。** 单次返回上限（默认 50），超出提示补充条件。

**R6 安全标记可见。** 结果中标记需皮试、抗生素、注射剂、毒性饮片，便于医生开方时注意。

**R7 性能。** 拼音码与名称建索引；响应 < 200ms（开方是高频操作）。

**R8 搜索不写审计。** 高频只读不写审计。

**R9 饮片与成药可切换。** 同一搜索框支持切换成药/饮片/颗粒类别（配合 F111）。

---

## 5. 验收标准

**AC1（拼音码搜索）**
- Given 药品"阿莫西林胶囊"拼音码 amsl
- When 输入"amsl"
- Then 精确定位到该药品
- 验证方式：自动

**AC2（通用名模糊）**
- Given 输入"阿莫"
- When 搜索
- Then 包含所有含"阿莫"的药品
- 验证方式：自动

**AC3（条码精确）**
- Given 扫码枪输入条码
- When 搜索
- Then 精确定位到该药品
- 验证方式：自动（mock 扫码枪）

**AC4（缺货可见）**
- Given 某药库存为 0
- When 搜索
- Then 仍显示但标记"缺货"
- 验证方式：自动

**AC5（停用默认隐藏）**
- Given 药品已停用
- When 默认搜索
- Then 不出现；开启"显示停用"后可查看
- 验证方式：自动

**AC6（常用优先）**
- Given 医生频繁使用某药
- When 搜索（空条件或常用列表）
- Then 该药排在前列
- 验证方式：自动

**AC7（安全标记可见）**
- Given 某药需皮试
- When 搜索结果展示
- Then 有明确"需皮试"标记
- 验证方式：自动

**AC8（性能）**
- Given 药品库 3000 条
- When 执行一次搜索
- Then 响应 < 200ms
- 验证方式：自动（性能断言）

**AC9（结果限制）**
- Given 搜索返回超过 50 条
- When 查看
- Then 返回 ≤50 并提示补充条件
- 验证方式：自动

**AC10（类别切换）**
- Given 开中药处方
- When 切换类别为饮片
- Then 搜索范围变为饮片库（F110）
- 验证方式：自动（跨模块，需 F111 配合）

| 码 | 场景 | 可重试 |
|---|---|---|
| E3006 | 结果过多需补充条件 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 库存接口不可用 | 搜索仍可用，库存列显示"未知"（不阻塞开方搜索） |
| 搜索超时 | 限制返回条数并提示 |
