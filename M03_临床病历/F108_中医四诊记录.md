# F108 中医四诊记录

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

> 新增功能点（中医需求）。原始 107 个功能点中无中医内容，本功能与 F109 补齐中医诊疗核心。

---

## 1. 职责

记录中医望、闻、问、切四诊内容，重点是**舌象与脉象**，为辨证论治（F109）提供依据。

---

## 2. 依赖

- 依赖：M02、M12、M14（`sys_dict` 舌象脉象字典）、M04（AI 语音可采集四诊描述）
- 被依赖：F109（辨证依据）、F19（中医模式必填）、M06 中药处方（辨证驱动）

---

## 3. 涉及的表

`tcm_four_diagnosis`（M03 自有）

---

## 4. 规则

**R1 四诊分栏。** 望诊 / 闻诊 / 问诊 / 切诊 四栏独立记录，可空但中医模式下舌象与脉象必填（R3）。

**R2 舌象结构化。** 分舌质与舌苔：
- 舌质：淡红 / 淡白 / 红 / 绛 / 紫 / 瘀斑（字典多选）
- 舌苔：白 / 黄 / 灰黑 / 无苔；薄 / 厚；润 / 燥 / 腻 / 腐（字典多选）
- 舌形：胖大 / 瘦小 / 齿痕 / 裂纹 / 芒刺（可选）

**R3 脉象结构化（中医模式必填）。** 从字典选择：浮 / 沉 / 迟 / 数 / 弦 / 滑 / 涩 / 细 / 结代 / 洪 / 弱 / 濡 等，支持多选与相兼脉（如"弦滑"）。允许补充文本描述。

**R4 望诊含神色形态。** 神（有神/少神/失神）、色（面色：青赤黄白黑）、形（胖瘦强弱）、态（动静姿态）。

**R5 闻诊与问诊。** 闻诊：声音、气味；问诊：寒热、汗出、头身、二便、饮食、睡眠、胸腹、口渴（十问要点提示）。

**R6 AI 可辅助采集。** 语音中提到的症状可落入问诊栏；舌脉需医生亲自判断，**AI 不得自动生成舌象脉象结论**（这是诊断行为，只能由医生填写）。

**R7 与西医查体区分。** 舌象脉象归本功能，不进 F15 查体（R3 of F15）。

**R8 修改留痕与审计。** 同 F10。确认后修改走 F77。

---

## 5. 验收标准

**AC1（舌象记录）**
- Given 选择舌质"红"、舌苔"黄腻"
- When 保存
- Then 结构化存储正确，展示为"舌红，苔黄腻"
- 验证方式：自动

**AC2（脉象记录）**
- Given 选择脉"弦"+"滑"
- When 保存
- Then 记录为相兼脉"弦滑"
- 验证方式：自动

**AC3（中医模式必填）**
- Given 开启中医模式，未填舌象与脉象
- When 确认病历（F19）
- Then 拒绝并提示补舌脉
- 验证方式：自动

**AC4（非中医模式可选）**
- Given 关闭中医模式
- When 不填四诊直接确认
- Then 允许确认
- 验证方式：自动

**AC5（AI 不自动生成舌脉）**
- Given AI 从语音中提取到"舌红"
- When 落入四诊
- Then 该内容进入**待确认草稿**且明确标记，需医生确认或修改后才成为正式舌象记录；AI 不得直接写入已确认字段
- 验证方式：自动（跨模块，需 M04 配合）

**AC6（十问提示）**
- Given 打开问诊栏
- When 录入
- Then 展示十问要点提示（寒热、汗、头身、二便、饮食、睡眠…）
- 验证方式：自动

**AC7（与查体区分）**
- Given 录入舌象
- When 查看 F15 查体字段
- Then 查体中没有舌象内容
- 验证方式：自动

**AC8（修改留痕）**
- Given 脉象从"弦"改为"弦滑"
- When 保存
- Then 审计含 before/after
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 中医模式下舌脉必填 | 否 |
| E3005 | 已确认不可直接修改 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 字典不可用 | 允许自由文本描述舌脉，标记 `coded=0` |
| 保存失败 | 保留内容重试 |
| 崩溃 | 草稿机制 |

---

## 8. 契约缺口

- 舌象/脉象字典需由 F128.4 或初始化时灌入（属 `sys_dict` 类别）。若 F128.4 延后，需保证初始化时内置基础舌脉字典。
