# F15 查体

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

记录体格检查：一般状况、各系统查体（含中医望诊相关的形体、面色等）、专科检查。

---

## 2. 依赖

- 依赖：M02、M12、F126（模板）、F108（中医四诊中的望诊部分与查体有交集但独立记录）
- 被依赖：F19、M11

---

## 3. 涉及的表

`physical_exam`（M03 自有）

---

## 4. 规则

**R1 分系统记录。** 提供分栏：一般状况 / 头颈 / 胸肺 / 心血管 / 腹部 / 神经系统 / 四肢脊柱 / 专科检查。分栏可空。

**R2 正常描述可快速填充。** 提供"各系统未见异常"一键填充（常用且省时），填充后可编辑。

**R3 与中医四诊区分。** 中医望诊（神色形态、舌象）归 **F108**，不混入西医查体。二者独立记录、独立展示。

**R4 模板支持。** 可套用 F126 模板（如"上呼吸道感染查体模板"），套用后可编辑。

**R5 AI 可预填。** AI 转写中提到的查体描述可落入对应分栏，标记来源。

**R6 非必填。** 允许为空（部分复诊开药场景不查体）。

**R7 修改留痕与审计。** 同 F10。

---

## 5. 验收标准

**AC1（分系统记录）**
- Given 录入"咽部充血，双肺呼吸音清"
- When 保存
- Then 落入对应分栏，正确存储
- 验证方式：自动

**AC2（快速填充正常）**
- Given 点击"各系统未见异常"
- When 填充
- Then 各分栏填入标准正常描述，且**可编辑**
- 验证方式：自动

**AC3（与中医四诊区分）**
- Given 录入舌象"舌红苔黄"
- When 查看查体字段
- Then 该内容不在查体中，而在 F108 中医四诊的舌象字段
- 验证方式：自动

**AC4（模板套用）**
- Given 套用查体模板
- When 保存
- Then 内容填入且可编辑
- 验证方式：自动

**AC5（非必填）**
- Given 查体为空
- When 确认病历
- Then 允许确认
- 验证方式：自动

**AC6（修改留痕）**
- Given 查体内容从 A 改为 B
- When 保存
- Then 审计含 before/after
- 验证方式：自动

**AC7（崩溃保护）**
- Given 编辑中
- When 强杀进程
- Then 草稿恢复，无脏数据
- 验证方式：自动
