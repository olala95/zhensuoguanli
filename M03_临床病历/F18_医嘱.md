# F18 医嘱

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

记录**非药品类**医嘱：处置/治疗、检验申请、复诊建议、生活医嘱、转诊建议、注意事项。

**药品一律走 M06 处方，本功能不承载药品。**

---

## 2. 依赖

- 依赖：M02、M12、M05（检验医嘱触发开单）、M08（处置医嘱触发执行）
- 被依赖：M08（处置执行依据）、M05（检验开单依据）、M10（打印给患者的医嘱单）

---

## 3. 涉及的表

`medical_order`（M03 自有）

---

## 4. 规则

**R1 明确不含药品（R-M03-9）。** 药品只能通过 M06 处方开立。若医嘱中出现药品名称，提示"请通过处方开立药品"。

**R2 分类。** 处置治疗 / 检验检查 / 复诊 / 生活调护 / 转诊 / 其他。分类便于后续统计与执行。

**R3 可触发下游单据。** 处置类医嘱可一键转为 M08 处置执行单；检验类医嘱可一键转为 M05 检验申请单。**转化后医嘱保留，并与生成的单据建立关联**。

**R4 自由文本 + 结构化并存。** 生活医嘱、注意事项为自由文本；处置与检验类尽量结构化（关联项目）。

**R5 患者可见部分。** 医嘱中标记"患者可见"的内容会出现在给患者的医嘱单（M10 打印）中。默认处置与检验可见，内部备注不可见。

**R6 非必填。** 允许无医嘱。

**R7 与中医治法衔接。** F109 辨证论治产生的"治法"可作为处置类医嘱的来源（如"针灸治疗"）。

**R8 修改留痕与审计。** 同 F10。已确认病历中的医嘱修改走 F77。

---

## 5. 验收标准

**AC1（录入口服以外的医嘱）**
- Given 录入"清淡饮食，多饮水"（生活医嘱）与"3 天后复诊"（复诊医嘱）
- When 保存
- Then 分类存储正确
- 验证方式：自动

**AC2（药品拦截提示）**
- Given 在医嘱中录入"阿莫西林 0.5g tid"
- When 保存
- Then 提示"药品请通过处方开立"，并给出跳转 M06 的入口
- 验证方式：自动

**AC3（转为处置执行）**
- Given 录入处置医嘱"针灸治疗"
- When 点击转为执行单
- Then 生成 M08 处置执行单，医嘱保留并与之关联
- 验证方式：自动（跨模块，需 M08 配合）

**AC4（转为检验申请）**
- Given 录入检验医嘱"血常规"
- When 点击转为检验申请
- Then 生成 M05 检验申请单，医嘱保留并关联
- 验证方式：自动（跨模块，需 M05 配合）

**AC5（患者可见标记）**
- Given 医嘱含处置（患者可见）与内部备注（不可见）
- When 打印给患者的医嘱单
- Then 仅显示患者可见部分
- 验证方式：自动（跨模块，需 M10 配合）

**AC6（非必填）**
- Given 无医嘱
- When 确认病历
- Then 允许确认
- 验证方式：自动

**AC7（中医治法衔接）**
- Given F109 中治法为"疏风清热，针灸辅助"
- When 生成医嘱
- Then 可一键生成处置类医嘱"针灸治疗"
- 验证方式：自动（跨模块，需 F109 配合）

**AC8（修改留痕）**
- Given 医嘱从 A 改为 B
- When 保存
- Then 审计含 before/after
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3024 | 医嘱中疑似含药品，请走处方 | 否 |
| E3005 | 已确认不可直接修改 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 下游模块不可用（M05/M08） | 医嘱仍可保存为文本，转化功能暂不可用并提示 |
| 保存失败 | 保留内容重试 |
| 崩溃 | 草稿机制 |
