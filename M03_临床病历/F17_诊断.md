# F17 诊断

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

记录本次就诊的诊断：西医诊断（ICD-10）与中医病证诊断（病名 + 证型），支持主诊断/次诊断排序。

---

## 2. 依赖

- 依赖：M14（诊断字典，由 F128.4 导入）、F109（中医证型）、M12
- 被依赖：**M06 处方**（诊断驱动，F34/F111 需校验有诊断）、M15 报表（疾病谱统计）、M11 归档

---

## 3. 涉及的表

`diagnosis`（M03 自有，含西医与中医诊断）

---

## 4. 规则

**R1 双轨诊断。** 一条诊断记录包含类型标记：
- `WEST`：西医诊断，ICD-10 编码 + 名称
- `TCM_DISEASE`：中医病名
- `TCM_SYNDROME`：中医证型（通常由 F109 写入，此处展示）

**R2 主诊断唯一。** 每次就诊**有且仅有一条主诊断**（`is_primary=1`），其余为次诊断。

**R3 必填（确认前）。** 病历确认前至少有一条诊断。若确实无法确诊，允许使用"待查"类诊断（如"发热待查"），但必须选择这类明确编码而非留空。

**R4 编码优先。** 西医诊断优先从 ICD-10 字典选择（支持编码搜索与拼音/名称模糊搜索）。字典无匹配时允许自由文本，标记 `coded=0`。

**R5 中医诊断跟随病名+证型。** 若开启中医模式，中医病名与证型需成对（有病名必须有证型）。

**R6 常用诊断快捷。** 提供医生个人常用诊断（按使用频次排序）与科室常用诊断。

**R7 诊断驱动处方。** M06 开方时校验：无诊断 → 提示（不强制，急诊可跳过但写审计）。

**R8 修改留痕。** 确认后修改诊断走 M11 F77 版本留痕；诊断变更影响处方合理性，因此变更后提示复核处方。

**R9 统计口径。** 疾病谱统计（M15 F123）按 ICD-10 编码或中医证型分组（契约 §7）。

## 5. 验收标准

**AC1（西医诊断录入）**
- Given 选择 ICD-10 编码 J06.9（急性上呼吸道感染）
- When 保存为主诊断
- Then 落库含编码与名称，`is_primary=1`
- 验证方式：自动

**AC2（主诊断唯一）**
- Given 已有主诊断 A
- When 将 B 设为主诊断
- Then A 自动降为次诊断，`is_primary=1` 仅 B 一条
- 验证方式：自动

**AC3（确认前必填）**
- Given 无任何诊断
- When 确认病历
- Then 拒绝并提示至少一条诊断（可使用"待查"）
- 验证方式：自动

**AC4（中医病名与证型成对）**
- Given 开启中医模式，录入中医病名"感冒"
- When 未录入证型就确认
- Then 拒绝并提示需补证型
- 验证方式：自动

**AC5（模糊搜索）**
- Given 诊断字典 5000 条
- When 搜索"上呼吸道"或"shxd"
- Then 可定位到对应编码
- 验证方式：自动

**AC6（自由文本诊断）**
- Given 字典中无匹配
- When 手工录入诊断名称
- Then 保存成功，标记 `coded=0`
- 验证方式：自动

**AC7（诊断驱动处方提示）**
- Given 无诊断
- When 开处方
- Then 提示"当前无诊断"但不阻断；跳过写审计
- 验证方式：自动（跨模块，需 M06 配合）

**AC8（常用诊断排序）**
- Given 医生多次使用某诊断
- When 打开诊断选择
- Then 该诊断排在常用列表前列
- 验证方式：自动

**AC9（变更后提示复核处方）**
- Given 已开处方后修改主诊断
- When 保存诊断变更
- Then 提示"诊断已变更，请复核处方"
- 验证方式：自动

**AC10（统计可分组）**
- Given 多条 ICD-10 诊断
- When M15 统计疾病谱
- Then 可按编码分组计数
- 验证方式：自动（跨模块，需 M15 配合）

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 诊断必填缺失 | 否 |
| E3022 | 主诊断不唯一 | 否 |
| E3023 | 中医病名缺证型 | 否 |
| E3005 | 已确认不可直接修改 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 字典不可用 | 允许自由文本诊断（`coded=0`），不阻塞 |
| 保存失败 | 保留内容重试 |
| 崩溃 | 草稿机制 |
