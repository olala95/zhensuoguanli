# F16 辅助检查记录

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

在病历中**引用**本次就诊相关的检验检查结果（引用 M05 的结果），并记录院内即时检查（如血糖仪、心电图）的简单结果。

---

## 2. 依赖

- 依赖：M05（外送检验结果，只读引用）、M02、M12
- 被依赖：F19、M11、M04（AI 可读取辅助检查结果生成草稿）

---

## 3. 涉及的表

`record_exam_ref`（M03 自有，存引用）
**只读** `lab_result`（M05 所有，通过接口或 `v_` 视图）

---

## 4. 规则

**R1 只存引用不复制。** 外送检验结果**不复制文本**进病历，只存对 `lab_result` 的引用（含结果 ID 与快照摘要）。避免数据双写不一致。

**R2 摘要快照允许。** 引用的同时可存一句摘要（如"血常规示白细胞升高"），但摘要与源数据的关系明确标注为引用。

**R3 源数据变更时提示。** 若被引用的检验结果被更正（M05），病历中提示"引用的结果已于 X 时间更新"，但已确认病历的内容不自动改（归档不可变）。

**R4 支持即时检查记录。** 院内即时检查（血糖、心电图、尿常规试纸）可直接在病历中记录结果文本与图片附件，不走 M05。

**R5 未回报的外送项目也显示。** 已开单但未回报的检验项目在病历中显示为"已开单待回报"，不误认为未做。

**R6 非必填。** 允许为空。

**R7 引用删除需谨慎。** 删除引用不影响 M05 中的原始结果（引用是单向的）。

**R8 修改留痕与审计。** 同 F10。

---

## 5. 验收标准

**AC1（引用外送结果）**
- Given M05 中有一份已回报的血常规结果
- When 在病历中引用该结果
- Then `record_exam_ref` 记录引用关系，病历中显示结果摘要而不复制全文
- 验证方式：自动（跨模块，需 M05 配合）

**AC2（源数据变更提示）**
- Given 引用的结果被 M05 更正
- When 查看病历
- Then 提示"引用的结果已于 X 更新"，已确认病历内容不被自动修改
- 验证方式：自动

**AC3（即时检查记录）**
- Given 记录即时血糖值 8.5 mmol/L
- When 保存
- Then 直接存入病历，不经过 M05
- 验证方式：自动

**AC4（待回报显示）**
- Given 已开单但结果未回报
- When 查看病历辅助检查
- Then 显示"已开单待回报"，不显示为空白
- 验证方式：自动

**AC5（删除引用不影响源）**
- Given 删除病历中的一条引用
- When 检查 M05
- Then 原始检验结果仍存在且完整
- 验证方式：自动

**AC6（非必填）**
- Given 无辅助检查
- When 确认病历
- Then 允许确认
- 验证方式：自动

**AC7（修改留痕）**
- Given 修改引用或摘要
- When 保存
- Then 审计含 before/after
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3007 | 已确认不可直接修改（修改须走 M11 F77 留痕流程） | 否 |
| E3021 | 引用的检验结果 / 检查申请不存在或已作废 | 否 |
| E2001 | 必填缺失或参数非法（即时检查缺值、即时检查带 M05 单据、ref_type 非法） | 否 |

> 修订：原草稿写的 E3005 与 M06「配伍禁忌」撞码（见 `03_GLOBAL_CONTRACTS` §6），
> "已确认不可直接修改"统一用 E3007。

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| M05 接口不可用 | 允许记录文本形式的即时检查；引用功能暂不可用并提示 |
| 引用的结果被删除 | 提示引用失效，允许移除引用；已确认病历不自动改 |
