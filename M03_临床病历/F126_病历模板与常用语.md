# F126 病历模板与常用语

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: M]

> 新增功能点（原始 107 个功能点中缺失）。AI 能生成草稿，但日接诊量大的诊所，医生要的是模板秒开。

---

## 1. 职责

提供病历模板（按病种/证型）与常用语（短语库）的管理与套用，提高书写效率。

---

## 2. 依赖

- 依赖：M14（用户上下文、配置）、M12、F17（诊断字典，模板可关联诊断）
- 被依赖：F10/F11/F15（套用）、F19（未修改提示）

---

## 3. 涉及的表

`record_template`（M03 自有）

---

## 4. 规则

**R1 模板分类。** 按类型分：全病历模板（覆盖主诉/现病史/查体等）、段落模板（单字段）、常用语（短语）。

**R2 模板可关联诊断。** 模板可绑定 ICD-10 编码或中医证型；选择诊断后自动推荐对应模板。

**R3 模板含变量。** 支持变量占位符（如 `{患者姓名}` `{年龄}` `{日期}`），套用时自动替换。

**R4 套用后必须可编辑（R-M03-10）。** 套用是填充不是锁定；全部内容可改。

**R5 整份未修改需提示。** F19 确认时检测病历与模板高度一致 → 提示复核（防止"千人一面"的病历）。

**R6 模板归属与共享。** 模板分个人模板与公共模板。个人模板仅本人可见可改；公共模板管理员维护。**医生不得修改他人个人模板。**

**R7 常用语快捷插入。** 常用语支持快捷码（如输入 `;` + 简码触发），插入后可编辑。

**R8 中医模板。** 支持中医病证模板（含四诊、辨证、治法预填），套用后仍需医生核实舌脉。

**R9 模板变更留痕。** 模板本身的增删改写审计；模板修改**不影响已套用并保存的病历**（病历是独立数据）。

## 5. 验收标准

**AC1（创建模板）**
- Given 医生创建全病历模板"上呼吸道感染"
- When 保存为个人模板
- Then 模板落库，仅本人可见
- 验证方式：自动

**AC2（套用填充）**
- Given 套用"上呼吸道感染"模板
- When 套用
- Then 主诉/现病史/查体等字段被填充，且**全部可编辑**
- 验证方式：自动

**AC3（变量替换）**
- Given 模板含 `{患者姓名}` `{年龄}`
- When 套用到患者"张三（36岁）"
- Then 替换为"张三""36岁"
- 验证方式：自动

**AC4（诊断推荐模板）**
- Given 诊断选择 J06.9
- When 打开病历
- Then 推荐关联该诊断的模板
- 验证方式：自动

**AC5（整份未修改提示）**
- Given 套用模板后完全未修改
- When 确认病历
- Then 提示"内容与模板一致，请复核个体化信息"
- 验证方式：自动

**AC6（常用语快捷插入）**
- Given 常用语"咽部充血"绑定简码 `ygch`
- When 在编辑器输入 `;ygch`
- Then 插入"咽部充血"，可继续编辑
- 验证方式：自动

**AC7（个人模板隔离）**
- Given 医生 A 的个人模板
- When 医生 B 查看模板列表
- Then 看不到 A 的个人模板；公共模板可见
- 验证方式：自动

**AC8（模板修改不影响历史病历）**
- Given 某病历套用了模板 T 并已确认
- When 修改模板 T 的内容
- Then 该历史病历内容**不变**
- 验证方式：自动

**AC9（中医模板）**
- Given 创建中医模板"风寒感冒"（含四诊、证型、治法预填）
- When 套用
- Then 四诊栏被填充，但**舌脉需医生亲自核实填写**（不预填舌脉结论）
- 验证方式：自动

**AC10（模板审计）**
- Given 修改公共模板
- When 保存
- Then 写审计（管理员操作写 `audit_high_risk`）
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 模板名称必填 | 否 |
| E6002 | 无权限修改他人/公共模板 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 套用失败 | 不影响已有内容；提示重试 |
| 模板保存失败 | 保留编辑内容重试 |
| 崩溃 | 模板本身是配置类数据，由事务保护 |
