# F12 既往史 / 个人史

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

记录患者既往疾病史、手术外伤史、输血史、个人史（吸烟饮酒职业）、家族史、月经婚育史。

**其中"既往史"在多次就诊间可复用**——这是本功能与其他病历字段最大的区别。

---

## 2. 依赖

- 依赖：M01（患者，历史数据复用）、M12
- 被依赖：F19、M06（处方规则可参考既往史）

---

## 3. 涉及的表

`record_history`（M03 自有）

---

## 4. 规则

**R1 分类记录。** 分栏：既往疾病史 / 手术外伤史 / 输血史 / 个人史 / 家族史 / 月经婚育史。各栏独立可空。

**R2 跨就诊复用。** 上次就诊的既往史**自动带出**到本次，医生可增改（不删历史内容，采用追加方式）。这是提高效率的关键。

**R3 复用需医生确认。** 自动带出的内容标记为"来自上次就诊（日期）"，医生需确认或编辑后才算本次记录（防止错误继承）。

**R4 重要既往史标记。** 可标记某些条目为"重要"（如高血压、糖尿病、心脏病），标记项在工作台顶部与处方规则中提示。

**R5 与过敏史分开。** 过敏史归 F13，不混入既往史（过敏是安全红线，需要独立且强制的展示逻辑）。

**R6 非必填。** 首次就诊无法采集时可空，但"未采集"与"确认无"要区分（标记 `not_collected` vs `confirmed_none`）。

**R7 修改留痕与审计。** 同 F10。

---

## 5. 验收标准

**AC1（分类记录）**
- Given 录入既往史"高血压 5 年"与个人史"吸烟 20 年"
- When 保存
- Then 分栏存储正确
- 验证方式：自动

**AC2（跨就诊复用）**
- Given 患者上次就诊记录过"高血压 5 年"
- When 本次就诊打开既往史
- Then 自动带出该内容，标注"来自 2026-09-01 就诊"
- 验证方式：自动

**AC3（复用需确认）**
- Given 带出的既往史
- When 医生未做任何操作直接确认病历
- Then 提示"既往史来自历史记录，请确认"；确认后标记本次已核实
- 验证方式：自动

**AC4（追加不覆盖）**
- Given 历史有"高血压"
- When 本次新增"糖尿病"
- Then 两条都存在，历史内容未被覆盖
- 验证方式：自动

**AC5（重要标记）**
- Given 标记"高血压"为重要既往史
- When 查看工作台
- Then 顶部展示该标记
- 验证方式：自动

**AC6（未采集 vs 确认无）**
- Given 医生未填写既往史
- When 查看记录
- Then 状态为"未采集"；医生点击"确认无既往史"后状态变为"确认无"
- 验证方式：自动

**AC7（修改留痕）**
- Given 既往史从 A 改为 B
- When 保存
- Then `audit_data_change` 含 before/after
- 验证方式：自动

**AC8（过敏史不混入）**
- Given 录入青霉素过敏
- When 查看既往史字段
- Then 该内容不在既往史中，而在 F13 过敏史中
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3005 | 已确认不可直接修改 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 复用查询失败 | 允许空既往史继续，不阻塞 |
| 保存失败 | 保留内容重试 |
| 崩溃 | 由草稿机制保护 |
