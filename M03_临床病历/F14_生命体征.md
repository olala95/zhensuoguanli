# F14 生命体征

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

记录体温、脉搏、呼吸、血压、血氧、体重、身高，支持一次就诊多次记录。

---

## 2. 依赖

- 依赖：M02、M12、M14（单位与正常范围参考值配置）
- 被依赖：F19、M04（AI 风险提醒 F25 可消费异常值）、M11

---

## 3. 涉及的表

`vital_sign`（M03 自有，按次记录）

---

## 4. 规则

**R1 多次记录。** 一次 Visit 可记录多组生命体征，每组带记录时间。列表按时间倒序展示。

**R2 字段与单位固定。** 体温 ℃、脉搏 次/分、呼吸 次/分、血压 mmHg（收缩压/舒张压）、血氧 %、体重 kg、身高 cm。单位固定，不允许自定义。

**R3 范围校验。** 输入超出**生理可能范围**（如体温 80℃、血压 500）→ 拒绝并提示录入错误。超出**正常参考范围**（如体温 39℃）→ 标记异常但不拒绝。

**R4 异常值高亮。** 超出参考范围的值界面高亮显示，便于医生快速识别。

**R5 BMI 自动计算。** 有身高与体重时自动计算 BMI 并展示。

**R6 血压格式。** 收缩压/舒张压，校验收缩压 > 舒张压。

**R7 非必填。** 部分就诊（如单纯开药）可能不测生命体征，允许为空。

**R8 儿科参考范围。** 若患者为儿童（按出生日期计算），使用儿科参考范围（心率、呼吸正常值不同于成人）。

**R9 修改留痕与审计。** 同 F10。

## 5. 验收标准

**AC1（基本记录）**
- Given 录入体温 36.5、脉搏 72、血压 120/80
- When 保存
- Then 正确落库，关联 Visit
- 验证方式：自动

**AC2（多次记录）**
- Given 已记录一组
- When 再记录一组
- Then 存在两组独立记录，按时间倒序展示
- 验证方式：自动

**AC3（生理不可能值拒绝）**
- Given 输入体温 80℃
- When 保存
- Then 拒绝并提示录入错误
- 验证方式：自动

**AC4（异常值高亮不拒绝）**
- Given 输入体温 39.2℃
- When 保存
- Then 保存成功，界面高亮该值为异常
- 验证方式：自动

**AC5（血压格式校验）**
- Given 输入 80/120（收缩压 < 舒张压）
- When 保存
- Then 拒绝并提示
- 验证方式：自动

**AC6（BMI 自动计算）**
- Given 身高 170cm、体重 65kg
- When 保存
- Then 自动显示 BMI ≈ 22.5
- 验证方式：自动

**AC7（儿科参考范围）**
- Given 患者为 3 岁儿童
- When 录入脉搏 110
- Then **不标记为异常**（儿童正常心率高于成人）
- 验证方式：自动

**AC8（非必填）**
- Given 未录入任何生命体征
- When 确认病历
- Then 允许确认，不阻断
- 验证方式：自动

**AC9（修改留痕）**
- Given 体温从 36.5 改为 37.0
- When 保存
- Then `audit_data_change` 含 before/after
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2002 | 数值格式错误 | 否 |
| E2003 | 超出生理可能范围 | 否 |
| E3005 | 已确认不可直接修改 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 保存失败 | 保留输入内容重试 |
| 崩溃 | 草稿机制 |
| 参考范围配置缺失 | 使用内置默认值，不阻断录入 |
