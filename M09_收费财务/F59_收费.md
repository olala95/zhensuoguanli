# F59 收费

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

收款：支持现金、微信、支付宝、银行卡、其他；一次账单可多笔支付，但**合计必须等于应收**（无部分支付）。

---

## 2. 依赖

- 依赖：F58（账单 PENDING）、M12
- 被依赖：F61（退款）、F62（冲正）、F64（日结）、M10 F68（凭条）、M15 F119（营收归集按 `paid_at`）

---

## 3. 涉及的表

`payment`、`payment_status_log`、`bill`、`bill_status_log`

---

## 4. 规则

**R1 支付状态机（契约 §2.6）。** `INIT → SUCCESS | FAILED`；`SUCCESS → REFUNDED | REVERSED`；`FAILED` 为终态，可重新发起**新支付**（不复用原记录）。

**R2 无部分支付。** 多笔支付合计 = 应收 → 账单转 `PAID`；否则**全部支付标记失败并退回账单 PENDING**，不留中间态（R-M09-2）。

**R3 同事务。** 写支付记录 + 账单转 `PAID` + 状态日志在同一 `db.tx()`；失败整体回滚（故障演练 #2：不出现"已扣款无账单"）。

**R4 支付方式字典化。** `channel` ∈ `CASH / WECHAT / ALIPAY / CARD / OTHER`（01 §5）。

**R5 时间归集口径。** `paid_at` 为营收归集时间（03 §7），取系统时间，**不接受外部传入**。

**R6 幂等。** 同一 `idempotent_key` 重复提交只产生一笔支付，防重复扣款（R-M09-12）。

**R7 渠道凭证号。** 第三方支付记录 `trade_no`，便于对账与退款。

**R8 找零与实收。** 现金记录 `received_amount_fen` 与 `change_amount_fen`（找零 = 实收 − 应收），**账单金额不变**。

**R9 已收费账单不可重复收。** `PAID` 账单再收 → 拒绝（E3072）。

**R10 高风险审计。** 收费本身非高风险，但**失败重试**、**作废后重收**需留痕。

## 5. 验收标准

**AC1（全额付清）**
- Given 账单 6525 分
- When 微信支付 6525 分
- Then 账单 `PAID`，支付 `SUCCESS`，`paid_at` 已记录
- 验证方式：自动

**AC2（多笔混合支付）**
- Given 应收 6525 分
- When 现金 1000 + 微信 5525
- Then 账单 `PAID`，两笔支付均 SUCCESS
- 验证方式：自动

**AC3（金额不足不留中间态）**
- Given 应收 6525
- When 只付 5000
- Then 拒绝，账单仍 `PENDING`，不产生部分支付状态
- 验证方式：自动

**AC4（现金找零）**
- Given 应收 6525，实收 7000
- When 现金支付
- Then `change_amount_fen=475`，账单金额仍 6525
- 验证方式：自动

**AC5（幂等防重复）**
- Given 同 `idempotent_key` 提交两次
- When 第二次
- Then 只有一笔支付，账单只转一次 PAID
- 验证方式：自动

**AC6（崩溃一致）**
- Given 支付事务中途强杀
- When 重启
- Then 账单与支付记录要么都在要么都不在，**不出现已扣款无账单**
- 验证方式：自动（故障演练 #2）

**AC7（重复收费被拒）**
- Given 账单已 PAID
- When 再次支付
- Then 拒绝 E3072
- 验证方式：自动

**AC8（支付失败可重试）**
- Given 一笔 FAILED 支付
- When 重新发起支付
- Then 生成**新**支付记录，原 FAILED 记录保留
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3072 | 账单已收费，不可重复支付 | 否 |
| E3073 | 支付金额与应收不符 | 否 |
| E3006 | 当日已日结 | 否 |
| E3001 | 账单状态不允许支付 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 支付事务中断 | 整体回滚，账单保持 PENDING，可重新支付 |
| 第三方渠道超时 | 标记 FAILED 并允许发起新支付；**不得自动冲正**（需人工确认） |
| 重复提交 | 幂等键拦截 |
