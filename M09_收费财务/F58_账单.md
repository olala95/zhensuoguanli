# F58 账单

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: L（拆 F58.1 汇总 / F58.2 生成 / F58.3 作废）]

---

## 1. 职责

**F58.1 汇总**：把一个 Visit 的应付项（处方 / 处置 / 检验 / 自动收费项目）聚合成明细清单。
**F58.2 生成**：写入 `bill` + `bill_item`，单号 `B{yyyyMMdd}{4位}`，状态 `PENDING`。
**F58.3 作废**：`PENDING → VOID`，必须填原因。

---

## 2. 依赖

- 依赖：M06（处方计价结果，**只读**）、M08（处置执行金额快照，**只读**）、M05（检验申请明细价，**只读**）、F57（收费项目）、M02（Visit）
- 被依赖：F59（收费）、F61（退款）、F62（冲正）、M10 F68（凭条）、M15 F119/F120

---

## 3. 涉及的表

`bill`、`bill_item`、`bill_status_log`（M09 自有；上游表只读）

---

## 4. 规则

**R1 汇总来源与口径（R-M09-1）。**

| 来源 | 取数 | 金额 |
|---|---|---|
| 成药处方 | M06 `prescription` CONFIRMED+ | `prescription_pricing.total_amount_fen` |
| 饮片处方 | M06 `prescription` 同上 | 同上（含代煎费与包装费） |
| 处置 | M08 `treatment_execution` 非 CANCELLED | `amount_fen`（快照价 × 数量） |
| 检验 | M05 `lab_order_item` | 项目收费价 × 数量 |
| 自动收费项目 | F57 `auto_add_on_visit=1` | `price_fen` |

**R2 明细行只增不改。** `bill_item` 只允许 INSERT；作废走账单状态，不删明细（R-M09-3）。

**R3 单号与唯一性。** `B{yyyyMMdd}{4位}`，事务内取号；**一个 Visit 最多一张有效账单**（已存在非 VOID 账单时拒绝重建，E3070）。

**R4 明细可溯源。** 每行记 `source_type`（DRUG/HERB/TREATMENT/LAB/CHARGE）与 `source_id`，反查上游单据。

**R5 名称与单价快照。** 明细记 `name_snap` / `unit_price_fen` / `quantity` / `amount_fen`，上游调价不追溯。

**R6 状态机（契约 §2.5）。** `PENDING → PAID | VOID`；生成即 `PENDING`，写状态日志。

**R7 作废必填原因。** `VOID` 必须填原因并写 `audit_high_risk`；已收费账单**不可作废**，只能退款/冲正（E3071）。

**R8 日结锁定。** 当日已日结 → 生成当日新账单被拒（E3006）。

**R9 金额整数分。** 总额 = Σ 明细 `amount_fen`，不做二次舍入（契约 §3）。

## 5. 验收标准

**AC1（汇总完整）**
- Given 就诊含 1 张饮片处方（525 分）、1 项处置（2000 分）、1 项检验（3000 分）、挂号费 1000 分
- When 生成账单
- Then 明细 4 行，总额 `6525` 分
- 验证方式：自动

**AC2（处方未确认不计入）**
- Given 处方仍为 DRAFT/PENDING
- When 生成账单
- Then 不含该处方行
- 验证方式：自动

**AC3（取消的处置不计入）**
- Given 处置已 CANCELLED
- When 生成账单
- Then 不含该行
- 验证方式：自动

**AC4（单号格式与唯一）**
- Given 生成账单
- When 查单号
- Then 形如 `B{yyyyMMdd}{4位}`，同 Visit 不可生成第二张有效账单（E3070）
- 验证方式：自动

**AC5（金额快照不追溯）**
- Given 生成后上游调价
- When 重查账单
- Then 明细金额不变
- 验证方式：自动

**AC6（作废必填原因）**
- Given PENDING 账单未填原因作废
- When 提交
- Then 拒绝 E2001
- 验证方式：自动

**AC7（已收费不可作废）**
- Given 账单 PAID
- When 作废
- Then 拒绝 E3071
- 验证方式：自动

**AC8（明细不可删）**
- Given 已生成明细
- When 尝试 DELETE
- Then 数据库拒绝 E2006
- 验证方式：自动

**AC9（崩溃一致）**
- Given 生成账单事务中途强杀
- When 重启
- Then 账单与明细要么全在要么全不在，不出现"有账单无明细"
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3070 | 该就诊已存在有效账单 | 否 |
| E3071 | 已收费账单不可作废 | 否 |
| E3006 | 当日已日结，不可生成/修改账单 | 否 |
| E2006 | 尝试删除账单明细 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 生成中途断电 | 事务回滚，可重新生成（单号跳号允许） |
| 上游数据异常（如处方未计价） | 拒绝生成并明确指出缺失项，不静默按 0 计 |
