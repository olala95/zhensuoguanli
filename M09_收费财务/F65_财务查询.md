# F65 财务查询

[TYPE: FEATURE] [PRIORITY: P1] [SIZE: M]

---

## 1. 职责

面向收费员与管理员的日常财务查询：账单查询、收款流水、退款流水、日结查询、按患者/就诊/时间维度的对账视图。

> **注意**：经营分析类报表（营收趋势、客单价、疾病谱等）归 **M15**，本 F 只做**交易级查询**，不做分析聚合（避免口径分裂）。

---

## 2. 依赖

- 依赖：F58/F59/F61/F62/F64（全部交易数据）
- 被依赖：M10 F68（凭条重打定位）、M15 F119（报表取数同源于此）

---

## 3. 涉及的表

`bill`、`bill_item`、`payment`、`refund`、`reversal`、`day_settlement`（**全部只读**）

---

## 4. 规则

**R1 只读。** 本 F 不产生任何业务写入，不写流水；查询不写审计（审计只记录写操作，避免噪声）。

**R2 查询维度。** 账单号 / 患者 / 就诊 / 日期区间 / 账单状态 / 支付渠道 / 日结单。

**R3 金额一律以分返回。** 展示层除以 100；接口返回同时给 `*_fen` 与格式化字符串（UI 直接用）。

**R4 净额口径统一。** 账单净额 = Σ `bill_item.amount_fen`（含负数冲正行）；已退 = Σ `refund.amount(SUCCESS)`。

**R5 分页与上限。** 结果集强制分页（默认 50，上限 200），避免单机大查询卡界面。

**R6 越权控制。** 财务查询需 `finance.view` 权限；越权拒绝并写 `audit_permission`（03 §9）。

**R7 可定位凭条重打。** 查询结果携带 `bill_id` 与 `payment_id`，供 M10 F70 重打凭条（不产生新单据号）。

---

## 5. 验收标准

**AC1（按日期查账单）**
- Given 当日多张账单
- When 按日期查询
- Then 返回全部且含状态与金额
- 验证方式：自动

**AC2（按患者查）**
- Given 某患者多次就诊
- When 按患者查询
- Then 返回其全部账单与净额合计
- 验证方式：自动

**AC3（支付流水查询）**
- Given 多笔支付
- When 按渠道与时间查询
- Then 笔数与金额与日结分项一致
- 验证方式：自动

**AC4（查询不产生写入）**
- Given 连续查询 100 次
- When 对比审计条数
- Then 无新增 `audit_operation`
- 验证方式：自动

**AC5（分页上限）**
- Given 请求 limit=10000
- When 查询
- Then 被限制为 200 且不报错
- 验证方式：自动

**AC6（越权拒绝）**
- Given 医生角色调用财务查询
- When 请求
- Then 拒绝 E6002 且写 `audit_permission`
- 验证方式：自动

**AC7（与日结一致）**
- Given 当日全部收款与退款
- When 用查询结果自行汇总
- Then 与日结单的实收/退款/净收一致
- 验证方式：自动（跨 F64）
