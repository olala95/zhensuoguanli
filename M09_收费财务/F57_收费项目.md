# F57 收费项目

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

**非药品、非处置**的收费项目目录：挂号费、诊查费、病历工本费、耗材费等。药品走 M06、处置走 M08、检验走 M05，本目录不重复承载。

---

## 2. 依赖

- 依赖：M14（字典与 F128 导入）、M12
- 被依赖：F58（账单生成时并入）、M15 F119

---

## 3. 涉及的表

`charge_item`（M09 自有）

---

## 4. 规则

**R1 编码唯一。** `item_code` 唯一索引；导入按编码 upsert。

**R2 类别字典化。** `category` 取自 `sys_dict`（`CHARGE_CATEGORY`）：`REGISTRATION 挂号 / CONSULT 诊查 / MATERIAL 耗材 / SERVICE 服务 / OTHER 其他`。

**R3 单价整数分。** `price_fen` INTEGER；调价不追溯已生成的账单明细（R-M09-1 同族）。

**R4 自动挂账标记。** `auto_add_on_visit=1` 的项目（如挂号费）在创建账单时自动并入，**不需人工逐项添加**。

**R5 停用不删除。** `is_active=0`；已被引用的项目不得物理删除。

**R6 与处置项目的边界。** 任何"需要做、需要记录执行过程"的项目归 M08 `treatment_item`；只有**无需执行记录**的收费项放这里（如挂号费）。

---

## 5. 验收标准

**AC1（建档）**
- Given 编码 `GH001`、名称"普通挂号费"、1000 分
- When 创建
- Then 成功，编码唯一
- 验证方式：自动

**AC2（重复编码被拒）**
- Given 已存在 `GH001`
- When 再建
- Then 拒绝 E2004
- 验证方式：自动

**AC3（自动并入账单）**
- Given 挂号费 `auto_add_on_visit=1`
- When 生成账单
- Then 明细自动含该行
- 验证方式：自动（跨 F58）

**AC4（停用后不再并入）**
- Given 项目停用
- When 生成账单
- Then 不含该行，历史账单不受影响
- 验证方式：自动

**AC5（调价不追溯）**
- Given 账单已生成后调价
- When 查该账单明细
- Then 金额仍按生成时价
- 验证方式：自动
