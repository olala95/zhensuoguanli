# M09 收费财务 · 验收

> 本文只写**跨 F 的端到端场景与故障演练**，单 F 内部的 AC 见各 `Fxx.md`。

---

## 1. 端到端场景

### S1 主流程收费

```
就诊完成 → 生成账单（F58 汇总处方/处置/检验/挂号费）
   → 收费（F59，可多笔混合支付）→ 账单 PAID
   → 打印凭条（M10 F68）
```

**判定**：
- [ ] 明细行可溯源到上游单据（处方 / 执行记录 / 检验申请 / 收费项目）
- [ ] 金额与上游计价结果一致（M09 不重算）
- [ ] 多笔支付合计 = 应收时才转 PAID
- [ ] `payment.paid_at` 已写入（营收归集口径）

### S2 退款与退药退款

```
部分退款（F61 逐行指定）→ 账单 PARTIAL_REFUNDED
退药（M07 F46 已确认）→ 退药退款（F63）→ 账单 FULLY_REFUNDED
```

**判定**：
- [ ] 退款金额始终 ≤ 行净额
- [ ] 原明细行金额不变，只累加已退金额
- [ ] 退款单与退药单可双向追溯
- [ ] 同一退药单不会被退两次

### S3 日结与日结后更正

```
日结（F64）→ 当日账单锁定（E3006）
   → 发现错账 → 红字冲正（F62 生成负数行）
   → 再次日结体现差额（历史日结单不被改）
```

**判定**：
- [ ] 日结后修改/作废账单被拒
- [ ] 日结后退款与冲正仍可用，并生成负数明细
- [ ] 同一天可多次日结，第二次只计增量
- [ ] 历史日结快照不被后续交易改写

### S4 全链路闭环

```
建档 → 就诊 → 病历 → 开方（含中药）→ 收费 → 发药（M07）
   → 打印 → 就诊完成 → 日结 → M15 报表
```

**判定**：
- [ ] 收费金额与处方计价一致（含代煎费与包装费）
- [ ] 发药后仍可退药退款，金额与库存双向一致
- [ ] 报表口径（03 §7）可用当前数据验证：营收 = Σ 成功收款 − Σ 成功退款

## 2. 故障演练

| # | 场景 | 期望 |
|---|---|---|
| M9-1 | 收费事务执行中强制断电 | 账单与支付记录**要么都在要么都不在**，不出现"已扣款无账单"（故障演练 #2） |
| M9-2 | 退款事务执行中强制断电 | 退款单与账单状态一致，不出现"已退钱账单未更新" |
| M9-3 | 同一支付重复提交（幂等键） | 只产生一笔支付，不重复扣款 |
| M9-4 | 支付金额与应收不符 | 整单拒绝，账单保持 PENDING，不留部分支付中间态 |
| M9-5 | 日结后尝试修改当日账单 | 拒绝 E3006，引导走冲正 |
| M9-6 | 尝试删除账单明细 | 数据库拒绝 E2006 |
| M9-7 | 对未确认退药单发起退款 | 拒绝 E3076 |

## 3. 审计与合规检查

- [ ] 账单生成、收费、退款、冲正、作废、日结均有 `audit_operation` 与状态日志
- [ ] 退款、冲正、作废、日结写 `audit_high_risk` 且原因必填
- [ ] `bill_item` 的 INSERT-ONLY 触发器已建立并验证
- [ ] 任一笔钱都能追溯到：谁收的、什么时候、哪张账单、哪个渠道、退了多少
- [ ] 埋点字段（`paid_at`、退款标记、作废标记）就位，M15 可直接取数
