# F64 日结

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

按营业日结账：汇总当日收款、退款、各渠道金额与笔数，生成日结单；**日结后当日账单不可修改**，只能走红字冲正 F62。

---

## 2. 依赖

- 依赖：F58/F59（账单与支付）、F61（退款）、F62（冲正）
- 被依赖：M15 F119（日营收/班结报表）

---

## 3. 涉及的表

`day_settlement`、`bill`、`payment`、`refund`、`reversal`

---

## 4. 规则

**R1 单号 `DS{yyyyMMdd}{2位}`**（契约 §1.2），**同一天可多次日结**（中途班结 + 收工日结）。

**R2 汇总口径（03 §7）。**
```
应收 = Σ bill_item.amount_fen（当日账单）
实收 = Σ payment.amount WHERE status='SUCCESS' AND paid_at 在当日
退款 = Σ refund.amount WHERE status='SUCCESS'
净收 = 实收 − 退款
```
**归集时间取 `payment.paid_at`**（收费时间），不是 Visit 创建时间。

**R3 渠道分项。** 按 `channel` 分组统计笔数与金额（现金/微信/支付宝/银行卡/其他）。

**R4 日结后锁定。** 日结范围内（`biz_date`）的账单：
- 不可新增/作废/修改金额 → E3006
- 仍可退款（F61）与冲正（F62），且退款在日结后需生成负数明细（F61 R8）

**R5 可多次但需不重不漏。** 第二次日结只汇总**上次日结之后**的增量，并记录 `from_settlement_id`，避免重复计入（M15 取数按全量或增量均可对齐）。

**R6 未完成业务阻断。** 存在 `PENDING` 账单时提示（不强制阻断，允许带未结账日结），但需记录未结账笔数与金额。

**R7 高风险审计。** 日结写 `audit_high_risk`（R-M09-10），含汇总数据快照。

**R8 幂等。** 同一 `biz_date` + 同一 `idempotent_key` 不重复生成。

**R9 数据快照固化。** 日结单保存汇总结果快照，**后续退款/冲正不改历史日结单**（只在下一次日结中体现差额）。

## 5. 验收标准

**AC1（生成日结单）**
- Given 当日实收 10000 分、退款 2000 分
- When 日结
- Then 单号 `DS{yyyyMMdd}{2位}`，净收 8000 分
- 验证方式：自动

**AC2（渠道分项）**
- Given 现金 3000、微信 7000
- When 日结
- Then 两个渠道分项金额与笔数正确
- 验证方式：自动

**AC3（日结后账单锁定）**
- Given 当日已日结
- When 修改/作废当日账单
- Then 拒绝 E3006
- 验证方式：自动

**AC4（日结后仍可退款与冲正）**
- Given 当日已日结
- When 退款/冲正
- Then 成功，且生成负数明细行
- 验证方式：自动（跨 F61/F62）

**AC5（同一天可多次日结）**
- Given 已日结一次
- When 再产生收款后二次日结
- Then 生成第二张 `DS`（序号递增），只计入增量
- 验证方式：自动

**AC6（未结账提示）**
- Given 存在 PENDING 账单
- When 日结
- Then 成功但记录未结账笔数与金额
- 验证方式：自动

**AC7（历史日结单不被改）**
- Given 日结后发生退款
- When 查历史日结单
- Then 快照不变
- 验证方式：自动

**AC8（高风险审计）**
- Given 日结完成
- When 查 `audit_high_risk`
- Then 有记录含汇总快照
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3006 | 日结后当日账单不可修改 | 否 |
| E3079 | 该营业日无可结账数据 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 日结事务中断 | 整体回滚，可重新日结（幂等） |
| 汇总发现数据异常（如支付无账单） | 拒绝日结并列出异常单据，不静默放行 |
