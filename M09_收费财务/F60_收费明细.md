# F60 收费明细

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

账单明细的查询与展示：按来源类型分组、可溯源到上游单据、**只增不改**（退款与冲正以新增行表达）。

---

## 2. 依赖

- 依赖：F58（生成明细）、F59（支付）
- 被依赖：F61（退款逐行指定）、F62（冲正）、M10 F68（凭条打印）、M15 F119/F122

---

## 3. 涉及的表

`bill_item`（**只允许 INSERT**，数据库触发器拦截 UPDATE/DELETE）

---

## 4. 规则

**R1 只增不改删。** 明细行一旦生成永不修改；退款生成 `refund_item`，冲正生成**负数明细行**（`is_reversal=1`），原行保留（R-M09-3、契约 §3.4）。

**R2 每行可溯源。** `source_type` ∈ `DRUG / HERB / TREATMENT / LAB / CHARGE`，`source_id` 指向上游单据明细；可反查。

**R3 已退/已冲金额可见。** 每行累计 `refunded_amount_fen` / `reversed_amount_fen`，净额 = `amount_fen − 已退 − 已冲`。

**R4 负数行显式标记。** 冲正产生的负数行带 `is_reversal=1` 与 `reversal_id`，不与正常行混淆。

**R5 展示口径。** 凭条与查询按 `source_type` 分组小计，总额取 Σ `amount_fen`（含负数行，天然体现冲正后的净额）。

**R6 只读。** 本 F 不提供任何修改接口；需要改就走退款/冲正。

---

## 5. 验收标准

**AC1（明细分组展示）**
- Given 账单含处方/处置/检验三类明细
- When 查询
- Then 按来源分组，小计正确
- 验证方式：自动

**AC2（禁止修改）**
- Given 一条明细
- When UPDATE 金额
- Then 数据库拒绝 E2006
- 验证方式：自动

**AC3（禁止删除）**
- Given 一条明细
- When DELETE
- Then 数据库拒绝 E2006
- 验证方式：自动

**AC4（冲正后净额正确）**
- Given 原行 2000 分，冲正生成 -2000 分行
- When 计算账单总额
- Then 净额 0
- 验证方式：自动（跨 F62）

**AC5（退款后已退金额可见）**
- Given 某行退 1000 分
- When 查该行
- Then `refunded_amount_fen=1000`，原 `amount_fen` 不变
- 验证方式：自动（跨 F61）

**AC6（可溯源）**
- Given 任取 10 行明细
- When 按 `source_type/source_id` 反查
- Then 全部命中上游单据
- 验证方式：自动
