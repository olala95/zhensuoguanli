# M13 数据安全与恢复 · 模块验收

> 本文件**只写跨 F 的端到端场景与故障演练**。单功能验收见各 `Fxx.md` 的 AC。

## 1. 端到端场景

### S1 日常自动备份闭环（F90 → F94）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 全新库首次启动 | 自检 7 项通过；当天尚无全量 → 自动备份一次（SCHEDULED） |
| 2 | 当天再次启动 | 跳过备份（skipped），不产生第二份文件 |
| 3 | 手动备份 | 仍然执行，产生第二份文件，reason=MANUAL |
| 4 | 查备份列表 | 两份文件，均有 size + SHA256，status=VALID |
| 5 | 查 `integrity_check` | 至少 2 条 BACKUP_VERIFY，结果 OK |

### S2 增量链与恢复（F91 → F93）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 做一次全量 F1 | `backup_job` 记 FULL/SUCCEEDED |
| 2 | 写入一批业务数据 | 库有变化，WAL 非空 |
| 3 | 执行增量备份 | 生成 `.walbak`，`parent_job_no` = F1 的 job_no |
| 4 | 再无写入时执行增量 | 返回 skipped，不产生文件 |
| 5 | 管理员确认恢复 F1 | 恢复前自动生成 PRE_RESTORE 备份；恢复后 integrity_check=ok |
| 6 | 查 `restore_log` / `audit_high_risk` | 有 restore_no 记录；有 RISK_RESTORE 含文件与 SHA256 |

### S3 备份损坏被拦截（F92 → F93）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 手动备份得到文件 A | status=VALID，记下 SHA256 |
| 2 | 人为改坏文件 A | 文件内容变化 |
| 3 | 恢复文件 A | 拒绝 E1003，当前库**完全不受影响** |
| 4 | 查 `restore_log` | 记一条 FAILED，detail 含校验失败原因 |

### S4 崩溃自愈（F96）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 制造 RUNNING 的 import_job / PRINTING 的 print_job / RUNNING 的 ai_task | 三个半成品 |
| 2 | 模拟崩溃（留非空 -wal），重启 | 自检 crash_recovery 报异常 |
| 3 | 崩溃恢复执行 | 三个任务分别收敛为 FAILED / FAILED / RETRYING |
| 4 | 查 `crash_recovery_log` | 有记录，含收敛明细 |
| 5 | 登录并开方收费 | 功能正常（不因安全模式阻断核心业务） |

### S5 损坏冻结现场（F95）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 注入 CORRUPT 异常 | 触发兜底处置 |
| 2 | 再写业务 | 返回 E1005 只读 |
| 3 | 查数据目录 | 原库文件完好未被删除 |
| 4 | 查 `audit_high_risk` | 有 RISK_DB_CORRUPT |
| 5 | 执行 salvage（确认后） | 生成独立 salvage 库，原库不动 |

### S6 硬件自愈（F98）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 注入打印机 fail | 打印失败 E4001，处方与账单不受影响 |
| 2 | 连续失败达阈值 | 看门狗重启驱动 |
| 3 | 复测 | 驱动恢复 online，设备状态回 ONLINE |
| 4 | 重打 | 成功出纸，`reprint_count` +1 |

### S7 AI 超时收敛（F97）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 1 | 制造一个 RUNNING 且超时的 ai_task | 卡死 |
| 2 | 执行 AI 看门狗 | retry_count 未达上限 → RETRYING |
| 3 | 再次超时并达上限 | → ABANDONED，写 `ai_failure_log` |
| 4 | 查 record | **无**任何 AI 内容被自动写入病历 |

## 2. 故障演练清单（模块级）

| 编号 | 演练 | 期望 | 自动化 |

## 3. 合规检查表

| 项 | 要求 | 落地位置 |
|---|---|---|
| 备份优先 | 迁移前必备份，失败中止迁移 | `runtime.bootstrap` |
| 备份可验证 | 每个文件记 SHA256 + 校验结果 | `backup_file.status` |
| 恢复高风险 | 二次确认 + 管理员 + RISK_RESTORE | F93 R7 / R6 |
| 损坏即只读 | CORRUPT → `set_readonly(True)` | F95 R2 |
| 只读不自动解除 | 仅恢复成功或管理员手动解除 | F95 R6 |
| 兜底不留半成品 | 启动时收敛 RUNNING/PRINTING 任务 | F96 R3 |
| 不做业务补偿 | 发药/收费不自动回滚或重做 | F96 R4 / R-M13-7 |
| 一切有痕 | 备份/恢复/检查/崩溃/看门狗全落表 + 审计 | 各 F 的 R7 |
