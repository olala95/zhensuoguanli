# F90 自动备份

[TYPE: JOB] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

在**关键时点自动触发**全量备份，保证"用户什么都不做也不会丢数据"：
每日首次启动、迁移前、安全退出前、以及每日定时全量。

> 核心能力已在第一阶段交付（`core/backup.py:full_backup`）；本文件补齐**自动触发策略**
> 与"每日只做一次"的幂等判定。

---

- 依赖：M14（配置 `backup.*`、编号 `BK{yyyyMMdd}{4位}`）、M12（审计）、`core/db`（checkpoint）
- 被依赖：F91（增量链的起点）、F93（恢复源）

## 3. 涉及的表

`backup_job`、`backup_file`、`integrity_check`

## 4. 规则

**R1 触发时机四选一，缺一不可。**
| 时机 | reason | 是否可跳过 |
|---|---|---|
| 每日首次启动（当天尚无 SUCCEEDED 全量） | `SCHEDULED` | 否 |
| 执行迁移前 | `BEFORE_MIGRATION` | **否（失败即中止迁移）** |
| 安全退出（F107） | `ON_EXIT` | 是（用户可选） |
| 手动（F92） | `MANUAL` | — |

**R2 每日只做一次。** 启动时先查 `backup_job` 当天是否已有 `job_type='FULL' AND
status='SUCCEEDED'`；有则跳过，返回 `skipped`。**强制参数 `force=true` 可 bypass**。

**R3 迁移前备份失败必须中止迁移。** 这是唯一"备份失败会阻断业务"的场景
（R-M13-1：迁移是不可逆的结构变更）。

**R4 备份前强制 `PRAGMA wal_checkpoint(TRUNCATE)`。** 否则备份的是一个不一致的快照
（05 §6）。

**R5 用 `VACUUM INTO`，禁止 copy 文件。** 直接 copy `.db` 在 WAL 模式下会拿到脏页；
`VACUUM INTO` 失败时降级到 `sqlite3.Connection.backup` API。

**R6 备份完成立即校验。** 对新文件跑 `PRAGMA integrity_check`，不 ok 则
`backup_file.status='INVALID'` + 任务 FAILED + `audit_high_risk`（R-M13-2：不可用的备份
绝不能出现在恢复列表里）。

**R7 清理与留痕。** 备份成功后执行保留策略清理（全量 `backup.keep_days` 默认 30 天，
每日最近 7 份，每月 1 份长期归档）；全过程写 `backup_job` + `audit_operation`。

## 5. 验收标准

**AC1（每日首次启动触发）**
- Given 当天尚无成功的全量备份
- When 系统启动
- Then 自动执行一次 FULL 备份，reason=SCHEDULED
- 验证方式：自动

**AC2（当天已备份则跳过）**
- Given 当天已有 SUCCEEDED 的 FULL 备份
- When 再次触发自动备份
- Then 返回 skipped，不产生新文件
- 验证方式：自动

**AC3（迁移前必备份）**
- Given 有待应用的迁移
- When 执行迁移
- Then 迁移前存在 reason=BEFORE_MIGRATION 的备份；备份失败则迁移中止
- 验证方式：自动

**AC4（退出前备份）**
- Given 请求安全退出且 backup=true
- When 退出流程执行
- Then 存在 reason=ON_EXIT 的备份
- 验证方式：自动

**AC5（备份文件可校验）**
- Given 一次成功的备份
- When 查询 `backup_file`
- Then 有 file_size 与 checksum（SHA256），status=VALID
- 验证方式：自动

**AC6（备份失败不静默）**
- Given 备份目录不可写
- When 执行自动备份
- Then 任务 FAILED 且存在高风险审计，日志有明确告警
- 验证方式：自动

**AC7（保留策略生效）**
- Given 存在超过保留天数的旧备份
- When 备份后执行清理
- Then 过期文件被删除，每月首份与最近 7 份保留
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E1002 | 磁盘空间不足 | 否 |
| E1004 | 备份 I/O 失败 | 是 |
| E1003 | 备份文件校验失败 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| `VACUUM INTO` 失败 | 自动降级 backup API；再失败标记 FAILED 并告警 |
| 校验失败 | 标记 INVALID，删除文件避免被误恢复 |
| 磁盘满 | 先清理旧备份再重试一次，仍失败则告警 |

---

## 8. 契约缺口

- 长期归档目录与日常备份目录同盘；若整盘损坏则全部失效。建议在 UI 提示"定期拷贝到
  移动介质"（不强制实现异地备份）。
