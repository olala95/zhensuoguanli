# F93 数据恢复

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

从备份文件把数据库**整体还原**到某个时间点，并在恢复前后做校验与留痕。这是系统的
最后一道防线，必须一键可完成、不可逆动作有提醒。

---

## 2. 依赖

- 依赖：F90/F91/F92（备份文件）、F94（完整性检查）、M12（高风险审计）
- 被依赖：无

---

## 3. 涉及的表

`restore_log`、`backup_file`（读）、`backup_job`（读）

---

## 4. 规则

**R1 恢复前先备份现状。** 恢复动作开始即自动对**当前库**做一次全量备份（reason=PRE_RESTORE），
防止"恢复错了还想退回"。

**R2 只恢复校验通过的备份。** SHA256 与登记值不符、或文件打不开 → 拒绝恢复（E1003）。

**R3 任一备份点都独立可恢复。** 全量与增量文件**同构**（F91 R1：增量也是完整快照），
因此恢复 = 直接把该文件还原为当前库，**不需要**回放链上其他文件。
指定的备份文件不存在 → 拒绝（E2005）。

**R4 恢复期间禁止业务。** 恢复前关闭所有连接、置只读；恢复完成并校验通过后重新打开。
过程中任何业务请求返回明确异常（E1005 只读），**绝不半恢复**。

**R5 恢复后强制完整性检查。** `PRAGMA integrity_check` 必须为 ok；不 ok → 保留现场、
标记恢复失败并告警，**不删除原库**。

**R6 高风险留痕。** 写 `restore_log` + `audit_high_risk`（RISK_RESTORE）：备份文件、
SHA256、操作人、时间、前后状态。

**R7 需要管理员权限与二次确认。** 权限 `system.restore`，且必须传 `confirm=true`
（UI 需弹窗说明"恢复将覆盖当前全部数据"）。

**R8 幂等与可追溯。** 每次恢复一个 `restore_no`；重复执行同一备份是允许的（覆盖式），
但每次都单独留痕。

---

## 5. 验收标准

**AC1（恢复成功）**
- Given 一个校验通过的全量备份
- When 管理员确认恢复
- Then 数据库还原到备份时间点，完整性检查 ok，`restore_log` 有记录
- 验证方式：自动

**AC2（恢复前自动备份现状）**
- Given 当前库有数据
- When 执行恢复
- Then 恢复前生成一张 PRE_RESTORE 备份
- 验证方式：自动

**AC3（损坏的备份被拒）**
- Given 备份文件被人为改坏
- When 恢复
- Then 拒绝 E1003，当前库不受影响
- 验证方式：自动

**AC4（增量可独立恢复）**
- Given 一个 INCR 备份文件（不带链上其他文件）
- When 恢复它
- Then 库还原到该快照点，完整性检查 ok
- 验证方式：自动

**AC4b（备份文件不存在被拒）**
- Given 指定一个不存在的备份文件
- When 恢复
- Then 拒绝 E2005
- 验证方式：自动

**AC5（恢复后完整性检查）**
- Given 恢复完成
- When 查 `integrity_check`
- Then 有新记录且结果为 ok
- 验证方式：自动

**AC6（高风险审计）**
- Given 一次恢复
- When 查 `audit_high_risk`
- Then 有 RISK_RESTORE 记录，含文件与 SHA256
- 验证方式：自动

**AC7（需确认与管理员权限）**
- Given 未传 confirm / 非管理员
- When 恢复
- Then 拒绝（E2001 / E6002）
- 验证方式：自动

**AC8（恢复期间业务被拒）**
- Given 正在恢复
- When 业务写入
- Then 返回只读异常 E1005，不产生半恢复状态
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E1003 | 备份文件损坏 / 校验失败 | 否 |
| E2005 | 备份文件不存在 | 否 |
| E1005 | 恢复期间系统只读 | 是 |
| E2001 | 缺少 confirm | 否 |
| E6002 | 非管理员 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 恢复中途失败 | 保留原库与 PRE_RESTORE 备份，标记 FAILED，可重试或改选其他备份 |
| 恢复后校验不过 | 回滚到 PRE_RESTORE 备份并告警 |
