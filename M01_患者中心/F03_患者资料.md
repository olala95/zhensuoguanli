# F03 患者资料

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

查看与维护患者完整档案：基本信息、证件、联系方式、备注标签，以及关联的历史就诊/处方/账单概览。

---

## 2. 依赖

- 依赖：M12（审计）、M02 / M06 / M09（历史数据只读，通过对方接口或只读视图）
- 被依赖：全部（患者快照的来源）

---

## 3. 涉及的表

`patient`、`patient_identifier`、`patient_contact`（M01 自有，读写）
**只读**：`visit`（M02）、`prescription`（M06）、`bill`（M09）—— 走接口或 `v_` 视图，不直接查表

---

## 4. 规则

**R1 修改必审计。** 任何字段修改写 `audit_data_change`（含 before/after）。身份证字段审计只记后 4 位 + 哈希。

**R2 姓名修改需谨慎提示。** 修改姓名时提示"历史单据中的患者快照不会随之改变"，避免用户误解。

**R3 快照不可变。** 已生成的处方、账单、归档病历中的患者快照字段**不随患者主数据更新**。这是归档不可变原则的要求（R-M01-7 快照机制）。

**R4 联系方式可增删改。** 支持多电话/地址，可切换主要标记，可删除单个联系方式（删除写审计）。**至少保留一个联系方式**。

**R5 有业务数据的患者不可删除。** 存在 Visit / 处方 / 病历 / 账单 → 只能停用或合并（F04），删除按钮不可用并说明原因。删除尝试写 `audit_high_risk`。

**R6 无业务数据的患者可停用作废。** 建档错误且无任何业务数据时，允许作废（软删除），写 `audit_high_risk` 并填原因。

**R7 历史概览只读。** 展示历史就诊/处方/账单列表，点击跳转到对应模块查看。**本模块不提供修改历史业务数据的入口。**

**R8 敏感信息按需展开。** 完整身份证、完整手机号默认隐藏，点击展开并写 `audit_operation`。

**R9 支持标签/备注。** 可给患者打标签（如"高血压随访""青霉素过敏"）用于提醒。标签不影响业务规则，仅展示。过敏史正式记录归 M03 F13，此处标签仅为快速提示，二者不冲突但**不互相替代**。

## 5. 验收标准

**AC1（查看完整档案）**
- Given 患者 P 有 3 次就诊、5 张处方
- When 打开患者资料
- Then 展示基本信息、证件、联系方式、历史就诊/处方/账单概览，数据完整
- 验证方式：自动

**AC2（修改审计）**
- Given 修改患者手机号从 A 改为 B
- When 保存
- Then `audit_data_change` 含 field=phone、before=A、after=B
- 验证方式：自动

**AC3（快照不随主数据变）**
- Given 处方 R001 中患者姓名快照为"张三"
- When 将患者主数据姓名改为"张三丰"
- Then 处方 R001 中姓名快照仍为"张三"，仅主数据变更
- 验证方式：自动（跨模块，需 M06 配合）

**AC4（有业务数据不可删除）**
- Given 患者有 1 张已发药处方
- When 尝试删除
- Then 拒绝并提示"存在业务数据，请改用停用作废或合并"；写 `audit_high_risk`
- 验证方式：自动

**AC5（无业务数据可作废）**
- Given 患者刚建档，无任何就诊/处方
- When 执行作废并填原因"录入错误"
- Then 软删除成功，写 `audit_high_risk` 含原因；F02 搜索中不再作为可建就诊对象
- 验证方式：自动

**AC6（联系方式至少保留一个）**
- Given 患者仅有 1 个手机号
- When 尝试删除该手机号
- Then 拒绝并提示"至少保留一个联系方式"
- 验证方式：自动

**AC7（敏感信息按需展开）**
- Given 患者资料页
- When 点击展开完整身份证号
- Then 显示完整号码，同时写 `audit_operation` 记录"查看完整证件号"
- 验证方式：自动

**AC8（历史概览只读）**
- Given 患者历史处方列表
- When 查看
- Then 可跳转到 M06 查看，**本模块无修改入口**
- 验证方式：自动

**AC9（标签不影响业务规则）**
- Given 给患者打标签"青霉素过敏"
- When 开含青霉素的处方
- Then 该标签**不触发**处方规则拦截（正式过敏拦截由 M03 F13 负责），仅在患者资料与接诊界面展示提醒
- 验证方式：自动（跨模块，需 M06 配合）

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 必填缺失 | 否 |
| E2008 | 身份证校验错误（可强制） | 否 |
| E3001 | 存在业务数据不可删除 | 否 |
| E3008 | 至少保留一个联系方式 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 修改中途崩溃 | 事务回滚；重新编辑 |
| 历史概览接口不可用 | 隐藏概览区并提示，基本信息仍可用 |
