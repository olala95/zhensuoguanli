# F107 安全退出

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

优雅关闭系统：完成在途事务、提示未完成的业务、检查点落盘、关闭连接、停止子进程的完整流程，并定义被强制终止时的兜底行为。

---

## 2. 依赖

- 依赖：`05_RUNTIME_TOPOLOGY` §8、M10（停止 Hardware Agent）、M04（停止 AI Worker）、M12（`audit_login`）
- 被依赖：无

---

## 3. 涉及的表

`sys_session`（M14 自有）；通过 M12 接口写 `audit_login`

---

## 4. 规则

**R1 退出七步（`05_RUNTIME_TOPOLOGY` §8）**

1. 等待进行中的事务完成（超时强制回滚，超时值可配，默认 10 秒）
2. 检查未确认草稿 / 未确认处方 / 未收费账单 / 未发药处方 / 未完成打印任务 → 明确列出并提示用户处理
3. 日志 flush（`F103` R5）
4. `PRAGMA wal_checkpoint(TRUNCATE)`
5. 关闭全部数据库连接
6. 优雅停止 AI Worker 与 Hardware Agent（等待在途任务，超时后强制终止并记录）
7. 写 `audit_login(LOGOUT)`；若配置为"退出时备份"，触发一次全量备份

**R2 未完成业务的提示必须具体。** 不允许只弹"有未完成业务"。必须列出：类型、单据号、当前状态、建议动作（去处理 / 作废 / 忽略）。

**R3 强制终止兜底。** 用户强杀进程或系统断电时，下次启动走 `05_RUNTIME_TOPOLOGY` §5.2 崩溃恢复：WAL 自动回滚未提交事务 + 跨表一致性校验。

**R4 禁止静默退出。** 存在未保存的病历草稿时，退出必须询问，不得直接丢弃。

**R5 退出不等于锁屏。** 退出结束进程；锁屏（F100）保持进程。二者不得混淆。

**R6 备份优先于退出完成。** 若配置退出时备份，备份未完成不得关闭连接；备份失败要提示但**允许用户选择继续退出**（不能把用户锁在系统里），并写 `audit_high_risk`。

## 5. 验收标准

**AC1（正常退出七步）**
- Given 系统空闲无未完成任务
- When 执行退出
- Then 依次完成七步：无未提交事务残留、日志已 flush、WAL 已 checkpoint、连接已关闭、子进程已停止、`audit_login` 有 LOGOUT 记录；进程正常结束，退出码 0
- 验证方式：自动（逐步断言）

**AC2（未完成业务提示具体）**
- Given 存在一张未收费账单 B202610090015 和一张未确认处方 R202610090012
- When 执行退出
- Then 提示中明确列出这两个单号、类型、状态与建议动作
- 验证方式：自动

**AC3（未保存草稿拦截）**
- Given 存在未保存的病历草稿
- When 执行退出
- Then 系统询问（保存 / 丢弃 / 取消退出），**不静默丢弃**
- 验证方式：自动

**AC4（事务超时回滚）**
- Given 退出时存在一个长时间未提交的事务
- When 超过超时阈值
- Then 事务被回滚，退出继续，日志记录了超时回滚事件
- 验证方式：自动（注入长事务）

**AC5（强制 kill 后恢复）**
- Given 正在写病历
- When 强制 kill 进程
- Then 重启后已保存内容不丢，未提交内容回滚，启动自检报告崩溃恢复一次，无脏数据
- 验证方式：自动

**AC6（断电恢复）**
- Given 收费事务执行中
- When 断电
- Then 重启后账单与支付记录要么同时存在要么都不存在，**不出现"已扣款无账单"或"有账单无支付"**
- 验证方式：自动（断电模拟/事务注入）

**AC7（退出备份失败不锁死）**
- Given 配置退出时备份，但备份目录不可写
- When 执行退出
- Then 提示备份失败，允许用户选择继续退出；选择后正常退出，写 `audit_high_risk`
- 验证方式：自动

**AC8（子进程优雅停止）**
- Given Hardware Agent 有一个进行中的打印任务
- When 执行退出
- Then 等待该任务完成（或超时后强制终止并记录），子进程进程表中不再存在残留
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E1001 | 关闭数据库连接失败 | 是 |
| E1002 | 退出备份失败 | 是 |
| E3003 | 存在未完成的业务单据 | 是（处理后） |
| E4001 | 子进程停止超时 | 是 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 退出流程卡住 | 提供"强制退出"入口（第二次点击），强制退出仍走 checkpoint 与日志 flush，并记 `audit_high_risk` |
| 子进程无法停止 | 超时后强制终止，记录 PID 与任务 ID，下次启动由看门狗/启动自检核对任务状态 |
| 备份中途失败 | 允许继续退出，备份标记为失败并告警 |
