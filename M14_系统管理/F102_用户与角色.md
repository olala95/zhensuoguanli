# F102 用户与角色

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

用户账号的增删改查与启用/禁用、角色定义与权限分配、密码修改与重置。

---

## 2. 依赖

- 依赖：M12（`audit_high_risk`、`audit_permission` 接口）、F100（会话上下文）
- 被依赖：全部模块（权限校验）

---

## 3. 涉及的表

`sys_user`、`sys_role`、`sys_user_role`（M14 自有）

---

## 4. 规则

**R1 四种内置角色。** 医生、药师、收费员、管理员。内置角色的**权限集合可配置**但角色本身不可删除，避免权限体系被破坏。

| 角色 | 核心权限 |
|---|---|
| 医生 | 接诊、写病历（含中医四诊辨证）、开处方（成药/饮片/颗粒）、开处置、开检验、病历确认、处方确认、作废本人未发药处方 |
| 药师 | 发药（成药与饮片）、退药、入库、盘点、报损、库存查询 |
| 收费员 | 收费、退款、退药退款、日结、财务查询 |
| 管理员 | 用户与角色、系统配置、备份恢复、硬件配置、诊断；**病历封存/解封** |

**R2 管理员不得越权临床。** 管理员**不具备**"修改已确认病历""绕过处方确认"的权限。若管理员同时是医生，必须切换到医生角色才能做临床操作（R-M14-2）。

**R3 用户不可物理删除。** 停用账号用 `is_disabled`，保留其历史操作的可追溯性。存在有效业务数据（开过处方、写过病历）的用户禁止删除，只能禁用。

**R4 角色变更必审计。** 分配/回收角色写 `audit_high_risk`，含 before/after 角色集合。

**R5 密码策略。** 最小长度 8，禁止弱口令（常见密码表）。修改密码需验证旧密码；管理员重置他人密码生成一次性临时密码并强制下次登录修改。密码修改写 `audit_high_risk`（不含密码内容）。

**R6 最后一名管理员保护。** 不允许禁用或回收系统中最后一名管理员的角色。

**R7 自己不能给自己提权。** 用户不得修改自己的角色集合（防提权），必须由其他管理员操作。

**R8 权限校验统一入口。** 所有权限判断走 `auth.require(permission)`，禁止各模块自行判断角色名。

## 5. 验收标准

**AC1（创建用户）**
- Given 管理员已登录
- When 创建用户"张医生"，分配角色"医生"
- Then `sys_user` 与 `sys_user_role` 正确写入，密码以带盐哈希存储（库中无明文），写 `audit_high_risk`
- 验证方式：自动

**AC2（权限生效）**
- Given 用户"张医生"仅有医生角色
- When 以该账号尝试执行收费操作
- Then 返回 `E6002`，写入 `audit_permission`，不产生账单
- 验证方式：自动

**AC3（多角色切换）**
- Given 用户同时有"医生"和"药师"角色，当前激活"医生"
- When 需要发药（药师权限）
- Then 提示切换角色；切换后操作成功，审计中角色字段为"药师"（配合 F100 AC6）
- 验证方式：自动

**AC4（禁止物理删除有业务数据的用户）**
- Given 用户"李医生"曾开具过处方
- When 尝试删除该用户
- Then 系统拒绝，提示只能禁用；禁用后该用户无法登录但历史处方中"开方医生"仍可正常显示
- 验证方式：自动

**AC5（最后管理员保护）**
- Given 系统仅有一名管理员
- When 尝试禁用该账号或回收其管理员角色
- Then 系统拒绝并提示原因
- 验证方式：自动

**AC6（禁止自我提权）**
- Given 管理员 A 已登录
- When A 尝试给自己增加角色或提升权限
- Then 拒绝并写 `audit_permission`
- 验证方式：自动

**AC7（密码策略）**
- Given 密码策略最小长度 8 且禁用弱口令
- When 设置密码 "123456"
- Then 拒绝并说明原因
- 验证方式：自动

**AC8（重置密码审计）**
- Given 管理员重置用户 B 的密码
- When 生成临时密码
- Then 写 `audit_high_risk`（**不含密码内容**），B 下次登录被强制要求修改密码
- 验证方式：自动

**AC9（内置角色不可删）**
- Given 内置角色"医生"
- When 尝试删除该角色
- Then 拒绝
- 验证方式：自动

## 7. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 必填字段缺失 | 否 |
| E2004 | 用户名重复 | 否 |
| E2005 | 密码不符合策略 | 否 |
| E3001 | 用户存在业务数据不可删除 | 否 |
| E3002 | 最后一名管理员不可禁用 | 否 |
| E6002 | 无权限 | 否 |
| E6004 | 账号已禁用 | 否 |

---

## 8. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 创建用户中途崩溃 | 事务回滚；不产生半条用户记录 |
| 角色分配部分成功 | 角色分配整体在一个事务内，全成功或全回滚 |
| 权限缓存与库不一致 | 提供权限刷新；关键操作前重新从库校验 |
