# F99 系统初始化

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

系统首次启动时完成：数据库创建、迁移执行、基础配置写入、管理员账号创建、默认数据字典灌入、目录结构建立、启动自检。

**本功能是整个系统的入口，必须先于一切业务可用。**

---

## 2. 依赖

- 依赖：`04_DATA_MODEL`（表结构）、`05_RUNTIME_TOPOLOGY` §3（SQLite 参数）、`05` §5（启动自检）
- 被依赖：全部模块

---

## 3. 涉及的表

`sys_config`、`sys_user`、`sys_role`、`sys_user_role`、`sys_dict`、`sys_migration`、`sys_sequence`（全部为 M14 自有表）

---

## 4. 规则

**R1 幂等。** 重复执行初始化不得产生重复数据。已初始化的系统再次启动时进入"校验模式"：只检查缺失项并补齐，不重建。

**R2 迁移前强制备份。** 执行数据库迁移前必须触发一次全量备份（`05_RUNTIME_TOPOLOGY` §6）。备份失败则中止初始化并告警。

**R3 默认字典必须灌入。** 至少包含：给药途径、药品剂型、中药脚注（先煎/后下/包煎/烊化/冲服/另煎）、煎法、服法、中药证型、处置类别、支付方式、退款原因、作废原因。字典项允许管理员后续增删。

**R4 首个管理员强制创建。** 初始化向导必须创建至少一名管理员账号；不允许存在"无账号可用"的已初始化状态。

**R5 目录结构。** 初始化时创建：`data/`（数据库）、`backup/`（备份，优先不同分区）、`logs/`（日志）、`attachments/`（检验报告图片等附件）、`exports/`（导出文件）。目录不可写则初始化失败并明确提示。

**R6 敏感默认值。** 默认开启锁屏（5 分钟）、默认密码策略（最小长度 8，禁止弱口令）、默认自动备份（每日）。管理员可关闭但关闭动作写 `audit_high_risk`。

## 5. 状态与流程

```
首次启动
  → 检查 data/ 目录与数据库文件
  → 不存在：创建数据库 + 设置 PRAGMA + 执行全部迁移
     存在：检查 sys_migration 版本 → 执行未执行的迁移（先备份）
  → 灌入默认数据字典
  → 创建管理员账号（向导）
  → 写入默认 sys_config
  → 创建目录结构
  → 执行启动自检（F105）
  → 自检通过 → 进入登录；不通过 → 进入安全模式
```

---

## 6. 验收标准

**AC1（首次初始化）**
- Given 一台未安装过本系统的机器
- When 首次启动程序
- Then 数据库文件创建成功，`PRAGMA journal_mode` 返回 `wal`，`PRAGMA foreign_keys` 返回 1，全部迁移执行成功且 `sys_migration` 记录完整，默认字典条目数 ≥ 50，管理员账号可登录
- 验证方式：自动

**AC2（幂等）**
- Given 系统已初始化
- When 再次执行初始化流程
- Then 不产生重复字典项、不重复创建管理员、`sys_migration` 无新增记录、业务数据零变更
- 验证方式：自动

**AC3（迁移前备份）**
- Given 存在未执行的迁移
- When 启动并触发迁移
- Then 在 `backup/` 下生成一个完整可用的备份文件，且该备份 `integrity_check` 通过
- 验证方式：自动

**AC4（目录不可写）**
- Given `backup/` 目录不可写
- When 执行初始化
- Then 初始化中止，返回 `E1002`（磁盘/目录不可写），提示具体路径，**不创建半成品数据库**
- 验证方式：自动

**AC5（迁移失败回滚）**
- Given 某条迁移脚本存在语法错误
- When 执行迁移
- Then 该迁移整体回滚，数据库停留在迁移前版本，记录 `E1001`，系统进入安全模式，**已有数据不损坏**
- 验证方式：自动（注入错误脚本）

**AC6（无管理员保护）**
- Given 初始化向导进行中
- When 尝试跳过管理员创建步骤
- Then 系统拒绝，必须创建至少一名管理员才能完成初始化
- 验证方式：自动

---

## 7. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E1001 | 数据库不可用 / 迁移失败 | 是 |
| E1002 | 磁盘满或目录不可写 | 是（处理后） |
| E1003 | 数据库损坏 | 否（需恢复） |
| E2001 | 必填配置缺失 | 否 |
| E6001 | 未登录访问初始化接口 | 否 |

---

## 8. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 迁移中途崩溃 | 迁移在事务内，重启后重新执行；执行前已有备份 |
| 目录创建中途失败 | 记录已创建目录，重启后继续；不删除已建内容 |
| 字典灌入中途失败 | 事务回滚，重启后重新灌入（幂等） |
