# F105 健康检查

[TYPE: JOB] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

周期性检查各组件状态并在异常时告警；同时承担**启动自检**（`05_RUNTIME_TOPOLOGY` §5.1 的 7 项检查）的执行入口。

---

## 2. 依赖

- 依赖：`05_RUNTIME_TOPOLOGY` §5（自检清单）、F101（阈值配置）
- 被依赖：F99（初始化末尾调用）、F104（诊断读取）、F107（退出前检查）

---

## 3. 涉及的表

`sys_health_check`（M14 自有）

---

## 4. 规则

**R1 启动自检 7 项（`05_RUNTIME_TOPOLOGY` §5.1）**

1. 数据库文件存在且可打开
2. `PRAGMA integrity_check` 通过
3. `PRAGMA foreign_key_check` 无违规
4. 无上次崩溃遗留的未完成事务
5. 关键表与 `sys_migration` 版本一致
6. 磁盘剩余空间高于阈值
7. 备份目录可写

任一失败 → **安全模式**：只读打开，禁止业务写入，仅允许管理员诊断与恢复。

**R2 周期性检查项**

| 组件 | 检查内容 | 周期 |
|---|---|---|
| 数据库 | 可读写、`integrity_check` | 每 30 分钟（轻量，不做全库 integrity） |
| 磁盘空间 | 剩余空间 vs 阈值 | 每 10 分钟 |
| 备份 | 最近一次全量备份时间与结果 | 每小时 |
| 打印/Hardware Agent | 心跳可达性 | 由 M10 上报，本功能汇总 |
| AI Worker | 心跳可达性 | 由 M04 上报，本功能汇总 |

**R3 状态三态。** NORMAL / WARNING / ERROR。WARNING 不阻断业务但界面提示；ERROR 视组件决定是否进安全模式（数据库 ERROR 必须进安全模式）。

**R4 告警去噪。** 同一异常在冷却期内（默认 15 分钟）不重复告警，但**每次检查结果都要落库**，只是不重复弹窗。

**R5 检查本身不得影响业务。** 周期性检查为轻量操作，禁止在业务高峰做全表扫描或全库 `integrity_check`（全库检查仅在启动时与诊断时执行）。

**R6 结果留痕。** 每次检查写入 `sys_health_check`（组件、状态、详情、时间）。保留 30 天，可清理。

---

## 5. 状态与流程

```
启动 → 执行 7 项自检
  → 全通过 → NORMAL，进入登录
  → 有失败 → 进入安全模式，界面明确列出失败项与处理建议
运行中 → 周期检查 → 状态变化 → 告警（去噪）+ 落库
```

---

## 6. 验收标准

**AC1（启动自检全通过）**
- Given 系统健康
- When 启动
- Then 7 项自检全部通过，`sys_health_check` 记录启动结果，正常进入登录
- 验证方式：自动

**AC2（数据库损坏进安全模式）**
- Given 数据库文件被人为损坏
- When 启动
- Then 第 2 项自检失败，进入安全模式，**业务写入被拒绝**，界面提示可恢复备份
- 验证方式：自动（注入损坏）

**AC3（残留事务检测）**
- Given 上次运行强制 kill 且遗留未完成事务
- When 启动
- Then 自检第 4 项报出，走 `05_RUNTIME_TOPOLOGY` §5.2 崩溃恢复流程，恢复完成后可正常进入
- 验证方式：自动（kill 注入）

**AC4（磁盘不足）**
- Given 磁盘剩余空间低于阈值
- When 周期检查触发
- Then 状态为 WARNING 或 ERROR，界面提示；业务仍可用（除非数据库写入失败）
- 验证方式：自动（mock 磁盘）

**AC5（备份过期告警）**
- Given 最近一次成功备份在 48 小时前（阈值 24 小时）
- When 周期检查触发
- Then 备份组件 WARNING，提示立即备份
- 验证方式：自动

**AC6（告警去噪）**
- Given 同一异常已告警一次
- When 冷却期内再次检查到同一异常
- Then 不重复弹窗，但 `sys_health_check` 中仍有新记录
- 验证方式：自动

**AC7（检查不影响业务）**
- Given 正常业务操作中
- When 周期检查触发
- Then 业务操作无明显延迟（< 100ms 额外开销）
- 验证方式：自动（性能断言）

---

## 7. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E1001 | 数据库不可用 | 是 |
| E1002 | 磁盘空间不足 | 是（清理后） |
| E1003 | 数据库损坏 | 否 |
| E1004 | 迁移版本不一致 | 否 |
| E1005 | 备份目录不可写 | 是 |

---

## 8. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 自检失败 | 进安全模式，管理员可从诊断（F104）进入备份恢复（F93） |
| 周期检查进程异常 | 下次周期自动重试；连续失败记为组件 ERROR 并告警 |
| 安全模式误判 | 管理员可手动重新执行自检；重新执行写 `audit_high_risk` |
