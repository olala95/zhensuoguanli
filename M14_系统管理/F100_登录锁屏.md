# F100 登录 / 锁屏

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

用户身份验证、角色选择、会话管理、自动锁屏与解锁、登出。为所有业务操作提供"操作人 + 角色"上下文（审计必需）。

---

## 2. 依赖

- 依赖：M12（`audit_login` 写入接口）、F99（初始化保证存在账号）
- 被依赖：全部模块（`auth.currentUser()` 是审计埋点的输入）

---

## 3. 涉及的表

`sys_user`、`sys_role`、`sys_user_role`、`sys_session`（M14 自有）
写入 `audit_login`（**M12 所有，通过 M12 接口写，不直接写表**）

---

## 4. 规则

**R1 角色必须选定。** 登录时选择当前角色（医生 / 药师 / 收费员 / 管理员）。一人可有多个角色，但一次会话只能激活一个。审计记录中的 `role` 字段取当前激活角色。

**R2 密码存储。** 禁止明文与可逆加密。使用带盐哈希（argon2id 或 bcrypt）。密码永不出日志、不进异常消息。

**R3 失败锁定。** 连续 5 次密码错误锁定账号 10 分钟（可在 `sys_config` 配置）。每次失败写 `audit_login`（含来源、时间）。第 3 次起写 `audit_high_risk`。

**R4 自动锁屏。** 无操作超过配置阈值（默认 5 分钟）自动锁屏。锁屏期间：
- 业务界面不可操作（输入被拦截）
- 已在途的业务事务须先完成或回滚，不允许事务跨锁屏悬挂

**R5 解锁需重新验证。** 解锁必须输入密码（不接受免密）。解锁成功写 `audit_login`，角色保持锁屏前角色。

**R6 会话唯一。** 单机单用户：同一时刻只允许一个活跃会话。新登录会先终止旧会话并写 `audit_login`。

**R7 锁屏不退出。** 锁屏不结束进程、不关闭数据库连接、不触发备份。仅拦截交互。

**R8 时间取系统时间。** 登录/解锁/登出时间一律取系统时间，不接受外部传入（配合 F88 时间异常检测）。

---

## 5. 状态与流程

```
sys_session: ACTIVE → LOCKED（超时 / 手动）→ ACTIVE（解锁）| LOGGED_OUT
```

登录流程：输入账号密码 → 校验 → 选择角色 → 建立会话 → 写 `audit_login(LOGIN)` → 进入主界面
锁屏流程：触发（超时/手动）→ 在途事务完成或回滚 → 置 LOCKED → 写 `audit_login(LOCK)` → 显示锁屏界面
解锁流程：输入密码 → 校验 → 置 ACTIVE → 写 `audit_login(UNLOCK)` → 恢复界面
登出流程：走 F107 安全退出 → 写 `audit_login(LOGOUT)`

## 6. 验收标准

**AC1（正常登录）**
- Given 存在管理员账号 A，密码正确
- When 输入正确账号密码并选择角色"医生"
- Then 会话建立，`auth.currentUser()` 返回 `{userId: A, role: 医生}`，`audit_login` 中有一条 LOGIN 记录且角色为医生
- 验证方式：自动

**AC2（密码错误与锁定）**
- Given 账号 A
- When 连续输入错误密码 5 次
- Then 前 2 次记录普通 `audit_login` 失败；第 3 次起同时写 `audit_high_risk`；第 5 次后账号锁定 10 分钟，期间即使密码正确也无法登录，返回 `E6003`
- 验证方式：自动

**AC3（自动锁屏）**
- Given 已登录，锁屏阈值配置为 1 分钟
- When 无操作 61 秒
- Then 会话置为 LOCKED，业务输入被拦截，`audit_login` 中有 LOCK 记录
- 验证方式：自动

**AC4（锁屏不悬挂事务）**
- Given 已登录且正在编辑一张未提交的处方
- When 触发锁屏
- Then 系统先完成或回滚在途事务，锁屏后数据库中不存在未提交事务（通过 `PRAGMA` 检查），重启无残留
- 验证方式：自动

**AC5（解锁验证）**
- Given 会话处于 LOCKED
- When 输入错误密码
- Then 拒绝解锁，会话保持 LOCKED，写 `audit_login` 失败记录
- 验证方式：自动

**AC6（角色切换留痕）**
- Given 用户同时拥有"医生"和"收费员"角色，当前为医生
- When 切换到收费员
- Then `audit_login` 记录切换事件（含前后角色），此后业务操作的审计角色字段为收费员
- 验证方式：自动

**AC7（会话唯一）**
- Given 已存在活跃会话
- When 同一账号再次登录
- Then 旧会话被终止并写 `audit_login(LOGOUT)`，新会话建立
- 验证方式：自动

**AC8（密码不入日志）**
- Given 任意登录失败场景
- When 检查 `logs/` 下所有日志文件与异常消息
- Then 不含任何明文密码或可还原的密码片段
- 验证方式：自动（日志扫描）

## 7. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E6001 | 未登录 | 否 |
| E6002 | 无该操作权限 | 否 |
| E6003 | 账号已锁定 | 是（等待解锁） |
| E6004 | 账号已禁用 | 否 |
| E6005 | 会话已失效（被新登录顶替） | 否 |

---

## 8. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 登录过程中崩溃 | 会话未建立或已回滚；重启后重新登录，无脏会话 |
| 锁屏时事务未结束 | R4 保证先完成或回滚；重启后启动自检校验无残留事务 |
| `sys_session` 记录与实际不符 | 启动时以数据库为准清理孤儿会话，写 `audit_login(LOGOUT)` 补齐 |
