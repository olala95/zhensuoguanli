# F125 就诊作废与退号

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

> 新增功能点（F108–F128 批次）。原始 107 个功能点中缺失"就诊取消/退号"环节，本功能补齐。

---

## 1. 职责

将一次未完成的就诊作废（退号），释放其占用的资源并记录原因。

---

## 2. 依赖

- 依赖：M12（`audit_high_risk`）、M09（已收费需先退款）、M06（已发药需先退药）、F06（移出队列）
- 被依赖：M15（统计口径中排除作废）

---

## 3. 涉及的表

`visit`、`visit_status_log`、`visit_void`（M02 自有）

---

## 4. 规则

**R1 作废必须填原因。** 原因从字典选择（患者未到 / 重复挂号 / 录入错误 / 患者放弃 / 其他）+ 备注。必填，写 `audit_high_risk`。

**R2 已收费的 Visit 不可直接作废。** 必须先走 M09 退款完成，再作废。检测存在有效收款 → 拒绝并引导退款。

**R3 已发药的处方不可直接作废。** 必须先走 M07 退药，再作废。

**R4 已确认的病历特殊处理。** 若该 Visit 下已有**已确认**的病历：
- 病历不随 Visit 作废而消失（归档不可变原则）
- 作废时明确提示"该就诊下已有 N 份已确认病历，将保留在患者档案中"
- 病历本身状态不变

**R5 未确认的单据一并作废。** 作废 Visit 时，其下**未确认**的处方、检验申请、处置执行一并置为作废/取消（通过各模块接口），并写审计。

**R6 COMPLETED 不可作废。** 已完成的就诊只能走退款/退药流程，不作废 Visit 本身（保证统计口径：完成的就诊永远算一次门诊量）。

**R7 作废不可逆。** 作废后不可撤销；如确需恢复只能新建 Visit。

**R8 作废后移出队列。** 立即从候诊队列移出。

**R9 统计口径。** 作废的 Visit **不计入门诊量**（契约 §7），但作废记录本身可被查询统计（用于分析退号率）。

---

## 5. 状态与流程

```
触发作废（WAITING / IN_PROGRESS / SUSPENDED）
  → 前置检查：
      · 存在有效收款？→ 拒绝，引导 M09 退款
      · 存在已发药处方？→ 拒绝，引导 M07 退药
      · 存在已确认病历？→ 提示将保留
  → 填原因（必填）
  → 事务内：
      · 作废其下未确认处方/检验/处置（走各模块接口）
      · 置 visit = VOID
      · 写 visit_void（原因、操作人、时间）
      · 写状态日志
      · 写 audit_high_risk
  → 移出队列
```

---

## 6. 验收标准

**AC1（候诊中作废）**
- Given Visit 处于 WAITING 无任何单据
- When 作废并填原因"患者未到"
- Then 状态置 VOID，`visit_void` 记录完整，`audit_high_risk` 有记录，移出队列
- 验证方式：自动

**AC2（原因必填）**
- Given 作废操作
- When 不填原因
- Then 拒绝，返回 `E2001`
- 验证方式：自动

**AC3（已收费拒绝）**
- Given Visit 下存在已支付账单
- When 尝试作废
- Then 拒绝并提示先退款，给出跳转 M09 的入口
- 验证方式：自动

**AC4（已发药拒绝）**
- Given Visit 下有已发药处方
- When 尝试作废
- Then 拒绝并提示先退药
- 验证方式：自动

**AC5（已确认病历保留）**
- Given Visit 下有 1 份已确认病历
- When 作废
- Then 作废成功，但明确提示病历保留；病历状态与内容不变，可在患者档案中查到
- 验证方式：自动（跨模块，需 M11/M03 配合）

**AC6（未确认单据一并作废）**
- Given Visit 下有 2 张未确认处方、1 个未采样检验申请
- When 作废
- Then 处方置 VOID、检验申请置 CANCELLED，各自写审计
- 验证方式：自动（跨模块）

**AC7（已完成不可作废）**
- Given Visit 处于 COMPLETED
- When 尝试作废
- Then 拒绝，返回 `E3016`，提示走退款/退药流程
- 验证方式：自动

**AC8（不计入门诊量）**
- Given 今日有 5 个 COMPLETED 与 2 个 VOID
- When 统计门诊量
- Then 结果为 5
- 验证方式：自动（跨模块，需 M15 配合）

**AC9（不可逆）**
- Given Visit 已 VOID
- When 尝试恢复为 IN_PROGRESS
- Then 拒绝
- 验证方式：自动

**AC10（事务性）**
- Given 作废过程中某单据作废失败
- When 执行
- Then 整体回滚，Visit 保持原状态
- 验证方式：自动（注入失败）

---

## 7. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 作废原因必填 | 否 |
| E3016 | 已完成就诊不可作废 | 否 |
| E3017 | 存在有效收款，请先退款 | 否 |
| E3018 | 存在已发药处方，请先退药 | 否 |
| E1010 | 审计写入失败 | 是 |

---

## 8. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 作废中途崩溃 | 事务回滚；重新作废 |
| 某模块单据作废失败 | 整体回滚并提示哪个模块失败 |
| 误作废 | 不可撤销；只能通过新建 Visit 重新就诊（提示用户） |

---
