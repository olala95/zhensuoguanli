# F55 执行记录

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

处置的执行过程状态推进：开始执行 → 完成 / 中断 / 取消，并记录执行人、执行时间、执行结果。

---

## 2. 依赖

- 依赖：F54（已开立记录）、F52（`need_record`）、M12
- 被依赖：M09（已执行才可收费/退费）、M15 F120（工作量）、F56（过程记录）、F116（中医结构化记录）

---

## 3. 涉及的表

`treatment_execution`、`treatment_status_log`

---

## 4. 规则

**R1 状态机（契约 §2.11）。**
```
SCHEDULED → IN_PROGRESS → COMPLETED
SCHEDULED → CANCELLED
IN_PROGRESS → INTERRUPTED（**必须填原因**）
INTERRUPTED → IN_PROGRESS | CANCELLED
```
非法转换拒绝 E3001 并留痕。

**R2 中断必填原因。** `INTERRUPTED` 必须记录中断原因（过敏、患者不耐受、设备故障等），写 `audit_high_risk`。

**R3 完成前校验必填记录。** `need_record=1` 的项目，完成时必须已有执行记录内容（F56）；中医项目必须已有 F116 结构化记录，否则拒绝完成（E2001）。

**R4 执行人与时间。** 完成记录 `executor_id` / `executed_at`（`occurred_at` 取业务发生时间）；**不接受外部传入**（03 §4.1）。

**R5 完成即终态。** `COMPLETED` 不可再改状态；如需撤销收费走 M09 退款，**不改处置状态**。

**R6 已完成处置的取消。** 已 `COMPLETED` 的处置不允许直接取消（E3062）——先走 M09 退款流程，再由管理人员作废并留痕。

**R7 中断可恢复。** `INTERRUPTED → IN_PROGRESS` 允许继续，保留中断历史（状态日志完整）。

**R8 埋点就位。** `occurred_at`、`executor_id`、`charge_flag` 供 M15 F120 统计（R-M08-10）。

---

## 5. 验收标准

**AC1（正常完成）**
- Given 处置 SCHEDULED
- When 开始并完成
- Then 状态 `COMPLETED`，执行人与时间已记录
- 验证方式：自动

**AC2（中断必填原因）**
- Given 执行中
- When 中断未填原因
- Then 拒绝 E2001
- 验证方式：自动

**AC3（中断可恢复）**
- Given 处置 INTERRUPTED
- When 恢复并继续
- Then 状态回 `IN_PROGRESS`，中断历史保留
- 验证方式：自动

**AC4（非法转换被拒）**
- Given 处置 COMPLETED
- When 尝试转 IN_PROGRESS
- Then 拒绝 E3001
- 验证方式：自动

**AC5（已完成不可直接取消）**
- Given 处置 COMPLETED
- When 取消
- Then 拒绝 E3062
- 验证方式：自动

**AC6（必记录项目未完成被拒）**
- Given `need_record=1` 且无执行记录
- When 完成
- Then 拒绝 E2001
- 验证方式：自动（跨 F56）

**AC7（中医项目未填穴位被拒）**
- Given 针灸项目无穴位记录
- When 完成
- Then 拒绝 E2001
- 验证方式：自动（跨 F116）

**AC8（高风险审计）**
- Given 中断与取消
- When 查 `audit_high_risk`
- Then 均有记录含原因
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E3001 | 状态非法转换 | 否 |
| E3062 | 已完成处置不可直接取消 | 否 |
| E2001 | 原因/执行记录缺失 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 执行中途断电 | 状态停留在 `IN_PROGRESS`，重启后可继续或标记为中断并补录原因 |
| 完成事务中断 | 回滚，保持上一状态 |
