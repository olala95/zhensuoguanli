# F116 中医治疗执行记录

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: M]

---

## 1. 职责

中医特有治疗操作的结构化记录：针灸（穴位、手法、留针时长、针感）、推拿、拔罐、艾灸、刮痧、穴位贴敷等，以及治疗中的反应。

---

## 2. 依赖

- 依赖：F54（开立，项目 `is_tcm=1`）、F55（完成前置校验）、M03（辨证论治结果可作为治疗依据，只读）
- 被依赖：M09（中医治疗收费）、M11（归档）、M15 F120

---

## 3. 涉及的表

`tcm_treatment_record`（M08 自有）

---

## 4. 规则

**R1 治疗类别字典化。** `therapy_type` 来自 `sys_dict`（`TCM_THERAPY`）：`ACUP 针灸 / TUINA 推拿 / CUPPING 拔罐 / MOXA 艾灸 / GUASHA 刮痧 / PATCH 穴位贴敷 / OTHER 其他`。

**R2 针灸必填三要素。** 穴位列表（`points`，如 `足三里, 三阴交`）、手法（`manipulation`，补/泻/平补平泻/电针等）、留针时长（`retain_minutes`，分钟）。

**R3 反应必记。** 晕针、出血、疼痛加剧、过敏等异常反应必须记录（`reaction` + `is_abnormal`），异常时写 `audit_high_risk`（与 F56 R4 同源）。

**R4 部位与体位。** 推拿/拔罐类记录部位（`body_part`）与体位（`posture`），便于复盘与责任追溯。

**R5 完成前置。** `is_tcm=1` 的执行记录在完成前必须有对应的中医治疗记录，否则拒绝完成（F55 R7）。

**R6 与证型关联。** 可记录本次治疗对应的证型（来自 M03 F109 辨证结果快照），**只读不写 M03 表**（R2）。

**R7 一条执行一条主记录 + 多次追加。** 主记录随执行记录创建，治疗过程中的补充以追加方式记录（与 F56 同族规则：只追加不改）。

**R8 时间与人。** `performed_at` 取系统时间，`operator_id` 取上下文（03 §4.1）。

---

## 5. 验收标准

**AC1（针灸记录）**
- Given 针灸项目已开立
- When 记录穴位"足三里,三阴交"、手法"平补平泻"、留针 30 分钟
- Then 记录完整，可随执行单查询
- 验证方式：自动

**AC2（缺穴位无法完成）**
- Given 针灸执行未填穴位
- When 完成执行
- Then 拒绝 E2001
- 验证方式：自动

**AC3（留针时长必填）**
- Given 针灸未填留针时长
- When 保存
- Then 拒绝 E2001
- 验证方式：自动

**AC4（异常反应留痕）**
- Given 患者晕针
- When 记录反应并标记异常
- Then `is_abnormal=1`，`audit_high_risk` 有记录
- 验证方式：自动

**AC5（推拿记录部位）**
- Given 推拿项目
- When 记录部位"颈肩"、体位"坐位"、手法"揉法"
- Then 保存成功
- 验证方式：自动

**AC6（证型关联只读）**
- Given 关联证型"肝郁脾虚"
- When 保存
- Then 只写本模块快照，M03 辨证记录未被修改
- 验证方式：自动（跨模块）

**AC7（只追加不改）**
- Given 已有中医治疗记录
- When 追加补充记录
- Then 原记录不变，新增一条
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2001 | 穴位/手法/留针时长缺失 | 否 |
| E3063 | 非中医项目不得记录中医治疗 | 否 |
| E2006 | 尝试修改已有记录 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 保存失败 | 重试，已保存内容不丢 |
| 崩溃 | 事务保护；未提交的补充记录可重新录入 |
