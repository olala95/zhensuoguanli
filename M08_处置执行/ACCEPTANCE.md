# M08 处置执行 · 验收

> 本文只写**跨 F 的端到端场景与故障演练**，单 F 内部的 AC 见各 `Fxx.md`。

---

## 1. 端到端场景

### S1 西医处置全链路

```
接诊中（Visit IN_PROGRESS）→ 开立处置（F54，可应用组套 F53）
   → 开始执行（F55 IN_PROGRESS）→ 记录过程（F56）→ 完成 COMPLETED
   → M09 按执行记录与单价快照生成账单明细
```

**判定**：
- [ ] 编号 `TE{yyyyMMdd}{4位}` 连续不重复
- [ ] 每次状态转换都有 `treatment_status_log`
- [ ] 单价快照不随项目调价变化
- [ ] M09 只读本模块，未直写 `treatment_execution`

### S2 中医治疗全链路

```
开立针灸项目（is_tcm=1）→ 执行 → 填写穴位/手法/留针时长（F116）
   → 记录反应（可选）→ 完成 → 收费
```

**判定**：
- [ ] 未填穴位/手法/留针时长时完成被拒
- [ ] 异常反应写 `audit_high_risk`
- [ ] 证型只作快照，未修改 M03 辨证记录

### S3 异常处置（中断 / 取消 / 退款）

```
执行中患者不适 → 中断（填原因）→ 恢复继续 或 取消
   → 已收费的取消处置 → M09 退款 → 处置保持可追溯，不物理删除
```

**判定**：
- [ ] 中断与取消必填原因并写高风险审计
- [ ] 已完成处置不可直接取消（E3062），必须先退款
- [ ] 中断历史完整保留，恢复后不丢

### S4 Visit 作废联动

```
M02 F125 作废就诊 → 该就诊下未执行的处置全部取消（cancelByVisit）
   → 已完成的保留（需人工退费）
```

**判定**：
- [ ] 未执行处置被取消且留有原因（继承就诊作废原因）
- [ ] 已完成处置不被自动取消
- [ ] M02 通过本模块服务接口调用，未直接 UPDATE 本模块表

## 2. 故障演练

| # | 场景 | 期望 |
|---|---|---|
| M8-1 | 执行中强制断电 | 状态停留在 `IN_PROGRESS`，重启后可继续或补录为中断（含原因） |
| M8-2 | 开立事务中途断电 | 执行记录要么完整要么不存在，编号跳号允许 |
| M8-3 | 组套展开部分失败 | 整单回滚，不产生半成品执行记录 |
| M8-4 | 重复提交开立（幂等键） | 只生成一批执行记录 |
| M8-5 | 已完成处置被尝试取消 | 拒绝 E3062，引导走退款流程 |
| M8-6 | 中医项目缺必填字段完成 | 拒绝 E2001，已录内容不丢 |

## 3. 审计与合规检查

- [ ] 开立、开始、完成、中断、取消均有 `audit_operation` 与状态日志
- [ ] 中断与取消写 `audit_high_risk`（含原因）
- [ ] 过程记录与中医治疗记录只追加，不可修改/删除
- [ ] 埋点字段（`occurred_at` / `executor_id` / `charge_flag`）就位，可供 M15 F120 统计
- [ ] 处置记录随病历归档（M11）时可完整导出，含中医结构化字段
