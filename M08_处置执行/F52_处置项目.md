# F52 处置项目

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

处置项目目录：编码、名称、类别、计价单位、单价、是否需执行记录、是否中医操作；是 M09 收费与 M15 统计的基础数据。

---

## 2. 依赖

- 依赖：M14（数据字典、F128 导入）、M12
- 被依赖：F53（组套）、F54（开立）、M09 F57/F58（收费）、M15 F120

---

## 3. 涉及的表

`treatment_item`（M08 自有）

---

## 4. 规则

**R1 编码唯一。** `item_code` 建唯一索引，导入时按编码 upsert（M14 F128 消费 `import.upsert`）。

**R2 类别字典化。** `category` 取值来自 `sys_dict`（`TREATMENT_CATEGORY`）：`INJECTION 注射 / DRESSING 换药 / NEBULIZE 雾化 / PHYSIO 理疗 / TCM 中医 / EXAM 检查操作 / OTHER 其他`。

**R3 单价整数分。** `price_fen` INTEGER；调价**不追溯**已开立的处置（R-M08-4）。

**R4 中医标记。** `is_tcm=1` 的项目执行时必须走 F116 的结构化记录（穴位/手法/留针时长）。

**R5 执行留痕标记。** `need_record=1` 的项目完成时必须填写执行记录，否则拒绝完成（E2001）。

**R6 停用而非删除。** 项目停用具 `is_active=0` + 软删除；已被历史执行引用的项目**不得物理删除**。

**R7 计价单位。** `unit`（次/部位/小时/穴位等），用于收费明细展示。

---

## 5. 验收标准

**AC1（建档）**
- Given 编码 `TZ001`、名称"静脉输液"、单价 2000 分
- When 创建
- Then 入库成功，编码唯一
- 验证方式：自动

**AC2（编码重复被拒）**
- Given 已存在 `TZ001`
- When 再次创建
- Then 拒绝 E2004
- 验证方式：自动

**AC3（调价不追溯）**
- Given 已开立单价 2000 分的处置，后将项目调为 2500 分
- When 查该执行记录
- Then 快照仍为 2000 分
- 验证方式：自动

**AC4（停用不可开立）**
- Given 项目已停用
- When 开立处置
- Then 拒绝 E3060
- 验证方式：自动

**AC5（中医项目标记）**
- Given `is_tcm=1` 的针灸项目
- When 完成时未填穴位
- Then 拒绝 E2001
- 验证方式：自动（跨 F116）

**AC6（导入 upsert）**
- Given CSV 含已存在编码与新编码
- When 导入
- Then 已存在更新、新增插入，返回条数正确
- 验证方式：自动（跨 M14 F128）

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E2004 | 编码重复 | 否 |
| E3060 | 项目已停用不可用 | 否 |
| E2001 | 必填缺失 | 否 |
