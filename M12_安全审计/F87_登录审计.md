# F87 登录审计

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

记录登录、锁屏、解锁、登出、角色切换事件，以及登录失败。

> 表 `audit_login` 归本模块所有，由 M14 的登录流程（F100）通过本模块接口写入，M14 不直接写表。

---

## 2. 依赖

- 依赖：M14（F100 登录/锁屏触发）
- 被依赖：无

---

## 3. 涉及的表

`audit_login`（M12 自有，**只允许 INSERT**）

---

## 4. 规则

**R1 记录事件类型。** LOGIN / LOGOUT / LOCK / UNLOCK / ROLE_SWITCH / LOGIN_FAILED / SESSION_TERMINATED（被新登录顶替）。

**R2 失败也要记。** 登录失败记录含尝试的用户名（不含密码）、时间、来源。

**R3 连续失败升级。** 同一账号连续失败 ≥3 次，除本表记录外同时写 `audit_high_risk`（F86）。

**R4 角色切换单独记。** 切换角色记录前后角色（配合 F100 AC6）。

**R5 时间取系统时间。** 不接受外部传入。

**R6 锁屏不影响会话连续性。** LOCK/UNLOCK 不产生新会话 ID，同一会话内记录。

**R7 退出必记。** 正常退出、异常终止（若可捕获）、被顶替均要记录 LOGOUT 或 SESSION_TERMINATED。

**R8 不可修改删除。** 同 F84 R4。

---

## 5. 验收标准

**AC1（登录记录）**
- Given 医生 A 登录
- When 登录成功
- Then `audit_login` 有一条 LOGIN 记录：用户 A、角色、时间（系统时间）、session_id
- 验证方式：自动

**AC2（失败记录）**
- Given 密码错误
- When 登录失败
- Then 记录 LOGIN_FAILED，含尝试的用户名，**不含密码**
- 验证方式：自动

**AC3（连续失败升级）**
- Given 同一账号连续失败 3 次
- When 第 3 次失败
- Then `audit_login` 有 3 条失败记录，且 `audit_high_risk` 新增对应记录
- 验证方式：自动

**AC4（锁屏解锁）**
- Given 会话锁屏后解锁
- When 查看记录
- Then LOCK 与 UNLOCK 两条记录的 session_id 相同
- 验证方式：自动

**AC5（角色切换）**
- Given 用户从"医生"切换到"收费员"
- When 切换
- Then 记录 ROLE_SWITCH，含 before_role 与 after_role
- 验证方式：自动

**AC6（被顶替）**
- Given 已登录会话被同一账号新登录顶替
- When 新登录建立
- Then 旧会话记录 SESSION_TERMINATED，新会话记录 LOGIN
- 验证方式：自动

**AC7（不可修改）**
- Given 已存在登录记录
- When 尝试 UPDATE/DELETE
- Then 拒绝并写 `audit_high_risk`
- 验证方式：自动

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E1010 | 审计写入失败 | 是 |
| E1011 | 尝试修改审计记录 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 登录审计写入失败 | 登录整体失败（不允许无审计的会话建立） |
| 退出前审计未写入 | 退出流程先写审计再关连接（`05_RUNTIME_TOPOLOGY` §8 第 7 步） |
