# F89 权限审计

[TYPE: FEATURE] [PRIORITY: P0] [SIZE: S]

---

## 1. 职责

记录所有被拒绝的权限访问尝试（越权、无角色、跨角色操作），用于发现误配置与潜在违规。

---

## 2. 依赖

- 依赖：M14（`auth.require()` 在拒绝时调用本接口）
- 被依赖：无

---

## 3. 涉及的表

`audit_permission`（M12 自有，**只允许 INSERT**）

---

## 4. 规则

**R1 拒绝即记录。** 任何 `auth.require()` 失败都写一条：操作人、当前角色、所需权限、模块/功能点、目标对象、时间。

**R2 不记录成功。** 成功的权限校验不写入本表（由 F84 覆盖），避免表膨胀。

**R3 高频去重。** 同一用户 + 同一权限在冷却期内（默认 5 分钟）重复被拒，合并计数而非逐条记录，但**首次必记**。

**R4 越权尝试告警。** 以下情况升级为 `audit_high_risk`：尝试访问/修改已确认病历、尝试修改审计表、非管理员尝试改敏感配置、尝试自我提权。

**R5 拒绝必须明确。** 拒绝时返回明确异常码 `E6002` 与人话提示（"当前角色为医生，无收费权限"），**不静默放行也不静默失败**。

**R6 不可修改删除。** 同 F84 R4。

**R7 统计视图。** 提供"权限拒绝统计"（按用户、权限、时间段），供管理员发现角色配置问题。

---

## 5. 验收标准

**AC1（拒绝记录）**
- Given 当前角色为"医生"
- When 尝试执行收费（需收费员权限）
- Then 操作被拒返回 `E6002`，`audit_permission` 新增一条：operator、role=医生、required_permission=收费、feature=F59
- 验证方式：自动

**AC2（明确提示）**
- Given 无权限操作
- When 界面提示
- Then 提示明确说明"当前角色 X 无 Y 权限"，不是笼统的"操作失败"
- 验证方式：自动

**AC3（越权升级）**
- Given 当前为"医生"角色
- When 尝试修改一张已确认的病历
- Then 拒绝 + 写 `audit_high_risk`
- 验证方式：自动

**AC4（高频去重）**
- Given 同一用户 1 分钟内被同一权限拒绝 10 次
- When 查看记录
- Then 首次完整记录，后续合并为计数（不超过 2 条）
- 验证方式：自动

**AC5（成功不记）**
- Given 一次有权限的正常操作
- When 操作成功
- Then `audit_permission` 无新增
- 验证方式：自动

**AC6（统计视图）**
- Given 存在多条拒绝记录
- When 管理员查看统计
- Then 可按用户/权限/时间筛选，显示拒绝次数
- 验证方式：自动

**AC7（不可修改）**
- Given 已存在拒绝记录
- When 尝试 UPDATE/DELETE
- Then 拒绝并写 `audit_high_risk`
- 验证方式：自动

---

## 6. 异常码

| 码 | 场景 | 可重试 |
|---|---|---|
| E6001 | 未登录 | 否 |
| E6002 | 无权限 | 否 |
| E6003 | 账号锁定 | 是 |
| E6004 | 账号禁用 | 否 |
| E1010 | 审计写入失败 | 是 |
| E1011 | 尝试修改审计记录 | 否 |

---

## 7. 失败恢复

| 失败点 | 恢复方式 |
|---|---|
| 权限审计写入失败 | 操作整体拒绝（不允许无记录的拒绝发生也无法追溯） |
| 角色配置错误导致大量拒绝 | 统计视图暴露问题；管理员调整角色 |
